创建窗口

创建窗口的步骤

  • 初始化GLFW glfwInit()

    • 管理窗口需要使用GLFW库，因此首先需要初始化GLFW库

  • 创建窗口对象 glfwCreateWindow()

    • 创建窗口对象

  • 设置上下文

    • glfwMakeContextCurrent()设置当前窗口为当前线程的主上下文

  • 加载glad

    • gladLoadGLLoader((GLADloadproc)glfwGetProcAddress)

    • glad库用于管理OpenGL的函数指针,调用OpenGL函数前需要初始化GLAD

  • 设置视口

    • glViewport()设置渲染窗口的尺寸大小

  • 主循环

    • while(!glfwWindowShouldClose(window))渲染循环

  • 回收资源

    • glfwTerminate()

头文件

GLAD必须在前面(GLAD中包含了正确的OpenGL头文件，例如:GL/gl.h)

主函数

初始化GLFW

  • 可选：使用glfwWindowHint()配置GLFW
    • 第一个参数代表选项的名称，以GLFW_开头的枚举值中选择
    • 第二个参数接受一个整型，用来设置这个选项的值
    • 该函数的所有的选项以及对应的值都可以在 GLFW’s window handling 这篇文档中找到
    • 如果编译后得到大量的 undefined reference (未定义的引用)错误，没有正确地链接GLFW库。

创建窗口对象

设置窗口上下文为当前线程的主上下文

加载glad

  • gladLoadGLLoader：这是 GLAD 提供的一个函数，用于加载 OpenGL 函数指针。它需要一个函数指针作为参数，这个函数指针指向一个能够加载 OpenGL 函数的函数。

  • GLADloadproc：GLADloadproc 是 GLAD 定义的一个函数指针类型，用于指向加载 OpenGL 函数的函数。

  • glfwGetProcAddress：这是 GLFW 库提供的函数，用于获取 OpenGL 函数的地址。当你创建了一个 OpenGL 上下文后，这个函数可以用来获取 OpenGL 函数的指针。

  • 给GLAD传入了用来加载系统相关的OpenGL函数指针地址的函数，glfwGetProcAddress根据我们编译的系统定义了正确的函数

设置视口(可选)

不设置则默认窗口大小为视口大小

主循环

程序在主动关闭它之前不断绘制图像并能够接受用户输入

  • glfwWindowShouldClose()在每次循环的开始前检查一次GLFW是否被要求退出

    • 如果是的话，该函数返回true，渲染循环将停止运行，之后我们就可以关闭应用程序。

  • glfwPollEvents()检查有没有触发什么事件（比如键盘输入、鼠标移动等）、更新窗口状态，并调用对应的回调函数（可以通过回调方法手动设置）。

  • glfwSwapBuffers()会交换颜色缓冲（它是一个储存着GLFW窗口每一个像素颜色值的大缓冲），它在这一迭代中被用来绘制，并且将会作为输出显示在屏幕上。
