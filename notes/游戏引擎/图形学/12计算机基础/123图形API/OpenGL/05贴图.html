贴图

配置贴图完整步骤

1. 准备纹理资源

首先需获取纹理图像文件（如PNG、JPG、TGA等），并通过图像加载库（如stb_image、FreeImage、SOIL2）读取图像数据，获取关键信息：

  • 图像宽度（width）、高度（height）
  • 颜色通道数（channels）：如RGB（3通道）、RGBA（4通道，含透明度）
  • 像素数据缓冲区（unsigned char* 类型，存储每个像素的颜色值）

2. 创建纹理对象

使用glGenTextures创建纹理对象（类似着色器的“对象ID”），后续所有纹理操作均围绕该ID进行。

3. 绑定纹理对象

通过glBindTexture将纹理对象绑定到指定的纹理目标（Texture Target），后续操作会作用于该绑定的纹理。
常用纹理目标：

  • GL_TEXTURE_2D：2D纹理（最常用，如平面、模型表面贴图）
  • GL_TEXTURE_CUBE_MAP：立方体贴图（如天空盒、环境映射）

4. 配置纹理参数（关键）

纹理参数决定GPU如何采样纹理（如放大/缩小过滤、边缘环绕方式），需在绑定纹理后调用glTexParameteri配置。若参数未正确设置，可能导致纹理拉伸、模糊或边缘异常。

核心纹理参数列表

参数名（GLenum） 作用 常用值（GLenum）
GL_TEXTURE_WRAP_S 纹理S轴（水平方向）环绕方式 GL_REPEAT（重复）、GL_CLAMP_TO_EDGE（边缘拉伸）、GL_MIRRORED_REPEAT（镜像重复）
GL_TEXTURE_WRAP_T 纹理T轴（垂直方向）环绕方式 同GL_TEXTURE_WRAP_S
GL_TEXTURE_MIN_FILTER 纹理缩小过滤（物体远离镜头时） GL_NEAREST（邻近过滤，像素化）、GL_LINEAR（线性过滤，平滑）、GL_LINEAR_MIPMAP_LINEAR（MIP贴图+线性，最高质量）
GL_TEXTURE_MAG_FILTER 纹理放大过滤（物体靠近镜头时） GL_NEAREST（像素化）、GL_LINEAR（平滑，无MIP贴图）

6. 生成MIP贴图（可选但推荐）

MIP贴图（Mipmap）是一组分辨率递减的纹理副本（如原图→1/2尺寸→1/4尺寸…），GPU在物体远离镜头时自动使用低分辨率MIP层，减少采样计算量并避免“纹理闪烁”。
仅需调用glGenerateMipmap即可自动生成所有MIP层级（需先上传基础层纹理数据）。

7. 释放CPU端图像数据

纹理数据已上传到GPU后，CPU端的textureData不再需要，需调用图像加载库的释放函数（如stbi_image_free），避免内存泄漏。

8. 在着色器中使用纹理

需在顶点着色器和片段着色器中添加纹理相关逻辑，建立“顶点纹理坐标→片段采样”的流程。

步骤1：定义纹理坐标（Vertex Shader）

顶点着色器需接收纹理坐标（TexCoord）（由应用程序传递，如顶点数据的一部分），并将其传递给片段着色器（通过out变量）。

步骤2：采样纹理颜色（Fragment Shader）

片段着色器需通过采样器（Sampler） 变量访问GPU中的纹理，使用texture()函数根据纹理坐标采样颜色，并将其作为片段颜色输出。

9. 绑定纹理单元并激活纹理

现代OpenGL支持多纹理采样（如同时使用“ diffuse贴图”和“ specular贴图”），通过纹理单元（Texture Unit） 区分不同纹理（编号从0开始，默认激活纹理单元0）。
使用纹理前需：

  1. 激活目标纹理单元（glActiveTexture）；
  2. 将纹理对象绑定到该纹理单元（glBindTexture）；
  3. （多纹理时）在着色器中设置采样器的uniform值，指定其绑定的纹理单元。

10. 绘制几何体（触发纹理采样）

激活着色器程序和纹理后，调用绘制函数（如glDrawArrays、glDrawElements），GPU会自动根据顶点纹理坐标采样纹理，生成带纹理的片段颜色。

11. 解绑纹理（可选）

绘制完成后，可解绑纹理对象（避免后续操作意外修改该纹理），但非必需（后续绑定其他纹理会自动覆盖当前绑定）。

12. 释放纹理资源（程序退出/资源销毁时）

当纹理不再需要（如场景切换、程序退出），需调用glDeleteTextures删除纹理对象，释放GPU内存。

核心函数详解

1. glGenTextures

  • 作用：生成一个或多个纹理对象ID（用于标识GPU中的纹理资源）。
  • 函数原型：
  • 参数：
    • n：要生成的纹理对象数量（如1表示生成1个纹理）；
    • textures：指向GLuint数组的指针，用于存储生成的纹理ID（若n=1，可直接传单个变量地址）。
  • 注意：生成的ID仅为“空标识”，需通过glBindTexture绑定后才能配置参数和上传数据。

2. glBindTexture

  • 作用：将纹理对象绑定到指定的纹理目标，后续纹理操作（如配置参数、上传数据）均作用于该绑定的纹理。
  • 函数原型：
  • 参数：
    • target：纹理目标（如GL_TEXTURE_2D、GL_TEXTURE_CUBE_MAP），决定纹理的类型和用途；
    • texture：要绑定的纹理ID（生成的textureID），或0（表示解绑当前目标的纹理）。
  • 关键逻辑：OpenGL通过“绑定目标”管理状态，同一时间一个目标只能绑定一个纹理，但一个纹理可绑定到多个目标（需类型匹配）。

3. glTexParameteri

  • 作用：设置纹理对象的参数（如环绕方式、过滤方式），决定GPU如何处理纹理采样。
  • 函数原型：
  • 参数：
    • target：纹理目标（需与绑定的目标一致，如GL_TEXTURE_2D）；
    • pname：要设置的参数名（如GL_TEXTURE_WRAP_S、GL_TEXTURE_MIN_FILTER）；
    • param：参数值（需与pname匹配，如GL_REPEAT、GL_LINEAR）。
  • 常见参数组合：
    • 像素化风格纹理：GL_TEXTURE_MIN_FILTER = GL_NEAREST + GL_TEXTURE_MAG_FILTER = GL_NEAREST；
    • 平滑风格纹理：GL_TEXTURE_MIN_FILTER = GL_LINEAR_MIPMAP_LINEAR + GL_TEXTURE_MAG_FILTER = GL_LINEAR；
    • 无重复纹理（如UI贴图）：GL_TEXTURE_WRAP_S = GL_CLAMP_TO_EDGE + GL_TEXTURE_WRAP_T = GL_CLAMP_TO_EDGE。

4. glTexImage2D

  • 作用：将CPU端的2D图像数据上传到GPU的纹理对象中，是“CPU→GPU”纹理数据传输的核心函数。
  • 参数细节（补充）：
    • level：MIP贴图层级，0表示“基础分辨率层”，1表示“1/2分辨率层”，以此类推（手动生成MIP时需指定，自动生成时设为0）；
    • internalFormat：GPU内部存储格式，决定纹理的颜色精度和通道数（如GL_RGB8表示8位/通道的RGB，GL_RGBA32F表示32位浮点/通道的RGBA）；
    • format：输入图像的格式，必须与textureData的通道数匹配（如channels=3时设为GL_RGB，channels=4时设为GL_RGBA）；
    • type：输入像素数据的类型，常用GL_UNSIGNED_BYTE（对应unsigned char，0-255范围），若为浮点纹理设为GL_FLOAT。
  • 注意：图像宽度/高度若为“2的幂”（如256、512），兼容性更好；现代OpenGL支持非2幂，但需确保GL_TEXTURE_WRAP设为非重复模式（如GL_CLAMP_TO_EDGE）。

5. glGenerateMipmap

  • 作用：自动为当前绑定的纹理生成所有MIP贴图层级，避免手动创建低分辨率纹理副本。
  • 函数原型：
  • 参数：纹理目标（需与绑定的目标一致，如GL_TEXTURE_2D）；
  • 使用场景：当纹理需要在“远/近镜头”切换时保持清晰（如3D模型贴图），必须生成MIP贴图；若为UI贴图（始终全屏显示），可省略（因无需缩小）。

6. glActiveTexture

  • 作用：激活指定的纹理单元，用于多纹理采样（如同时使用多个贴图时区分不同纹理）。
  • 函数原型：
  • 参数：纹理单元标识，格式为GL_TEXTUREi（i为纹理单元编号，如GL_TEXTURE0、GL_TEXTURE1）；
  • 默认值：OpenGL默认激活GL_TEXTURE0，因此单纹理场景可省略glActiveTexture调用；多纹理场景必须显式激活不同单元。

7. texture()（GLSL函数）

  • 作用：在片段着色器中根据纹理坐标采样纹理颜色，是“GPU纹理采样”的核心函数。
  • 函数原型（GLSL）：
  • 参数：
    • sampler：采样器变量（如sampler2D ourTexture），绑定到特定纹理单元；
    • texCoord：纹理坐标，2D纹理用vec2（S/T轴，范围通常0.0-1.0），立方体贴图用vec3（方向向量）；
  • 返回值：采样得到的颜色（vec4，RGBA格式，每个分量0.0-1.0）。
