全局光照

全局光照（Global Illumination, GI）是计算机图形学中模拟光线在场景中多次反射、折射和散射的技术，涵盖直接光照（光源直射）和间接光照（光线经物体表面反射/折射后的二次及多次光照），旨在实现真实感光照效果。以下是该小节的核心内容：

一、基础理论与核心概念

1. 光照能量传递模型

  • 光的传播规律：
    • 直接光照：光源到物体的一次光照（如太阳直射地面）。
    • 间接光照：
      • 漫反射间接光照：光线经粗糙表面多次漫反射（如墙面反射的太阳光均匀照亮房间）。
      • 镜面/光泽间接光照：光线经镜面或半镜面表面反射/折射（如镜子反射的灯光、玻璃折射的环境光）。
  • 辐射度方程：
    [ L_o(\mathbf{p}, \mathbf{\omega_o}) = L_e(\mathbf{p}, \mathbf{\omega_o}) + \int_{\Omega} L_i(\mathbf{p}, \mathbf{\omega_i}) f_r(\mathbf{p}, \mathbf{\omega_i}, \mathbf{\omega_o}) (\mathbf{n} \cdot \mathbf{\omega_i}) d\mathbf{\omega_i} ]
    其中 (L_e) 为自发光，(L_i) 为入射光，(f_r) 为BRDF，描述物体表面的反射特性。

2. 全局光照核心目标

  • 物理真实性：模拟光线的能量守恒、颜色衰减、次表面散射等现象（如皮肤的透光效果）。
  • 视觉效果：
    • 环境光的柔和过渡（如室内角落的间接漫反射）。
    • 镜面反射的准确反射路径（如金属物体反射周围环境）。

二、实时全局光照技术（Real-Time GI）

1. 基于图像的光照（Image-Based Lighting, IBL）

  • 核心原理：
    • 使用HDR环境贴图（如天空盒、立方体贴图）近似环境光照，通过预过滤的环境贴图模拟间接光照。
    • 漫反射IBL：
      • 对环境贴图进行球谐函数（Spherical Harmonics, SH）投影或低频滤波，快速计算漫反射间接光照（如Unity的光照探头）。
    • 镜面IBL：
      • 基于微表面粗糙度对环境贴图进行Mipmap层级采样（如GGX分布的重要性采样），模拟光泽反射（如Unreal引擎的反射捕获Actor）。
  • 优势：计算高效，适合实时渲染，广泛用于游戏和交互式场景。

2. 光照贴图（Lightmap）

  • 离线烘焙技术：
    • 预处理阶段计算静态场景的间接光照，将结果存储在光照贴图（纹理）中，运行时直接采样。
    • 技术分类：
      • 辐射度贴图：记录每个面片的辐射度值（适合漫反射为主的场景）。
      • 光照探针（Light Probe）：在场景中布置探针，记录周围环境光照（动态物体通过插值探针数据获取间接光照）。
  • 应用场景：
    • 开放世界游戏的静态环境（如《刺客信条》的全局光照烘焙）。
    • 移动端渲染（减少实时计算开销）。

3. Light Propagation Volumes (LPV)

  • 体积光照技术：
    • 将场景划分为三维网格（体积），通过光线传播算法在体积间传递间接光照（如《战地3》的动态全局光照）。
    • 步骤：
      1. 从光源出发，在体积网格中传播光照能量。
      2. 动态物体通过采样网格数据获取间接光照。
  • 优势：支持动态物体的间接光照，计算复杂度随体积分辨率增长。

4. GPU加速实时GI（如Lumen, NVIDIA RTX GI）

  • 混合技术方案：
    • 光线追踪+光栅化结合：
      • 直接光照使用光栅化，间接漫反射/镜面反射使用路径追踪（如UE5的Lumen全局光照）。
    • 距离场与网格结合：
      • 通过 Signed Distance Field (SDF) 快速计算物体间的光照遮挡，加速间接光照采样。

三、离线全局光照技术（Offline GI）

1. 路径追踪（Path Tracing）

  • 蒙特卡洛积分：
    • 从相机或光源发射光线，模拟光线在场景中的随机路径（反射/折射/吸收），通过统计平均估计光照分布。
    • 关键特性：
      • 天然支持所有类型的全局光照（包括焦散、次表面散射）。
      • 噪声问题：通过重要性采样（如BRDF、光源方向采样）和降噪算法（如BM3D、深度学习降噪）优化。
  • 工业级应用：
    • 电影渲染（如《阿凡达》的水体焦散、《冰雪奇缘》的毛发间接光照）。
    • 产品可视化（如Blender Cycles、V-Ray的路径追踪模式）。

2. 辐射度方法（Radiosity）

  • 面片能量传递：
    • 将场景分解为漫反射面片，计算面片间的形状因子（Form Factor），通过线性方程组求解全局辐射度分布。
    • 优势：精确处理漫反射间接光照，生成柔和的漫反射阴影（适合室内场景）。
    • 局限：仅支持静态场景，无法处理镜面反射和动态物体。

3. 光子映射（Photon Mapping）

  • 双向能量传递：
    • 两步法：
      1. 从光源发射光子，记录光子在场景中的碰撞位置（光子图）。
      2. 从相机追踪光线，利用光子图估计间接光照（尤其适合焦散效果）。
  • 典型应用：
    • 液体、玻璃等透明物体的焦散渲染（如Caustics in Maya Mental Ray）。

四、关键技术与挑战

1. 环境贴图与预处理

  • 预过滤技术：
    • 漫反射环境贴图：通过球谐函数压缩（SH，3阶可表示低频光照）。
    • 镜面环境贴图：生成各向同性/各向异性Mipmap层级（如基于粗糙度的预过滤Cubemap）。
  • 光照探针布局：
    • 基于场景语义（如角落、物体间隙）自动布置探针，减少采样误差（如Unity的Progressive Lightmapper）。

2. 间接光照采样优化

  • 重要性采样：
    • 根据BRDF和光源可见性对采样方向加权（如对区域光的方向采样权重高于均匀采样）。
  • 辐照度缓存（Irradiance Cache）：
    • 存储高频光照细节（如边缘、角落的光照突变），减少重复计算（如Arnold渲染器的辐照度缓存）。

3. 降噪与实时性平衡

  • 传统降噪：
    • 双边滤波、非局部均值滤波（NLM）减少路径追踪噪声。
  • 深度学习降噪：
    • 利用神经网络（如NVIDIA RTX Denoiser）实时过滤稀疏采样噪声，提升实时全局光照质量。

4. 动态全局光照挑战

  • 动态物体交互：
    • 实时更新间接光照路径（如角色移动时，其反射光对环境的影响）。
  • 大规模场景：
    • 结合层次化数据结构（如BVH、八叉树）加速光线与物体的相交测试（如《微软模拟飞行》的全球光照计算）。

五、与其他模块的关联

1. 微表面模型与BRDF

  • 全局光照的间接光照计算依赖微表面模型的BRDF积分（如GGX-Smith-Schlick模型模拟粗糙表面的反射分布，属于2.3.1小节）。

2. 光源系统与阴影技术

  • 全局光照中的间接光源（如反射光形成的二次光源）需与光源系统协同，阴影技术需处理间接光照的遮挡（如软阴影由区域光的间接反射产生，属于2.3.2-2.3.3小节）。

3. 渲染管线与硬件加速

  • 实时管线：全局光照结果作为后处理输入（如IBL的环境光叠加，属于2.2.4后处理链）。
  • 光线追踪硬件：RTX核心加速路径追踪中的光线发射与相交测试（属于3.4.2 RTX实战）。

4. 物理模拟与材质

  • 次表面散射（SSS）的全局光照计算需结合材质的散射参数（如皮肤的半透明属性，属于2.3.1微表面模型扩展）。

六、应用场景与前沿趋势

  1. 电影与动画：
    • 离线路径追踪实现照片级真实感（如《蜘蛛侠：平行宇宙》的艺术化全局光照）。
  2. 实时渲染：
    • 游戏引擎的动态全局光照（如《控制》的光追全局光照增强环境氛围）。
    • VR/AR的沉浸式光照（如Meta Quest的实时IBL优化低功耗设备表现）。
  3. 建筑与工业设计：
    • 光照模拟软件（如Enscape、Twinmotion）的实时全局光照辅助设计决策。
  4. 前沿研究：
    • 神经全局光照：利用神经网络预测间接光照路径（如减少路径追踪的采样次数）。
    • 无偏实时GI：结合硬件加速与算法优化，向电影级光照质量迈进（如UE5 Lumen的动态GI突破）。

避免重复内容

本小节聚焦「光线多次反射的全局能量传递」，不涉及以下内容：

  • 直接光照计算与光源分类（属于2.3.2光源系统）
  • 阴影技术的可见性判断（属于2.3.3阴影技术，全局光照侧重间接光照的能量分布）
  • 微表面模型的BRDF数学推导（属于2.3.1微表面模型，此处侧重全局光照中的应用）

全局光照通过物理模拟与工程优化的结合，成为提升场景真实感的关键技术，其从离线预处理到实时动态计算的演进，推动了交互式图形从“能用”到“逼真”的跨越。
