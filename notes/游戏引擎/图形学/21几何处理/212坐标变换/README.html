坐标变换

坐标变换是计算机图形学中几何处理的核心模块，用于在不同坐标系下转换几何对象的位置、方向和尺度，支撑渲染管线、动画、物理模拟等关键功能。以下是该小节的核心内容：

一、基础几何变换

1. 平移变换（Translation）

  • 数学定义：将点/向量从原坐标 ((x, y, z)) 移动到新坐标 ((x + t_x, y + t_y, z + t_z))
  • 变换矩阵（齐次坐标下）：
    [
    T(t_x, t_y, t_z) = \begin{bmatrix}
    1 & 0 & 0 & t_x \
    0 & 1 & 0 & t_y \
    0 & 0 & 1 & t_z \
    0 & 0 & 0 & 1 \
    \end{bmatrix}
    ]
  • 应用：模型在世界空间中的位置调整，动画中的对象移动。

2. 旋转变换（Rotation）

  • 绕轴旋转（右手定则定义正方向）：
    • 绕x轴：角度 (\theta)，矩阵：
      [
      R_x(\theta) = \begin{bmatrix}
      1 & 0 & 0 & 0 \
      0 & \cos\theta & -\sin\theta & 0 \
      0 & \sin\theta & \cos\theta & 0 \
      0 & 0 & 0 & 1 \
      \end{bmatrix}
      ]
    • 绕y轴、z轴：类似形式，交换行列顺序。
  • 复合旋转：通过欧拉角（Euler Angles）或四元数（Quaternion）表示复杂旋转，避免欧拉角的万向节锁（Gimbal Lock）问题。
  • 四元数优势：避免矩阵插值的非线性问题，高效表示旋转插值（球面线性插值Slerp）。

3. 缩放变换（Scaling）

  • 均匀缩放：各轴缩放因子相同（(s_x = s_y = s_z)），保持对象比例。
  • 非均匀缩放：各轴独立缩放（(s_x, s_y, s_z) 不同），可能导致对象变形。
  • 变换矩阵：
    [
    S(s_x, s_y, s_z) = \begin{bmatrix}
    s_x & 0 & 0 & 0 \
    0 & s_y & 0 & 0 \
    0 & 0 & s_z & 0 \
    0 & 0 & 0 & 1 \
    \end{bmatrix}
    ]
  • 特殊情况：镜像变换（缩放因子为负数，如 (s_x = -1) 表示x轴镜像）。

二、齐次坐标与仿射变换

1. 齐次坐标（Homogeneous Coordinates）

  • 定义：将3D点表示为4维向量 ((x, y, z, w))，其中：
    • 点：(w = 1)（如 ((x, y, z, 1))）
    • 向量：(w = 0)（平移不影响向量，如 ((x, y, z, 0))）
  • 核心作用：将平移变换统一为矩阵乘法，使所有仿射变换（平移、旋转、缩放）可通过4x4矩阵表示。

2. 复合变换矩阵

  • 变换顺序：矩阵相乘顺序至关重要（如先旋转后平移 ≠ 先平移后旋转），通常按 局部变换 → 世界变换 → 视图变换 → 投影变换 的顺序级联。
  • 变换级联：多个变换矩阵按顺序相乘，如 (M = T \cdot R \cdot S)（先缩放，再旋转，最后平移）。

三、坐标空间转换

1. 核心坐标空间

  • 局部空间（Local Space）：对象自身的坐标系（模型原点通常位于中心或锚点）。
  • 世界空间（World Space）：全局坐标系，所有对象的局部变换最终转换到世界空间。
  • 视图空间（View/Camera Space）：以相机为原点的坐标系，世界空间点通过视图变换（相机位置、朝向）转换到视图空间。
  • 裁剪空间（Clip Space）：投影变换后的坐标系，通过齐次除法（(x/w, y/w, z/w)）转换为标准化设备坐标（NDC，范围 ([-1, 1]^3)）。

2. 关键变换阶段

  • 模型变换（Model Transform）：局部空间 → 世界空间（应用缩放、旋转、平移）。
  • 视图变换（View Transform）：世界空间 → 视图空间（等价于将相机固定在原点，反向变换场景）。
  • 投影变换（Projection Transform）：
    • 正交投影（Orthographic Projection）：保持对象比例，无近大远小，用于工程图、2D渲染。
    • 透视投影（Perspective Projection）：模拟真实相机视角，通过视锥体（Frustum）裁剪，近平面物体更大，远平面物体更小，矩阵包含透视除法逻辑。

四、顶点与法线变换

1. 顶点变换

  • 顶点坐标直接通过4x4变换矩阵相乘（齐次坐标下），结果经齐次除法得到最终坐标。

2. 法线变换

  • 问题：非均匀缩放会改变法线方向，不能直接使用顶点变换矩阵。
  • 正确方法：使用顶点变换矩阵的逆转置矩阵 ( (M^{-1})^T )，确保法线与切线空间的正交性。
  • 特例：均匀缩放时，法线可直接乘以缩放因子（或忽略，若缩放因子已知且均匀）。

五、变换的应用场景

  1. 渲染管线：
    • 模型加载时，通过模型矩阵将局部坐标转换为世界坐标。
    • 视图矩阵将世界坐标转换为相机坐标，投影矩阵生成裁剪坐标。
  2. 动画与骨骼蒙皮：
    • 骨骼变换矩阵级联（父骨骼到子骨骼的相对变换），顶点通过蒙皮权重混合多个骨骼变换结果。
  3. 物理模拟：
    • 刚体运动的位置、旋转更新（变换矩阵或四元数表示刚体状态）。
  4. 用户交互：
    • 鼠标点击屏幕坐标到世界空间的逆向变换（屏幕坐标 → 视图坐标 → 世界坐标，用于射线拾取）。

六、注意事项与数学特性

  1. 变换矩阵的可逆性：
    • 旋转矩阵是正交矩阵（逆矩阵等于转置矩阵，(R^{-1} = R^T)），保证变换可逆。
    • 奇异矩阵（行列式为0）表示不可逆变换（如缩放因子为0），需避免。
  2. 变换顺序的影响：
    • 矩阵乘法不满足交换律（(A \cdot B \neq B \cdot A)），必须严格遵循业务逻辑所需顺序（如先缩放后旋转，或先旋转后缩放）。
  3. 数值稳定性：
    • 多次变换级联可能导致浮点精度误差，需定期对变换矩阵进行正交化或归一化（如骨骼动画中的矩阵压缩）。
