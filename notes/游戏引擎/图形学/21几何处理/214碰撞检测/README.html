碰撞检测

碰撞检测是计算机图形学与物理模拟中判断物体间是否发生接触或相交的核心技术，其目标是在保证效率的前提下精确检测几何对象的空间关系。以下是该小节的核心内容：

一、基础碰撞检测类型

1. 离散碰撞检测（Discrete Collision Detection, DCD）

  • 原理：在离散时间步长内检测物体当前状态是否相交，不考虑运动过程中的中间状态。
  • 优势：计算高效，适用于实时场景（如游戏、交互系统）。
  • 缺点：可能遗漏高速运动物体的穿透现象（“隧道效应”）。

2. 连续碰撞检测（Continuous Collision Detection, CCD）

  • 原理：计算物体在运动轨迹中是否与其他物体发生接触，求解最小相交时间（Time of Impact, TOI）。
  • 方法：
    • 基于运动向量的射线检测（如刚体运动视为线段，检测线段与静止物体的相交）。
    • 分离轴定理（Separating Axis Theorem, SAT）扩展至运动物体。
  • 优势：避免高速物体穿透，适用于精确物理模拟（如刚体动力学、流体碰撞）。

二、包围体（Bounding Volume）技术

1. 轴对齐包围盒（AABB, Axis-Aligned Bounding Box）

  • 定义：以对象坐标轴对齐的最小立方体，由最小/最大坐标点 ((min_x, min_y, min_z)) 和 ((max_x, max_y, max_z)) 定义。
  • 相交检测：判断两AABB在x、y、z轴上的投影区间是否重叠（三维重叠条件：三轴向均不分离）。
  • 优势：计算极快，适合快速排除不相交对象；硬件加速友好（如GPU的AABB查询）。
  • 缺点：紧密性差（复杂形状的包围盒空隙大），旋转后需重新计算。

2. 包围球（Sphere）

  • 定义：以对象中心点为球心，半径为最大距离的球体。
  • 相交检测：两球心距离小于半径之和则相交。
  • 优势：旋转不变性（仅需更新球心位置），适合快速粗略检测。
  • 缺点：紧密性差（凸凹物体的包围球包含大量无效空间）。

3. 方向包围盒（OBB, Oriented Bounding Box）

  • 定义：随对象方向变化的包围盒，由中心、轴向量（局部坐标系）和半长轴定义。
  • 相交检测：基于分离轴定理（SAT），检查15条潜在分离轴（两物体各3个轴向 + 6个叉积轴）。
  • 优势：紧密性优于AABB，适合旋转对象的碰撞检测（如角色模型）。
  • 缺点：相交检测计算复杂度高于AABB（需矩阵变换与轴计算）。

4. 胶囊体（Capsule）

  • 定义：两端为半球、中间为圆柱的包围体，常用于模拟人体或细长物体（如角色四肢）。
  • 相交检测：线段与球体/圆柱的组合检测，或转化为点到胶囊体的距离计算。
  • 应用：角色与环境的碰撞（如避免穿模），机器人运动规划中的障碍物检测。

5. 包围体层次（Bounding Volume Hierarchy, BVH）

  • 结构：对复杂几何体（如多边形网格）递归构建包围体树，父节点包围子节点的包围体。
  • 检测流程：
    1. 从根节点递归检测包围体是否相交；
    2. 若相交，继续检测子节点，直到叶子节点（几何图元，如三角形）。
  • 优势：通过层级过滤快速排除不相交区域，提升大规模网格检测效率（如光线追踪、物理引擎）。

三、精确几何检测算法

1. 点与几何对象的检测

  • 点与三角形：利用重心坐标或面积法判断点是否在三角形内部（需计算向量叉积）。
  • 点与曲面：隐式曲面（如SDF）直接计算点到曲面的距离；参数曲面（如NURBS）通过参数空间投影判断。

2. 射线与几何对象的检测

  • 射线与三角形（Möller-Trumbore算法）：
    • 通过求解射线与三角形所在平面的交点，并判断交点是否在三角形重心坐标范围内。
    • 优势：计算高效，仅需16次浮点运算，是光线追踪和碰撞检测的核心算法。
  • 射线与网格：结合BVH加速，先检测射线与包围体相交，再递归到叶子节点的三角形。

3. 多边形网格与网格的检测

  • 分离轴定理（SAT）：
    • 对凸多边形，若存在一条轴（坐标轴或边法线）使两物体的投影不重叠，则不相交。
    • 扩展至凹网格时需分解为凸部件（如凸包分解）。
  • GJK算法（GJK Algorithm）
    • 基于闵可夫斯基差集，通过迭代搜索凸形状间的最小距离，判断是否小于零（相交）。
    • 优势：适用于凸体检测，内存占用小，是物理引擎（如Bullet、PhysX）的核心算法。
  • EPA算法（Expanding Polytope Algorithm）
    • 与GJK配合，计算相交凸体的接触点和穿透深度，用于碰撞响应（如力的施加）。

4. 曲面与曲面的检测

  • 隐式曲面（如SDF）：计算两曲面的最小距离（符号距离场的交集判断）。
  • 参数化曲面：通过离散采样或解析方法求解曲面间的交线（如NURBS曲面求交，用于CAD模型碰撞）。

四、空间划分与加速技术

1. 均匀网格（Grid）

  • 原理：将场景划分为等大小的网格单元，每个单元存储进入其中的物体。
  • 检测步骤：仅检测相邻网格内的物体对，减少不必要的对象对比较。
  • 优势：实现简单，适合稀疏场景；支持GPU并行化（如compute shader批量处理网格单元）。
  • 缺点：网格分辨率难以平衡（过密增加存储，过疏漏检）。

2. 八叉树（Octree）

  • 原理：递归将三维空间划分为8个子空间，直到达到叶子节点容量限制。
  • 应用场景：动态场景（如物体移动时仅更新所在子树），地形碰撞检测（结合地形LOD层次）。

3. 空间哈希（Spatial Hashing）

  • 原理：通过哈希函数将物体位置映射到网格索引，快速查找潜在碰撞对象。
  • 优势：动态插入/删除高效，适合高频运动物体（如粒子系统、流体模拟）。

五、碰撞检测的应用与优化

1. 应用场景

  • 物理模拟：刚体/软体碰撞（如布料与角色碰撞、车辆碰撞），计算接触力与动量传递。
  • 交互系统：射线拾取（如鼠标点击3D物体）、碰撞反馈（如UI按钮按压效果）。
  • 游戏开发：角色与环境碰撞（避免穿模）、技能范围检测（如AOE伤害判定）。
  • 机器人学：运动规划中的障碍物规避（如机械臂避障）。

2. 优化策略

  • 分层检测：先进行包围体粗检，再进行精确几何检测（如BVH+三角形相交）。
  • 时间连贯性：利用上一帧碰撞对信息，减少重复检测（如空间划分结构的增量更新）。
  • 硬件加速：
    • GPU并行化（如大规模粒子碰撞检测，利用CUDA/OpenCL）。
    • 专用硬件（如Intel的IPT技术，加速AABB相交检测）。

3. 碰撞响应

  • 接触点与法向量：精确检测后需计算接触点和表面法向量，用于物理引擎的碰撞响应（如弹性碰撞、摩擦力计算）。
  • 穿透处理：通过位置修正（Position Correction）或冲量传递（Impulse-Based）消除穿透，保持模拟稳定性。

六、挑战与前沿技术

  1. 大规模场景：城市级建模中的碰撞检测，需结合层次化结构（如BVH+空间哈希混合方案）。
  2. 可变形物体：软体、布料的碰撞检测，需实时更新包围体并处理动态网格（如基于FEM的变形体碰撞）。
  3. 深度学习辅助：通过神经网络预测潜在碰撞区域，减少传统算法的遍历开销（如自动驾驶中的实时碰撞预警）。
