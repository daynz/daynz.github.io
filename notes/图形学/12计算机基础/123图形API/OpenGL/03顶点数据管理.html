顶点数据管理

顶点数据管理步骤

对象声明

声明了三个无符号整数变量，用于存储这三种缓冲对象的ID。

生成缓冲对象

  • glGenBuffers函数生成指定数量的缓冲对象，并将它们的ID存储在变量中
  • 第一个参数是要生成的对象数量，第二个参数是存储ID的变量地址

绑定VAO

绑定VAO，之后所有的顶点属性配置都会保存在当前绑定的VAO中，方便后续渲染时快速切换配置。

绑定缓冲对象到目标

  • GL_ARRAY_BUFFER：用于顶点数据的目标
  • GL_ELEMENT_ARRAY_BUFFER：用于索引数据的目标
  • 绑定后，后续的缓冲操作都会作用于当前绑定的缓冲对象

将数据复制到缓冲内存

  • 第一个参数：目标缓冲类型
  • 第二个参数：数据大小（字节）
  • 第三个参数：要复制的数据指针
  • 第四个参数：使用提示（GL_STATIC_DRAW表示数据不会频繁修改）

配置顶点属性指针

  • glVertexAttribPointer：定义了顶点数据的解析方式
    • 参数1：顶点属性位置索引（与着色器中的layout(location = 0)对应）
    • 参数2：每个顶点属性的分量数量（3表示xyz坐标）
    • 参数3：数据类型
    • 参数4：是否归一化
    • 参数5：步长（连续顶点属性之间的字节偏移量）
    • 参数6：数据在缓冲中的起始偏移量
  • glEnableVertexAttribArray：启用指定索引的顶点属性

解绑缓冲对象

  • 解绑VBO和VAO，防止后续操作意外修改这些缓冲对象
  • 注意：EBO不需要手动解绑，它会被当前绑定的VAO保管

绘制图形

  • 这是使用索引绘制的函数：

    • 参数 1：绘制的图元类型（这里是三角形）

    • 参数 2：要绘制的索引数量（6 个索引）

    • 参数 3：索引的数据类型（无符号整数）

    • 参数 4：索引数据在 EBO 中的偏移量（0 表示从起始位置开始）

资源释放部分

  • 这些函数会通知 OpenGL 释放对应的 GPU 资源，避免内存泄漏：

    • glDeleteVertexArrays：删除 VAO

    • glDeleteBuffers：删除 VBO 和 EBO

    • glDeleteProgram：删除着色器程序

顶点缓冲区对象VBO

  1. glGenBuffers：

    • 作用：生成一个或多个缓冲区对象的名称。
    • 细节：这个函数不分配 GPU 内存，只是创建一个或多个缓冲区对象的名称，这些名称可以用于后续的绑定和数据操作。

  2. glBindBuffer：

    • 作用：将一个缓冲区对象绑定到一个特定的缓冲区目标。
    • 细节：绑定操作使得后续对缓冲区目标的调用（如 glBufferData）都会影响到绑定的缓冲区对象。可以将其视为“激活”或“选择”一个缓冲区以便进行操作。

  3. glBufferData：

    • 作用：为绑定的缓冲区对象分配内存，并可选地上传数据。
    • 细节：这个函数分配 GPU 内存，并根据提供的参数初始化缓冲区内容。如果提供了数据指针，数据将被复制到 GPU 内存中；如果没有提供数据指针（即 data 参数为 NULL），则只分配内存，内容未定义。

这三个函数的典型使用流程如下：

  1. 调用 glGenBuffers 来获取一个或多个缓冲区对象的名称。
  2. 调用 glBindBuffer 并传入缓冲区对象的名称和目标（如 GL_ARRAY_BUFFER），以绑定缓冲区对象。
  3. 调用 glBufferData 并传入缓冲区大小、数据指针和数据使用模式，以分配内存并初始化缓冲区内容。

这个过程确保了应用程序能够将数据有效地传输到 GPU，供后续的渲染操作使用。

glGenBuffers

glGenBuffers 是用于生成缓冲区对象名称的函数。这个函数会返回一个或多个缓冲区对象的名称，这些名称可以随后用于绑定和操作相应的缓冲区。

函数原型如下：

  • 参数：
    • n：要生成的缓冲区对象名称的数量。这个值必须大于 0。
    • buffers：一个指向 GLuint 类型数组的指针，用于存储生成的缓冲区对象名称。指向一个数组的指针，该数组足够大，可以存储 n 个缓冲区对象的名称。这些名称随后可以被用来绑定缓冲区，以便你可以向 GPU 上传数据或从中读取数据。

glBindBuffer

glBindBuffer 是用于绑定缓冲区对象到特定缓冲区目标的函数。缓冲区目标定义了缓冲区的用途，例如顶点数据、索引数据或统一缓冲区对象（UBO）。

函数原型如下：

  • 参数：
    • target：指定缓冲区的目标，这个目标决定了缓冲区的用途。例如，GL_ARRAY_BUFFER 用于顶点属性数据，GL_ELEMENT_ARRAY_BUFFER 用于索引数据。包括但不限于：
      • GL_ARRAY_BUFFER：用于存储顶点属性数据，如顶点坐标、颜色、纹理坐标等。
      • GL_ELEMENT_ARRAY_BUFFER：用于存储索引数据，通常用于 glDrawElements 函数。
      • GL_UNIFORM_BUFFER：用于存储着色器的统一变量。
      • GL_TEXTURE_BUFFER：用于存储纹理数据。
      • 还有其他一些针对特定扩展的目标。
    • buffer：指定要绑定的缓冲区对象的名称。传递 0 可以解绑当前绑定的缓冲区。

glBindBuffer用于设置渲染管线的缓冲区状态。通过绑定不同的缓冲区到不同的目标，可以控制数据如何在渲染管线中流动。

glDeleteBuffers

glDeleteBuffers 是 OpenGL 中用于删除缓冲区对象的函数。当你不再需要一个或多个缓冲区对象（例如 VBO、EBO 等）时，应该使用这个函数来释放它们占用的资源。

函数原型如下：

  • 参数：

    • n：要删除的缓冲区对象名称的数量。
    • buffers：一个指向包含缓冲区对象名称的数组的指针，该数组包含了要删除的缓冲区对象的名称。

  • 注意事项：

    • 删除缓冲区对象后，不应再对这些对象进行操作，否则可能会导致未定义的行为。

    • 在应用程序退出之前，或者在不再需要这些缓冲区之前，应该清理和删除所有创建的缓冲区对象，以避免资源泄露。

    • 如果尝试删除一个已经绑定的缓冲区，OpenGL 的行为是未定义的。因此，在删除缓冲区之前，确保已经解绑了所有相关的缓冲区。

  • 解绑VBO

    • 在 OpenGL 中，VBO（顶点缓冲区对象）可以在数据上传到 GPU 后解绑。解绑 VBO 是一个好习惯，因为它允许 OpenGL 优化资源的使用，并且可以避免意外修改已经绑定的缓冲区。

    • 通常，在以下情况下解绑 VBO：

      1. 数据上传完成后：一旦你使用 glBufferData 或 glBufferSubData 将数据上传到 VBO，就可以解绑 VBO。

      2. 切换到另一个缓冲区：如果你需要绑定另一个缓冲区（例如，切换到另一个 VBO 或者绑定 EBO），那么在此之前应该解绑当前的 VBO。

      3. 完成渲染命令设置：在设置了所有顶点属性指针和绘制调用之后，可以解绑 VBO。

      4. 在渲染循环的开始或结束：在渲染循环中，你可以在每次绘制调用之前重新绑定 VBO，然后在绘制完成后解绑。

    • 解绑 VBO 不会改变缓冲区中的数据，也不会影响已经设置的顶点属性指针。如果你在渲染循环中重复使用同一个 VBO，那么可以在循环开始时绑定它，并在循环结束时解绑。这样做有助于避免在每次迭代中重复绑定和解绑操作，从而提高性能。

glBufferData

glBufferData 是用于创建和初始化缓冲区对象（如 VBO、EBO 等）的函数。这个函数不仅可以用来创建缓冲区，还可以用来更新已经存在的缓冲区的内容。

函数原型如下：

  • 参数：
    • target：指定缓冲区的目标，例如 GL_ARRAY_BUFFER 或 GL_ELEMENT_ARRAY_BUFFER。
    • size：指定要创建的缓冲区的大小，以字节为单位。
    • data：指向要复制到缓冲区的初始数据的指针。如果设置为 NULL，则缓冲区被分配但不被初始化，其内容是未定义的。
    • usage：指定期望的缓冲区数据使用模式，这有助于 OpenGL 优化内存分配和访问模式。常见的使用模式有：
      • GL_STATIC_DRAW：数据不会或几乎不会改变，但可能会被多次绘制。
      • GL_DYNAMIC_DRAW：数据会频繁改变，但可能会被多次绘制。
      • GL_STREAM_DRAW：数据每次绘制时都会改变。

glBufferData 可以用于初始化新创建的缓冲区，也可以用于更新已经存在的缓冲区。如果需要更新缓冲区的部分数据，可以使用 glBufferSubData 函数。如果只是需要更改整个缓冲区的数据，可以重新调用 glBufferData 来重新上传数据。

请注意，glBufferData 可能会在内部进行内存复制，因此提供的数据在函数调用后可以被释放或修改，而不会影响 GPU 上的数据。

现在已经把顶点数据储存在显卡的内存中，用VBO这个顶点缓冲对象管理。后续顶点着色器和片段着色器来处理这些数据

顶点数组对象VAO

  1. glGenVertexArrays：

    • 作用：生成一个或多个 VAO 名称。
    • 细节：这个函数创建了 VAO 的名称（即句柄），并将它们存储在提供的数组中。这些名称随后可以用来创建和引用 VAO。此时，VAO 只是一个空的容器，没有关联任何状态或顶点数据。

  2. glBindVertexArray：

    • 作用：绑定一个 VAO，使其成为当前的顶点数组对象。
    • 细节：当你绑定一个 VAO 时，OpenGL 会记录当前的顶点属性状态，包括顶点缓冲区的绑定和顶点属性指针的配置。绑定 VAO 后，你可以进行顶点属性的设置，如绑定 VBO、设置顶点属性指针、启用或禁用顶点属性等。这些设置会被保存在 VAO 中，当你再次绑定同一个 VAO 时，这些设置会自动恢复，从而避免了重复配置的需要。

glGenVertexArrays 用于创建 VAO 的名称， glBindVertexArray 用于将 VAO 绑定到当前的 OpenGL 状态，以便你可以配置和管理顶点属性。这种机制允许将顶点属性配置与 VAO 关联，从而在渲染时快速恢复这些配置。

glGenVertexArray

glGenVertexArrays 是 OpenGL 中用于生成顶点数组对象（VAO）名称的函数。VAO 用于存储顶点属性的状态，包括顶点缓冲区对象（VBO）的绑定和顶点属性指针的配置。使用 VAO 可以简化顶点属性的设置过程，并提高渲染效率。

函数原型如下：

  • 参数：
    • n：要生成的 VAO 名称的数量。这个值必须大于 0。
    • arrays：一个指向 GLuint 类型数组的指针，用于存储生成的 VAO 名称。指向一个数组的指针，该数组足够大，可以存储 n 个 VAO 名称。这些名称随后可以被用来绑定 VAO，以便你可以配置和管理顶点属性。

glBindVertexArray

glBindVertexArray 是 OpenGL 中用于绑定顶点数组对象（VAO）的函数。当你绑定一个 VAO 时，OpenGL 会将当前的顶点属性状态（包括顶点缓冲区对象（VBO）的绑定和顶点属性指针的配置）与该 VAO 关联起来。这样，当你下次绑定这个 VAO 时，所有之前配置的状态都会自动加载，从而简化了渲染流程。

函数原型如下：

  • 参数：

    • array：要绑定的 VAO 的名称。如果传递 0，则会解绑当前的 VAO。指定要绑定的 VAO 的名称。这个名称是通过调用 glGenVertexArrays 函数生成的。如果你传递 0，那么当前绑定的 VAO 将被解绑。

  • 解绑VAO

    • 在 OpenGL 中，VAO（顶点数组对象）的解绑通常不是必要的，因为 VAO 本身不存储任何 GPU 数据，它只是保存了顶点属性的状态。VAO 的主要作用是保存顶点属性指针和启用状态的配置，以便在渲染时可以快速恢复这些配置。因此，一旦你完成了 VAO 的配置，你可以在渲染循环中重复绑定和解绑 VAO，而不需要在每次使用后立即解绑。

      1. 在切换到另一个 VAO 之前：如果你需要绑定另一个 VAO，那么在此之前应该解绑当前的 VAO。

      2. 在完成一系列设置之后：在设置了 VAO 的所有顶点属性指针和状态后，可以解绑 VAO。

      3. 在渲染循环的开始或结束：在渲染循环中，你可以在每次绘制调用之前绑定 VAO，并在绘制完成后解绑。

    • 解绑 VAO 不会影响 VAO 保存的状态，也不会影响 GPU 上的数据。在下一次需要使用 VAO 时，你只需重新绑定它，OpenGL 会恢复之前保存的所有顶点属性配置。解绑 VAO 主要是为了确保当前没有 VAO 被激活，这在某些情况下可以避免混淆或错误。

glDeleteVertexArrays

glDeleteVertexArrays 是 OpenGL 中用于删除顶点数组对象（VAO）的函数。当你完成了 VAO 的使用，并且不再需要它时，应该调用这个函数来释放相关资源。

函数原型如下：

  • 参数：

    • n：要删除的 VAO 名称的数量。
    • arrays：一个指向包含 VAO 名称的数组的指针。该数组包含了要删除的 VAO 的名称。

  • 注意事项：

    • 删除 VAO 后，不应再对它进行操作，否则可能会导致未定义的行为。

    • 在应用程序退出之前，或者在不再需要这些 VAO 之前，应该清理和删除所有创建的 VAO，以避免资源泄露。

    • 如果尝试删除一个当前绑定的 VAO，OpenGL 的行为是未定义的。因此，在删除 VAO 之前，确保已经解绑了所有相关的 VAO。

链接/解析顶点属性

  1. glVertexAttribPointer：

    • 作用：指定顶点缓冲区对象（VBO）中顶点属性数据的格式和位置。
    • 细节：这个函数定义了顶点属性的布局，包括每个顶点属性的组件数量、数据类型、是否需要归一化、步长（连续顶点属性之间的距离）以及指针（数据在 VBO 中的起始位置）。

  2. glEnableVertexAttribArray：

    • 作用：启用一个顶点属性数组，使得 OpenGL 在渲染时会读取并使用该顶点属性。
    • 细节：这个函数通过顶点属性的索引来启用它。在调用 glVertexAttribPointer 设置了顶点属性指针之后，必须启用对应的顶点属性，否则 OpenGL 将忽略该属性。

glVertexAttribPointer 负责告诉 OpenGL 如何解释 VBO 中的顶点数据，而 glEnableVertexAttribArray 则确保对应的顶点属性在渲染时被激活和使用。这两个函数通常在绑定了 VAO 之后一起使用，以确保顶点属性的正确配置。

glVertexAttribPointer

glVertexAttribPointer 是 OpenGL 中用于定义顶点属性指针的函数。这个函数指定了顶点缓冲区对象（VBO）中顶点数据的格式和位置，这样 OpenGL 就知道如何解释顶点数据。

函数原型如下：

  • 参数：
    • index：顶点属性的索引，这个索引与着色器中 layout(location = index) 定义的布局相匹配。
    • size：每个顶点属性的组件数量（例如，对于 xyz 坐标，size 将是 3）。
    • type：数据的类型，例如 GL_FLOAT、GL_INT 或 GL_UNSIGNED_INT 等。
    • normalized：如果为 GL_TRUE，当 type 是整数类型时，数据会被归一化到 [0,1] 或 [-1,1] 范围内。
    • stride：连续顶点属性之间的字节距离。如果设置为 0，OpenGL 会假定数据是紧密打包的。
    • pointer：指向第一个顶点属性的指针（即 VBO 中数据的起始位置）。

glEnableVertexAttribArray

glEnableVertexAttribArray 是 OpenGL 中用于启用顶点属性数组的函数。在 OpenGL 3.0 及以后的版本中，顶点属性（如顶点坐标、颜色、纹理坐标等）是通过通用顶点属性接口进行控制的。每个顶点属性都有一个与之关联的索引，你可以通过调用 glEnableVertexAttribArray 来启用或禁用特定索引的顶点属性。

函数原型如下：

  • 参数：
    • index：要启用的顶点属性的索引。这个索引与顶点着色器中接收顶点属性的变量的 location 相对应。

绘制图元

glDrawArrays

  • 作用：直接根据顶点缓冲区中的顶点数据顺序绘制图元，不需要索引缓冲（EBO）。
  • 适用场景：顶点数据无重复利用的情况（如独立三角形列表）。

函数原型：

  • 参数：
    • mode：绘制的图元类型，常用值包括：
      • GL_TRIANGLES：每个组3个顶点构成一个三角形
      • GL_TRIANGLE_STRIP：连续三角形带（共享边）
      • GL_TRIANGLE_FAN：三角形扇（围绕一个中心点）
      • GL_LINES：线段（每2个顶点一条线段）
      • GL_LINE_STRIP：连续线段
      • GL_POINTS：点集
    • first：起始顶点的索引（从VBO中第几个顶点开始绘制）
    • count：要绘制的顶点总数

glDrawElements

  • 作用：通过索引缓冲区（EBO）中的索引数据绘制图元，可重复利用顶点数据。
  • 适用场景：顶点数据有重复的复杂模型（如网格、四边形由两个三角形组成的情况），能显著减少数据冗余。

函数原型：

  • 参数：
    • mode：同glDrawArrays，指定图元类型
    • count：要绘制的索引总数（不是顶点数）
    • type：索引数据的数据类型，常用值：
      • GL_UNSIGNED_BYTE：无符号字节（0-255范围）
      • GL_UNSIGNED_SHORT：无符号短整型（0-65535范围）
      • GL_UNSIGNED_INT：无符号整型（更大范围）
    • indices：索引数据在EBO中的起始偏移量（通常为0，表示从开头开始）

绘制函数与顶点属性的关系

  • 绘制函数依赖于已激活的着色器程序和已绑定的VAO：
    • 必须先通过glUseProgram激活着色器程序
    • 必须先通过glBindVertexArray绑定包含顶点属性配置的VAO
    • 对于glDrawElements，还需要确保EBO已绑定到VAO或显式绑定

其他常用绘制函数

  • glDrawArraysInstanced：实例化绘制，用于高效绘制多个相同物体（如粒子系统）
  • glDrawElementsInstanced：带索引的实例化绘制
  • glMultiDrawArrays/glMultiDrawElements：一次调用绘制多个图元组

这些函数在需要批量绘制或实例化渲染时非常有用，能显著提升渲染效率。

绘制函数是 OpenGL 渲染管线的"执行命令"，它们根据之前配置的顶点属性（glVertexAttribPointer/glEnableVertexAttribArray）和缓冲数据，最终将图元渲染到屏幕上。
