C++ STL 容器核心操作复杂度及典型应用场景

1. std::vector

  • 核心操作复杂度:
    • 随机访问（operator[], at()）: O(1)
    • 尾部插入/删除（push_back(), pop_back()）: 均摊 O(1)
    • 中间插入/删除（insert(), erase()）: O(n)
    • 查找（未排序）: O(n)
    • 空间：连续内存，预分配机制（capacity()）
  • 典型应用场景:
    • 需要快速随机访问（如数组替代）。
    • 动态数组（元素数量变化不大或主要在尾部操作）。
    • 存储有序数据（排序后二分查找）。
    • 实现栈（结合 push_back()/pop_back()）。

2. std::deque（双端队列）

  • 核心操作复杂度:
    • 随机访问: O(1)（常数因子大于 vector）
    • 头尾插入/删除（push_front(), push_back(), pop_front(), pop_back()）: 均摊 O(1)
    • 中间插入/删除: O(n)
  • 典型应用场景:
    • 需要高效头尾操作的队列（如滑动窗口、BFS）。
    • 替代 vector 避免扩容开销（分块存储）。
    • std::stack 和 std::queue 的默认底层容器。

3. std::list（双向链表）

  • 核心操作复杂度:
    • 插入/删除（已知迭代器位置）: O(1)
    • 随机访问: O(n)
    • 合并（splice()）: O(1)
    • 排序（sort()）: O(n log n)
  • 典型应用场景:
    • 频繁在任意位置插入/删除（如 LRU Cache）。
    • 大型对象存储（避免 vector 扩容拷贝）。
    • 需要稳定迭代器（插入/删除不影响其他元素迭代器）。

4. std::forward_list（单向链表）

  • 核心操作复杂度:
    • 插入/删除（已知前驱位置）: O(1)
    • 随机访问: O(n)
    • 无反向遍历（无 rbegin()/rend()）。
  • 典型应用场景:
    • 内存敏感场景（比 list 节省一个指针）。
    • 只需要单向遍历（如哈希表桶管理）。

5. std::set / std::multiset

  • 核心操作复杂度（红黑树实现）:
    • 插入/删除/查找（insert(), erase(), find()）: O(log n)
    • 遍历（有序）: O(n)
    • set 去重，multiset 允许多个相同键。
  • 典型应用场景:
    • 维护有序集合（如排行榜）。
    • 需要频繁查找/插入/删除（优于 vector）。
    • 去重计数（set）或重复键排序（multiset）。

6. std::map / std::multimap

  • 核心操作复杂度（红黑树实现）:
    • 插入/删除/查找（insert(), erase(), find()）: O(log n)
    • 遍历（按键有序）: O(n)
    • map 键唯一，multimap 允许多个相同键。
  • 典型应用场景:
    • 键值对字典（如 ID 到对象的映射）。
    • 范围查询（lower_bound()/upper_bound()）。
    • 需要按键有序遍历的场景。

7. std::unordered_set / std::unordered_multiset

  • 核心操作复杂度（哈希表实现）:
    • 平均插入/删除/查找: O(1)
    • 最坏情况（哈希冲突）: O(n)
    • 遍历无序。
  • 典型应用场景:
    • 快速去重（如词频统计）。
    • 不需要有序性的高频查找（如黑名单过滤）。

8. std::unordered_map / std::unordered_multimap

  • 核心操作复杂度（哈希表实现）:
    • 平均插入/删除/查找: O(1)
    • 最坏情况: O(n)
    • 遍历无序。
  • 典型应用场景:
    • 高频键值查询（如缓存系统）。
    • 不需要有序性的字典（如词频统计）。

9. std::stack（适配器）

  • 底层容器（默认 deque）：
    • 核心操作复杂度:
      • push(): O(1)
      • pop(): O(1)
      • top(): O(1)
  • 典型应用场景:
    • LIFO 操作（如函数调用栈、括号匹配）。

10. std::queue（适配器）

  • 底层容器（默认 deque）：
    • 核心操作复杂度:
      • push(): O(1)
      • pop(): O(1)
      • front(): O(1)
  • 典型应用场景:
    • FIFO 操作（如 BFS 算法、任务队列）。

11. std::priority_queue（适配器）

  • 底层容器（默认 vector + 堆算法）：
    • 核心操作复杂度:
      • 插入（push()）: O(log n)
      • 删除堆顶（pop()）: O(log n)
      • 访问堆顶（top()）: O(1)
  • 典型应用场景:
    • 需要最大/最小元素（如任务调度、Dijkstra 算法）。

选择指南

需求 推荐容器
快速随机访问 vector / array
高效头尾操作 deque
任意位置插入删除 list / forward_list
有序集合/键值对 set/map（红黑树）
高频查找（无需有序） unordered_set/unordered_map
LIFO 栈 stack
FIFO 队列 queue
优先级队列 priority_queue
