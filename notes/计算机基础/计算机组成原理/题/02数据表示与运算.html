2.1数制与码制

进制转换

定点数表示

一、基础概念：符号位与数值位

  • 符号位：最高位固定为符号位（0=正，1=负），其余位为数值位。

二、原码

  • 定义：直接表示符号和数值，符号位+绝对值的二进制形式。
  • 转换规则：
    • 正数：符号位为0，数值位为该数绝对值的二进制。
      例：+5的原码 → 00000101（符号位0，数值位5的二进制0000101）。
    • 负数：符号位为1，数值位为该数绝对值的二进制。
      例：-5的原码 → 10000101（符号位1，数值位5的二进制0000101）。
  • 特殊值：0有两种原码（+0=00000000，-0=10000000）。

三、反码

  • 定义：负数对原码的数值位取反（0变1，1变0），符号位不变。
  • 转换规则：
    • 正数：反码 = 原码（数值位不变）。
      例：+5的原码=00000101 → 反码=00000101。
    • 负数：符号位不变，数值位按位取反。
      例：-5的原码=10000101 → 反码=11111010（数值位0000101取反为1111010）。
  • 特殊值：0有两种反码（+0=00000000，-0=11111111）。

四、补码

  • 定义：解决反码中“0有两种表示”和“减法运算复杂”的问题，是计算机中实际存储的编码。
  • 转换规则：
    • 正数：补码 = 原码 = 反码（三者相同）。
      例：+5的补码=00000101。
    • 负数：补码 = 反码 + 1（符号位不变，数值位先取反再+1）。
      例：-5的反码=11111010 → 补码=11111010 + 1=11111011。
  • 特殊值：0只有一种补码（00000000），8位补码范围：-128~+127（-128的补码为10000000，无原码/反码对应）。

五、移码

  • 定义：用于表示浮点数的阶码，将补码的符号位取反（本质是加一个偏移量，使所有数均为非负）。
  • 转换规则：
    • 移码 = 补码的符号位取反（数值位不变）。
      例：+5的补码=00000101 → 移码=10000101（符号位0变1）。
      例：-5的补码=11111011 → 移码=01111011（符号位1变0）。
  • 特点：移码的大小顺序与真值一致，方便比较（如10000101 > 01111011 对应 +5 > -5）。

六、转换关系总结（以8位为例）

真值 原码 反码 补码 移码（补码符号位取反）
+5 00000101 00000101 00000101 10000101
-5 10000101 11111010 11111011 01111011
+0 00000000 00000000 00000000 10000000
-0 10000000 11111111 00000000 10000000
-128 无 无 10000000 00000000
