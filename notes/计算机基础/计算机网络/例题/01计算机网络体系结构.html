一、基础单链路传播时间计算（含发送时间对比）

题目1：某链路带宽为100Mbps，链路长度为2000km，信号在链路上的传播速度为2×10⁸m/s。若要传输一个大小为5000B的分组，忽略分组头开销和处理延迟、排队延迟，求：
（1）该分组的传播时间；
（2）该分组的发送时间；
（3）从分组第一个比特发出到最后一个比特到达接收端的总延迟。

解析：

核心公式：

  • 传播时间（TpT_pTp​）= 链路长度（LLL）/ 信号传播速度（vvv）
  • 发送时间（TtT_tTt​）= 分组大小（MMM）/ 链路带宽（RRR）（注意单位统一：1B=8bit，1Mbps=10⁶bit/s）

（1）传播时间：
L=2000km=2×106mL=2000km=2×10^6mL=2000km=2×106m，v=2×108m/sv=2×10^8m/sv=2×108m/s
Tp=2×106/2×108=0.01s=10msT_p = 2×10^6 / 2×10^8 = 0.01s = 10msTp​=2×106/2×108=0.01s=10ms

（2）发送时间：
M=5000B=5000×8=4×104bitM=5000B=5000×8=4×10^4bitM=5000B=5000×8=4×104bit，R=100Mbps=100×106bit/sR=100Mbps=100×10^6bit/sR=100Mbps=100×106bit/s
Tt=4×104/(100×106)=4×10−4s=0.4msT_t = 4×10^4 / (100×10^6) = 4×10^{-4}s = 0.4msTt​=4×104/(100×106)=4×10−4s=0.4ms

（3）总延迟：
“第一个比特发出到最后一个比特到达” = 发送时间 + 传播时间（最后一个比特需先发送完，再传播到接收端）
总延迟 = Tt+Tp=0.4ms+10ms=10.4msT_t + T_p = 0.4ms + 10ms = 10.4msTt​+Tp​=0.4ms+10ms=10.4ms

二、多链路级联场景（路由器转发延迟）

题目2：主机A通过2段链路与主机B通信，链路1：长度1000km，带宽1Gbps；链路2：长度500km，带宽100Mbps。信号在两段链路上的传播速度均为2×10⁸m/s。路由器转发分组时的处理延迟为1ms（忽略排队延迟），分组大小为1500B（含分组头）。求：
（1）两段链路各自的传播时间；
（2）从A发送分组到B接收分组的总延迟（需考虑路由器转发）。

解析：

多链路场景核心：分组需依次经过“链路1发送→链路1传播→路由器处理→链路2发送→链路2传播”，总延迟为各环节延迟之和。

（1）各链路传播时间：

  • 链路1：Tp1=1000×103/2×108=0.005s=5msT_{p1} = 1000×10^3 / 2×10^8 = 0.005s = 5msTp1​=1000×103/2×108=0.005s=5ms
  • 链路2：Tp2=500×103/2×108=0.0025s=2.5msT_{p2} = 500×10^3 / 2×10^8 = 0.0025s = 2.5msTp2​=500×103/2×108=0.0025s=2.5ms

（2）各环节延迟计算：

  • 链路1发送时间：Tt1=(1500×8)/(1×109)=1.2×10−5s=0.012msT_{t1} = (1500×8) / (1×10^9) = 1.2×10^{-5}s = 0.012msTt1​=(1500×8)/(1×109)=1.2×10−5s=0.012ms
  • 链路2发送时间：Tt2=(1500×8)/(100×106)=1.2×10−4s=0.12msT_{t2} = (1500×8) / (100×10^6) = 1.2×10^{-4}s = 0.12msTt2​=(1500×8)/(100×106)=1.2×10−4s=0.12ms
  • 路由器处理延迟：Tproc=1msT_{proc} = 1msTproc​=1ms

（3）总延迟：
总延迟 = Tt1+Tp1+Tproc+Tt2+Tp2T_{t1} + T_{p1} + T_{proc} + T_{t2} + T_{p2}Tt1​+Tp1​+Tproc​+Tt2​+Tp2​
= 0.012+5+1+0.12+2.5=8.632ms0.012 + 5 + 1 + 0.12 + 2.5 = 8.632ms0.012+5+1+0.12+2.5=8.632ms

三、分组拆分与并行传输优势

题目3：某链路带宽为10Mbps，长度为1500km，信号传播速度为2×10⁸m/s。若要传输一个大小为40000B的大文件，有两种方案：
方案1：作为1个完整分组传输（忽略分组头）；
方案2：拆分为40个小分组传输（每个小分组大小1000B，忽略分组头和拆分开销）。
忽略处理延迟和排队延迟，求两种方案的总传输延迟（从第一个比特发出到最后一个比特到达），并说明分组拆分的优势。

解析：

关键区别：方案1需“完整发送1个大分组后，再传播”；方案2中，前一个小分组开始传播后，后一个小分组可立即开始发送（并行性），总延迟=“最后一个小分组的发送时间 + 传播时间”。

（1）基础参数：

  • 传播时间：Tp=1500×103/2×108=0.0075s=7.5msT_p = 1500×10^3 / 2×10^8 = 0.0075s = 7.5msTp​=1500×103/2×108=0.0075s=7.5ms
  • 带宽：R=10Mbps=10×106bit/sR=10Mbps=10×10^6bit/sR=10Mbps=10×106bit/s

（2）方案1（大分组）：

  • 分组大小：M1=40000B=3.2×105bitM1=40000B=3.2×10^5bitM1=40000B=3.2×105bit
  • 发送时间：Tt1=3.2×105/10×106=0.032s=32msT_{t1}=3.2×10^5 / 10×10^6 = 0.032s=32msTt1​=3.2×105/10×106=0.032s=32ms
  • 总延迟：Tt1+Tp=32+7.5=39.5msT_{t1} + T_p = 32 + 7.5 = 39.5msTt1​+Tp​=32+7.5=39.5ms

（3）方案2（40个小分组）：

  • 单个小分组大小：M2=1000B=8×103bitM2=1000B=8×10^3bitM2=1000B=8×103bit
  • 单个小分组发送时间：Tt2=8×103/10×106=0.0008s=0.8msT_{t2}=8×10^3 / 10×10^6 = 0.0008s=0.8msTt2​=8×103/10×106=0.0008s=0.8ms
  • 40个小分组总发送时间：40×0.8=32ms40×0.8=32ms40×0.8=32ms（与方案1发送总数据量相同，总发送时间一致）
  • 总延迟：40×Tt2+Tp=32+7.5=39.5ms40×T_{t2} + T_p = 32 + 7.5 = 39.5ms40×Tt2​+Tp​=32+7.5=39.5ms？（此处需注意：若链路无排队，方案2总延迟与方案1相同？但实际多链路或多用户场景中，小分组排队延迟更低，且可并行在多链路传输，本题为单链路，需明确场景）

补充说明：本题单链路场景下，因总数据量相同，总发送时间一致，故总延迟相同；但在多链路级联（如经过多个路由器）或多用户共享链路场景中，小分组的“发送-传播”并行性更明显，且排队延迟更低，总延迟会显著低于大分组。

四、传播时间与RTT（往返时间）关联

题目4：主机A向主机B发送一个确认请求分组（大小100B），B收到后立即发送确认响应分组（大小100B）。链路带宽为100Mbps，链路长度为3000km，信号传播速度为2×10⁸m/s，忽略处理延迟和排队延迟。求：
（1）该链路的单程传播时间；
（2）此次“请求-响应”的总RTT（往返时间）。

解析：

RTT = 往程（A→B）总延迟 + 返程（B→A）总延迟；往程/返程总延迟均为“发送时间 + 传播时间”。

（1）单程传播时间：
Tp=3000×103/2×108=0.015s=15msT_p = 3000×10^3 / 2×10^8 = 0.015s = 15msTp​=3000×103/2×108=0.015s=15ms

（2）单个分组发送时间：
Tt=(100×8)/(100×106)=8×10−6s=0.008msT_t = (100×8) / (100×10^6) = 8×10^{-6}s = 0.008msTt​=(100×8)/(100×106)=8×10−6s=0.008ms

（3）总RTT：
往程总延迟 = Tt+Tp=0.008+15=15.008msT_t + T_p = 0.008 + 15 = 15.008msTt​+Tp​=0.008+15=15.008ms
返程总延迟 = 往程总延迟（链路对称，分组大小相同）= 15.008ms
RTT = 15.008×2=30.016ms15.008×2 = 30.016ms15.008×2=30.016ms

（注：若分组很小（如本题100B），发送时间远小于传播时间，RTT≈2×传播时间，可近似计算；若分组很大，发送时间不可忽略）

五、传播时间与带宽的“时延带宽积”

题目5：已知某链路的传播时间为20ms，带宽为1Gbps。求：
（1）该链路的时延带宽积（Delay-Bandwidth Product）；
（2）时延带宽积的物理意义是什么？

解析：

时延带宽积是链路“传播时间”与“带宽”的乘积，单位为“bit”（或“B”），反映链路的“数据容量”。

（1）时延带宽积计算：
传播时间Tp=20ms=0.02sT_p=20ms=0.02sTp​=20ms=0.02s，带宽R=1Gbps=1×109bit/sR=1Gbps=1×10^9bit/sR=1Gbps=1×109bit/s
时延带宽积 = Tp×R=0.02×1×109=2×107bit=2.5×106BT_p × R = 0.02 × 1×10^9 = 2×10^7bit = 2.5×10^6BTp​×R=0.02×1×109=2×107bit=2.5×106B（或2.5MB）

（2）物理意义：
表示“当分组的第一个比特到达接收端时，发送端已经发出的比特总数”，即链路中最多能同时存在的比特数（链路的“数据缓冲区”需求参考）。例如本题中，链路最多可同时承载2000万比特（2.5MB）的数据。

六、综合场景（传播时间+分组丢失重传）

题目6：主机A向主机B传输一个1000B的分组，链路带宽为10Mbps，链路长度为2000km，信号传播速度为2×10⁸m/s。假设分组在传输过程中丢失概率为50%（丢失后A需重新发送，重传次数无上限，忽略重传等待时间、处理延迟和排队延迟）。求该分组从A开始发送到B成功接收的平均总延迟。

解析：

核心是“几何分布求平均重传次数”：每次传输成功概率为p=50%=0.5p=50\%=0.5p=50%=0.5，平均传输次数为1/p=21/p=21/p=2次；每次传输的总延迟为“发送时间 + 传播时间”，平均总延迟=平均传输次数×单次传输总延迟。

（1）单次传输延迟：

  • 传播时间：Tp=2000×103/2×108=0.01s=10msT_p=2000×10^3 / 2×10^8=0.01s=10msTp​=2000×103/2×108=0.01s=10ms
  • 发送时间：Tt=(1000×8)/(10×106)=0.0008s=0.8msT_t=(1000×8)/(10×10^6)=0.0008s=0.8msTt​=(1000×8)/(10×106)=0.0008s=0.8ms
  • 单次传输总延迟：Tsingle=10+0.8=10.8msT_{single}=10+0.8=10.8msTsingle​=10+0.8=10.8ms

（2）平均传输次数：
几何分布中，成功概率为ppp时，平均试验次数为1/p1/p1/p，故平均传输次数=1/0.5=2次。

（3）平均总延迟：
平均总延迟=2×TsingleT_{single}Tsingle​=2×10.8=21.6ms
