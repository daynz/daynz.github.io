函数式编程

std::function、std::bind 是 C++11 为函数式编程提供的核心工具，配合传统的函数对象，解决了 C++ 中 “函数作为一等公民” 的关键问题 —— 统一管理不同类型的可调用对象（函数指针、lambda、函数对象、类成员函数），并支持灵活的参数绑定与复用。

核心背景：可调用对象的碎片化问题

C++ 中 “可调用对象” 包含多种形式：

  1. 普通函数 / 函数指针；
  2. 类成员函数（需绑定this指针）；
  3. 函数对象（重载operator()的类实例）；
  4. Lambda 表达式（本质是匿名函数对象）。

C++11 前，不同可调用对象的类型不统一，无法用同一类型存储 / 传递；std::function 作为 “类型擦除” 的包装器，统一了所有可调用对象的接口；std::bind 则解决了参数绑定（如固定部分参数、调整参数顺序）的问题。

函数对象（Function Object）

函数对象（也称仿函数，Functor）是重载了operator()的类 / 结构体的实例，本质是 “行为像函数的对象”。相比普通函数，函数对象可携带状态（成员变量），支持更灵活的逻辑定制。

  • 可携带状态：通过成员变量保存上下文（如上述的threshold），普通函数无法做到；
  • 类型明确：每个函数对象有独立类型，可作为模板参数（如 STL 算法的谓词）；
  • 可内联优化：编译器可优化operator()的调用，性能优于函数指针；
  • Lambda 的本质：C++11 的 Lambda 表达式编译后会被转换为匿名函数对象（带自动生成的类型）。

std::function（可调用对象包装器）

std::function 是 C++11 提供的类型安全的可调用对象包装器，属于模板类（定义在<functional>头文件），能存储 / 调用任意符合 “签名” 的可调用对象，实现了 “类型擦除”—— 无论底层是函数指针、Lambda、函数对象，都可通过统一的std::function类型管理。

  • 若包装的是类成员函数，需将this指针作为第一个参数（或结合std::bind）；
  • 空的std::function调用会抛出std::bad_function_call异常，可通过operator bool()判断是否有效。

std::bind（参数绑定器）

std::bind 是 C++11 提供的参数绑定工具（定义在<functional>），用于：

  1. 固定可调用对象的部分参数（“柯里化”）；
  2. 调整参数的传递顺序；
  3. 绑定类成员函数的this指针；
  4. 将多参数函数适配为少参数函数（匹配std::function的签名）。
  • std::placeholders::_1、_2…：表示绑定后的函数调用时传入的第 1、2… 个参数；
  • 绑定类成员函数时，第一个参数必须是&类名::成员函数，第二个参数是this指针 / 对象（值 / 引用）。

std::bind 的注意事项

占位符作用域：std::placeholders 需在std命名空间下（或using namespace std::placeholders;）；

参数生命周期：若按值绑定对象（如bind(&MyClass::add, obj, ...)），需确保对象生命周期长于绑定后的函数；按引用绑定（&obj）需避免悬空引用；

C++14 替代方案：Lambda 表达式可替代大部分std::bind场景，语法更直观（如auto bound = [&obj](int x) { return obj.add(10, x); }）。
