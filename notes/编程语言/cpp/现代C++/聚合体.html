C++ 联合体（Union）与 POD 类型

联合体 Union

定义与本质

  • 特殊聚合数据类型，所有成员共享同一段内存
  • 同一时刻仅能激活一个成员
  • 内存大小 = 最大成员的内存大小
  • 核心用途：内存复用、类型变体存储

C++98 传统联合体

限制条件

  1. 仅支持 POD 类型 成员
  2. 无自定义构造/析构函数
  3. 无拷贝/移动构造/赋值函数
  4. 无虚函数、无虚基类
  5. 无非 POD 嵌套成员

POD 类型体系

POD (Plain Old Data) 是 C++ 中用于描述内存布局简单、语义纯粹、与 C 语言完全兼容的一类数据类型。核心在于：可以安全地用 memcpy/memset 操作、二进制序列化、与 C 代码互通。

平凡类型（Trivial）

生命周期操作（构造、拷贝、赋值、析构）完全由编译器默认生成，无任何自定义逻辑：

  • 拥有平凡的默认构造函数（隐式生成或 = default）
  • 拥有平凡的拷贝 / 移动构造、拷贝 / 移动赋值
  • 拥有平凡的析构函数（不执行任何操作）
  • 没有虚函数、没有虚基类

条件

  1. 平凡默认构造
  2. 平凡析构
  3. 平凡拷贝/移动构造/赋值
  4. 无虚函数、无虚基类
  5. 所有成员均为平凡类型

特征

  1. 可安全逐字节拷贝
  2. 无需初始化即可使用
  3. memset/memcpy 安全

判断

标准布局类型（Standard-layout）

内存布局与 C 兼容、可预测、无编译器插入的隐藏数据（如虚表指针）：

  • 所有非静态成员访问权限相同（全 public/private/protected）
  • 没有虚函数、没有虚基类
  • 继承简单：最多一个基类含非静态成员，且第一个非静态成员 ≠ 基类类型
  • 所有非静态成员、基类本身都是标准布局类型

条件

  1. 无虚函数、无虚基类
  2. 所有成员访问权限一致
  3. 符合 C 语言内存布局
  4. 基类无非静态成员
  5. 所有成员均为标准布局

特征

  1. 内存布局可预测
  2. 可与 C 语言结构体交互
  3. 偏移量固定

判断

哪些是 POD 类型？

  • 标量类型

    （天生 POD）

    • 算术类型：bool, char, int, float, double 等
    • 枚举类型
    • 指针、指针到成员、nullptr_t
    • 以上类型的 const/volatile 限定版本

  • POD 类 / 结构体 / 联合体

    • 仅含 POD 成员
    • 满足平凡 + 标准布局
    • 空类 / 空结构体

  • POD 数组（元素是 POD）

C++98 POD 定义

  1. 无自定义构造/析构/拷贝/移动
  2. 无虚函数、无虚基类
  3. 无继承
  4. 所有成员均为 POD
  5. 成员访问权限一致
  6. 与 C 语言二进制兼容

POD 核心用途

  1. C/C++ 混合编程、跨语言交互
  2. 二进制文件读写
  3. 网络数据序列化
  4. 内存操作：memset、memcpy
