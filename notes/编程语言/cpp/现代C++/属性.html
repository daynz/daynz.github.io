属性

基本概念

  • 用 [[...]] 书写
  • 给编译器、静态分析工具提供提示
  • 不影响程序运行逻辑
  • 不产生额外代码 / 无运行开销
  • 用于：警告控制、优化提示、代码规范、API 约束

C++11

[[noreturn]]

  • 作用：声明函数永不返回（如 exit、abort、无限循环）
  • 用途：避免编译器警告“函数应有返回值”

[[carries_dependency]]

  • 作用：用于线程/内存模型，告诉编译器不打断内存依赖顺序
  • 用途：极少用，高性能无锁编程

C++14

[[deprecated]]

  • 作用：标记函数/类/变量已废弃
  • 编译器会警告：不要使用

C++17

[[maybe_unused]]

  • 作用：告诉编译器“这个东西可能不用，别警告”
  • 用于：未使用参数、未使用函数、编译分支

[[nodiscard]]

  • 作用：必须接收返回值，丢弃就警告
  • 最常用属性之一

[[fallthrough]]

  • 作用：switch case 中故意不 break，告诉编译器别警告

inline_namespace

  • 作用：内联命名空间，用于版本管理
  • 用于库的 ABI 兼容

[[no_unique_address]]

  • 作用：允许空类成员不占空间
  • 用于优化结构体内存布局

[[gnu::]] / [[msvc::]]

编译器扩展（非标准，但 C++17 统一了语法）

C++20

[[likely]]

  • 作用：提示编译器这个分支很可能执行，优化

[[unlikely]]

  • 作用：提示分支几乎不执行

[[no_unique_address]]

空成员优化

[[assume(nopack, ...)]]

（部分厂商支持）

C++23

[[assume(condition)]]

  • 作用：告诉编译器条件一定成立，用于强优化

[[defer]]

（部分支持）

重要属性

  1. [[nodiscard]] → 必须接收返回值（最常用）
  2. [[maybe_unused]] → 消除未使用警告
  3. [[deprecated]] → 标记废弃
  4. [[noreturn]] → 永不返回
  5. [[fallthrough]] → switch 不 break
  6. [[likely]] → 分支大概率执行
  7. [[unlikely]] → 分支小概率执行
