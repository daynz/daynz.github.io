指针，引用与const

const 修饰指针

语法形式 const 修饰对象 核心特性（函数/普通场景通用） 函数参数场景应用
const Type* p 指针指向的内容 1. 不能通过p修改指向的内容
2. 指针p可指向其他变量		 最常用：函数内只读数据，不修改
例：void print(const int* arr, int n)
Type* const p 指针本身 1. 指针p不可更换指向
2. 可通过p修改指向的内容		 固定指向某块内存（如硬件寄存器）
例：void setReg(int* const reg, int val)
const Type* const p 内容 + 指针本身 1. 内容不可改
2. 指针指向不可改		 完全只读，适用于常量数据
例：void showConst(const int* const p)

const 修饰引用

语法形式 const 修饰对象 核心特性 函数参数场景应用
const Type& ref 引用绑定的对象 1. 不能通过ref修改原对象
2. 可绑定右值（临时对象）
3. 延长临时对象生命周期		 函数传参最佳实践：
1. 避免大对象拷贝（效率高）
2. 防止误修改实参
例：void print(const string& s)
Type& ref（无const） 无（引用本身不可改） 1. 可通过ref修改原对象
2. 只能绑定左值		 函数内需要修改实参
例：void swap(int& a, int& b)

指针作为函数返回值 + const

语法形式 含义 适用场景 禁止场景
const Type* func() 返回只读内容的指针 返回全局/静态常量的地址，防止外部修改
例：const int* getGlobalConst()		 禁止返回局部变量指针（栈销毁，野指针）
Type* const func() 返回只读指针（指向固定） 返回固定地址的指针（如单例对象）
例：int* const getSingletonPtr()		 无绝对禁止，但需保证指向对象生命周期

引用作为函数返回值 + const

语法形式 含义 适用场景 禁止场景
const Type& func() 返回只读引用 1. 避免大对象拷贝
2. 防止外部修改返回的对象
例：const string& getName()		 禁止返回局部变量引用（栈销毁，野引用）
Type& func()（无const） 返回可修改的引用 支持链式调用（如重载赋值运算符）
例：MyString& operator=(const MyString& s)		 禁止返回局部变量引用

右值引用与 const 的关系

语法形式 核心特性 函数场景应用
Type&& ref（无const） 绑定右值（临时对象），可修改 移动构造/赋值函数参数
例：MyString(MyString&& other)
const Type&& ref 绑定右值，但只读 几乎无实用场景（右值通常用于移动/修改），避免使用

关键规则

  1. 移动语义的核心是Type&&（非const）：需要修改临时对象的资源（如置空指针）；
  2. std::move 可将左值转为Type&&，但const左值转const Type&&（无法触发移动，退化为拷贝）。
