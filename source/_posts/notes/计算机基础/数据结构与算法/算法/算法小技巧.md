## 变量类型选择

| 应用场景                          | 推荐类型          | 备选类型       | 绝对避免                | 核心避坑要点                                                                 |
|-----------------------------------|-------------------|----------------|-------------------------|------------------------------------------------------------------------------|
| 数组/容器下标、循环计数（n≤1e6） | int               | size_t         | long long、unsigned int | 1. int足够覆盖1e6量级；2. 用size_t需避免负数循环（如i--到0时溢出）|
| 小数值运算（仅加减，≤2e9）| int               | long long      | unsigned int            | 仅适用于无乘法/累加溢出风险的场景（如纯计数）|
| 中等/大数值运算（>2e9或含乘法）| long long         | -              | int、unsigned long long | 1. 乘法（如n²）、累加必用；2. 即使结果≤2e9，中间步骤也需用（避免溢出）|
| 取模运算（如1e9+7）| long long         | -              | int                     | 模前计算过程易溢出，全程用long long                                          |
| 浮点数计算（几何、小数）| double            | long double    | float                   | 1. 比较用`fabs(a-b) < 1e-8`；2. float精度仅6~7位，易丢精度                   |
| 单个字符处理（ASCII操作）| char              | -              | int（语义不清晰）| 范围判断用`>= 'a' && <= 'z'`，避免直接用数值对比                             |
| 字符串存储（任意长度、含空格）| string            | char[]         | -                       | 1. 优先用string（自动管理内存）；2. 读带空格字符串用getline                  |
| 布尔判断/状态标记（是/否）| bool              | int（0/1）| -                       | 比int更易读，仅占1字节，适合标记数组（如visited[]）|
| 长度/尺寸类变量（非负）| size_t（可选）| int/long long  | unsigned int            | 1. 仅无负数场景用size_t；2. 新手可直接用int，避免无符号溢出                  |
| 位运算/状态压缩（≤32位）| int               | long long      | bool、size_t            | 32位int可覆盖大部分状态压缩场景，64位用long long                             |
| 位运算/状态压缩（>32位）| long long         | -              | int、size_t             | 64位long long可处理更多状态位                                               |
| 高精度运算（>1e18）| 字符串模拟        | -              | long long、unsigned     | 内置类型无法覆盖，需手动实现大数加减乘除                                     |

1. **优先级原则**：数值运算优先选 `long long`，下标/计数优先选 `int`，小数优先选 `double`，正确性 > 语义规范性；
2. **无符号类型慎用**：`unsigned int`/`unsigned long long` 仅在极特殊场景（如底层内存操作）使用，算法题中几乎用不到，易触发负数溢出坑；
3. **类型匹配**：容器/数组的数值存储类型需和运算类型一致（如 `vector<long long>` 而非 `vector<int>` 存大数）。

## 输入输出

在算法考试的 ACM 模式中，**输入处理**是最容易出错的环节之一（比如你之前遇到的空格/换行问题），掌握输入技巧能大幅减少调试时间。以下是针对 C++ 语言的核心输入技巧，覆盖绝大多数考试场景：

### 基础输入：数字/无空格字符串（cin 直接读）
适用于：输入为纯数字、无空格的字符串（如单词、密码）。
```cpp
// 场景1：单个数字/字符串
int n;
string s;
cin >> n >> s; // 自动跳过空格、换行、制表符等空白字符

// 场景2：多行/多个数字（如第一行n，第二行n个整数）
int n;
cin >> n;
vector<int> nums(n);
for (int i = 0; i < n; i++) {
    cin >> nums[i]; // 无需关心换行，cin 自动跳过空白
}
```
**关键特性**：`cin >>` 会自动忽略**所有空白字符**（空格、换行、制表符），直到读取到有效字符。

### 带空格的整行字符串（`getline`）
适用于：输入包含空格的字符串、整行文本。
```cpp
// 场景：先读数字n，再读长度为n的带空格字符串
int n;
cin >> n;
// 必须先忽略cin >> n后残留的换行符！否则getline会读空行
cin.ignore(numeric_limits<streamsize>::max(), '\n'); 
string s;
getline(cin, s); // 读取整行（包含空格），直到换行符结束（换行符不纳入字符串）
```
**核心坑点**：
- **如果先用 `cin >>` 读数据，再用 `getline`，必须用 `cin.ignore()` 清空缓冲区的换行符；**
- `cin.ignore(MAX, '\n')` 表示：忽略最多 MAX 个字符，直到遇到换行符（并忽略换行符）；
- `numeric_limits<streamsize>::max()` 需要包含头文件 `<limits>`，表示“忽略尽可能多的字符”。

### 多行输入/不定行数输入
适用于：输入行数不固定（如“输入多行字符串，直到输入结束”）。
```cpp
// 场景1：读取多行字符串，直到EOF（考试中通常是输入结束）
string line;
while (getline(cin, line)) { // 当有输入时循环，Ctrl+D（Linux）/Ctrl+Z（Windows）结束
    // 处理每行数据
    cout << line << endl;
}

// 场景2：读取n行字符串（每行可能带空格）
int n;
cin >> n;
cin.ignore(); // 忽略换行符
vector<string> lines(n);
for (int i = 0; i < n; i++) {
    getline(cin, lines[i]);
}
```

### 混合输入：数字+带空格字符串
适用于：一行中既有数字又有带空格的字符串（如“1 Hello World”）。
```cpp
// 场景：一行输入格式为「数字 带空格字符串」
string line;
getline(cin, line); // 先读整行
istringstream iss(line); // 把字符串转为输入流（需包含<sstream>）
int n;
string s, temp;
iss >> n; // 先读数字
// 读取剩余的所有字符（即带空格的字符串）
getline(iss >> ws, s); // >> ws 忽略数字后的空白字符

// 示例输入：3 Hello World
// 输出：n=3, s="Hello World"
```
**关键**：`istringstream` 可以把字符串“拆成”`cin` 一样的输入流，方便混合解析；`>> ws` 用于忽略数字后的空白。

### 特殊字符分隔的输入
适用于：输入用逗号、分号等非空格字符分隔（如“1,2,3,4”）。
```cpp
// 场景：输入以逗号分隔的数字（如1,2,3,4）
string line;
getline(cin, line);
replace(line.begin(), line.end(), ',', ' '); // 把逗号替换为空格（需包含<algorithm>）
istringstream iss(line);
int num;
while (iss >> num) {
    cout << num << " "; // 输出：1 2 3 4
}
```
**技巧**：先将分隔符替换为空格，再用 `cin` 风格读取，简单高效。

## 匹配子序列

给定字符串 **s** 和 **t** ，判断 **s** 是否为 **t** 的子序列。双指针

```c++
bool isSubsequence(string s, string t) {
    if(s.size() == 0) return true;
    int j = 0;
    for (int i = 0; i < t.size(); ++i) {
        if(t[i] == s[j])
        {
            j++;
            if(j == s.size())return true;
        }
    }
    return false;
}
```
