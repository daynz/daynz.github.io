# 算法

## 基础算法
| 算法名称 | 典型用途（含游戏） | 复杂度要点 |
|---------|------------------|-----------|
| 冒泡排序 | 教学、极小数据排序 | O(n²) |
| 选择排序 | 简单数据排序 | O(n²) |
| 插入排序 | 近乎有序数据、部分引擎内部排序 | O(n)~O(n²) |
| 希尔排序 | 高效简化版插入排序 | O(n log n) 左右 |
| 归并排序 | 外部排序、稳定排序 | O(n log n)，稳定 |
| 快速排序 | 通用排序、配置表排序 | O(n log n) 平均 |
| 堆排序 | 优先队列、A* 寻路 | O(n log n) |
| 计数排序 | 小范围整数、伤害数值统计 | O(n + k) |
| 桶排序 | 分数排行、技能伤害分段 | O(n) 近似 |
| 基数排序 | 大量ID排序、玩家排行榜 | O(n × 位数) |
| 顺序查找 | 简单列表遍历 | O(n) |
| 二分查找 | 有序数组、配置表检索 | O(log n) |
| 二分答案 | 数值最值求解、AI 参数搜索 | O(log V) |

## 搜索与回溯
| 算法名称 | 算法分类 | 典型用途（含游戏） | 复杂度要点 |
|---------|---------|------------------|-----------|
| DFS 深度优先搜索 | 搜索 | 迷宫生成、地图探索、技能树遍历 | O(状态数) |
| BFS 广度优先搜索 | 搜索 | 最短路径、洪水填充、视野扩散 | O(状态数) |
| 双向 BFS | 搜索 | 长距离寻路优化 | 比单向更快 |
| 回溯算法 | 回溯 | 关卡解谜、技能组合枚举、棋盘AI | O(指数) |
| 记忆化搜索 | 剪枝 | 避免重复计算、技能伤害计算 | 大幅剪枝 |
| 爬山算法 | 启发式 | AI 行为决策、路径优化 | 局部最优 |
| 模拟退火 | 启发式 |  procedural 生成、布局优化 | 跳出局部最优 |
