# 数据结构

## 基础线性结构
| 数据结构                 | 典型用途                                  | 时间复杂度要点           |
| ------------------------ | ----------------------------------------- | ------------------------ |
| 静态数组(`array`)        | 网格、顶点数据、像素缓冲区、固定列表      | 访问 O(1)，插入删除 O(n) |
| 动态数组(`vector`)       | 游戏对象列表、技能列表、动态缓存          | 尾部增删 O(1)，中间 O(n) |
| 单链表(`list`)           | 简单消息链、轻量对象池                    | 插入删除 O(1)，访问 O(n) |
| 双向链表(`forward_list`) | 渲染队列、UI 链表、骨骼动画节点           | 头尾/已知节点增删 O(1)   |
| 栈(`stack`)              | 状态机回溯、技能连招、UI 导航栈、寻路回溯 | 压栈弹栈 O(1)            |
| 队列(`queue`)            | 网络消息队列、动画队列、任务队列          | 入队出队 O(1)            |
| 双端队列(`deque`)        | 滑动窗口、AOI 管理、物理碰撞队列          | 两端增删 O(1)            |

## 树形基础结构
| 数据结构      | 典型用途                                 | 时间复杂度要点          |
| ------------- | ---------------------------------------- | ----------------------- |
| 二叉树        | 行为树节点、场景树简化结构               | 遍历 O(n)               |
| 二叉搜索树BST | 有序物体管理、区域查询                   | 平均 O(logn)，最坏 O(n) |
| 堆(大/小顶堆) | 优先技能释放、寻路 A*  OPEN 表、事件调度 | 插入弹出 O(logn)        |
| 优先队列      | A* 寻路、伤害结算、技能优先级排序        | 同上                    |
| 四叉树        | 2D 游戏场景物体管理、碰撞剔除、视野裁剪  | 空间划分查询优化        |
| 八叉树        | 3D 场景管理、视锥剔除、物理 Broad-Phase  | 三维空间划分            |
| BSP 树        | 3D 引擎可见性判断、室内场景 Portal 渲染  | 空间分割与可见性判断    |

## 平衡树 & 高级索引结构
| 数据结构         | 典型用途                                     | 时间复杂度要点           |
| ---------------- | -------------------------------------------- | ------------------------ |
| AVL 树           | 有序数据强平衡场景                           | 增删查 O(logn)           |
| 红黑树           | C++ `std::map`、游戏内有序 ID 管理、定时器   | 增删查 O(logn)，工程常用 |
| B 树 / B+ 树     | 游戏存档索引、配置表数据库、资源索引         | 多路平衡，磁盘友好       |
| 跳表(`SkipList`) | 高并发定时器、大世界实体管理、Redis 风格结构 | 增删查 O(logn)，实现简单 |
| 字典树(`Trie`)   | 玩家名字查重、指令前缀匹配、热更新路径管理   | 串匹配 O( len )          |
| 基数树 / 前缀树  | 网络 IP 匹配、资源路径管理                   | 内存更紧凑               |

## 区间 & 统计类结构
| 数据结构               | 典型用途                              | 时间复杂度要点            |
| ---------------------- | ------------------------------------- | ------------------------- |
| 树状数组(Fenwick Tree) | 伤害统计、分数排行、区间求和          | 单点更新/区间查询 O(logn) |
| 线段树                 | 实时属性计算、BUFF 叠加、区间最值查询 | 区间更新/查询 O(logn)     |
| 可持久化线段树(主席树) | 历史状态回溯、录像回放、角色属性快照  | 版本化查询 O(logn)        |
| 单调栈                 | 伤害曲线、技能判定范围、地形遮挡计算  | 线性遍历 O(n)             |
| 单调队列               | 移动平均伤害、视野内最近敌人          | 滑动窗口极值 O(n)         |
| 珂朵莉树(ODT)          | 大面积地形修改、区间 BUFF 批量修改    | 随机数据极快              |

## 图结构与连通性
| 数据结构    | 典型用途                             | 时间复杂度要点      |
| ----------- | ------------------------------------ | ------------------- |
| 邻接表      | 场景寻路网格、社交关系、技能依赖图   | 遍历 O(V+E)         |
| 邻接矩阵    | 小图状态机、技能互斥表               | 遍历 O(V²)          |
| 并查集(DSU) | 组队系统、地图区块连通、物理连通体   | 近似 O(1)(路径压缩) |
| 拓扑排序    | 技能释放顺序、动画依赖、资源加载顺序 | DAG 线性化          |
| 最小生成树  | 地图生成、路网生成、 procedural 内容 | Kruskal / Prim      |

## 缓存 & 工程高级结构
| 数据结构          | 典型用途                                   | 时间复杂度要点         |
| ----------------- | ------------------------------------------ | ---------------------- |
| LRU Cache         | 纹理资源缓存、模型加载缓存、动画 Clip 缓存 | O(1) 访问淘汰          |
| LFU Cache         | 高频资源常驻缓存、技能图标缓存             | 按频率淘汰 O(1) 近似   |
| ARC Cache         | 改进型 LRU，引擎资源缓存策略               | 自适应冷热数据         |
| Time Wheel 时间轮 | 游戏定时器、技能 CD、buff 倒计时           | 海量定时任务 O(1) 触发 |
| 哈希表(HashMap)   | 实体组件映射、配置表、资源 GUID 索引       | 平均 O(1)              |
| 有序映射          | 按 Z 轴渲染排序、UI 层级管理               | O(logn)                |
| 布隆过滤器        | 资源存在性快速判断、玩家黑名单             | 极小假阳性，查询 O(1)  |

## 游戏引擎专用 / 渲染物理专用
| 数据结构                  | 典型用途                             | 时间复杂度要点         |
| ------------------------- | ------------------------------------ | ---------------------- |
| 场景树(`SceneTree`)       | Unity/UE 节点体系、UI 层级、父子变换 | 遍历更新、裁剪可见对象 |
| 包围盒层次树 BVH          | 物理碰撞检测、射线检测、剔除加速     | 加速相交测试           |
| 网格(Grid/2D 数组)        | tiled 地图、寻路网格、AOI 九宫格     | 空间索引 O(1) 定位     |
| 稀疏网格 Sparse Grid      | 大世界地形、体素地形、无限地图       | 只存非空块，节省内存   |
| 环形缓冲区 Ring Buffer    | 音频流、网络发包、日志循环记录       | 无内存拷贝，O(1)       |
| 对象池 `ObjectPool`       | 子弹、特效、怪物、UI 弹窗复用        | 避免 GC，分配 O(1)     |
| 内存池 `Arena/StackAlloc` | 帧分配器、临时计算、引擎底层内存管理 | 批量释放，零碎片       |
| 事件总线 / 消息队列       | 模块解耦、技能触发、战斗事件系统     | 广播/监听 O(n)         |
