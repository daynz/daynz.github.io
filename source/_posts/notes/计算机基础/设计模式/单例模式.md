# 单例模式

## 饿汉式单例

### 核心设计

类加载时就直接实例化唯一对象，**天然线程安全**，无论是否使用，实例提前创建。

### C#代码

```c#
public sealed class HungrySingleton
{
    private static readonly HungrySingleton _instance = new();
    private HungrySingleton() { }

    public static HungrySingleton Instance => _instance;
}
```

### C++代码

```c++
class HungrySingleton
{
public:
    static HungrySingleton &GetInstance()
    {
        return instance;
    }

private:
    static HungrySingleton instance;
    HungrySingleton() {}
    ~HungrySingleton() {}
    HungrySingleton(const HungrySingleton &) = delete;
    HungrySingleton &operator=(const HungrySingleton &) = delete;
    HungrySingleton(HungrySingleton &&) = delete;
    HungrySingleton &operator=(HungrySingleton &&) = delete;
};

HungrySingleton HungrySingleton::instance;
```

### 关键特性

- 线程安全：静态字段由 CLR 保证只初始化一次
- 懒加载：程序启动就占用内存
- 优点：无锁、并发安全、代码稳定
- 缺点：常驻内存，不需要该类也会占用资源

## 懒汉式单例

### 核心设计

**延迟初始化**：第一次调用`Instance`才创建对象，不用不创建，节省内存。

### C#代码

```c#
public class LazySingleton
{
    private static LazySingleton _instance;
    private LazySingleton() { }
    public static LazySingleton Instance => _instance ??= new LazySingleton();
}
```

### C++代码

```c++
class LazySingleton
{
public:
    static LazySingleton &GetInstance()
    {
        static LazySingleton instance;
        return instance;
    }
private:
    LazySingleton() {}
    ~LazySingleton() {}
    LazySingleton(const LazySingleton &) = delete;
    LazySingleton &operator=(const LazySingleton &) = delete;
    LazySingleton(LazySingleton &&) = delete;
    LazySingleton &operator=(LazySingleton &&) = delete;
};
```

### 关键特性

- 线程安全：多线程并发会创建多个实例
- 懒加载：用时才初始化
- 优点：按需创建、内存友好、代码极简
- 缺点：C#版本多线程环境直接崩溃

## 双重检查锁 DCL 单例

### 核心设计

两次判空 + 锁机制 + `volatile` 禁止指令重排，兼顾**懒加载 + 线程安全 + 高性能**。

### C#代码

```c#
public class DclSingleton
{
    private static volatile DclSingleton _instance; // volatile 禁止指令重排
    private static readonly object LockObj = new();

    private DclSingleton()
    {
    }

    public static DclSingleton Instance
    {
        get
        {
            if (_instance == null) // 减少锁竞争
            {
                lock (LockObj)
                {
                    if (_instance == null) // 防止阻塞线程重复实例化
                    {
                        _instance = new DclSingleton();
                    }
                }
            }

            return _instance;
        }
    }
}
```

### 关键特性

- 线程安全：`volatile`+`lock`+双层判空完全安全
- 懒加载：用时才初始化
- 优点：并发安全、按需加载、锁粒度小、性能高
- 缺点：写法稍复杂，需要理解指令重排

## 静态构造函数单例

### 核心设计

利用 C# **静态构造函数** 仅执行一次的特性，由 CLR 自动保证线程安全。

### C#代码

```c#
public sealed class SingletonStaticCtor
{
    static SingletonStaticCtor() // 静态构造函数：CLR 保证全局仅执行一次、线程安全
    {
        Instance = new SingletonStaticCtor();
    }

    private SingletonStaticCtor() { }

    public static SingletonStaticCtor Instance { get; }
}
```

### 关键特性

- 线程安全：CLR 底层保证
- 懒加载：访问静态成员时才触发
- 优点：无手动锁、简洁、安全
- 缺点：静态构造触发时机由 CLR 控制，不够灵活

## .NET 自带 `Lazy<T>` 单例

### 核心设计

借助框架自带`Lazy<T>`，封装懒加载与线程安全。

### C#代码

```c#
public sealed class SingletonLazyNet
{
    private static readonly Lazy<SingletonLazyNet> LazyInstance = new(() => new SingletonLazyNet());

    private SingletonLazyNet() { }

    public static SingletonLazyNet Instance => LazyInstance.Value;
}
```

### 特性

极简、全自动线程安全、纯现代 C# 项目首选，Unity 新版项目可用。

## 泛型单例基类

### 核心设计

抽取单例逻辑为泛型父类，所有普通管理类直接继承，杜绝重复代码。

### C#代码

```c#
public abstract class SingletonBase<T> where T : class, new()
{
    private static T _instance;

    public static T Instance
    {
        get
        {
            _instance ??= new T();
            return _instance;
        }
    }
}

public class CsharpSingleton<T> where T : class, new()
{
    private static readonly Lazy<T> LazyInstance = new(() => new T());

    public static T Instance => LazyInstance.Value;
}
```

## 基础挂载式 Mono 单例 / 持久化 Mono 单例

### 核心设计

脚本手动挂在场景物体上，`Awake` 中做单例唯一性校验，同场景唯一。

在基础单例上加 `DontDestroyOnLoad`，**跨场景常驻**，全局唯一管理器标准写法。

### C#代码

```c#
public class MonoSingleton : MonoBehaviour
{
    public static MonoSingleton Instance { get; private set; }

    private void Awake()
    {
        if (Instance && Instance != this)
        {
            Destroy(gameObject);
            return;
        }

        Instance = this;
        // DontDestroyOnLoad(gameObject);
    }
}
```

### 特性

- 不跨场景：切换场景物体随场景销毁
- 特点：简单轻量，适合当前场景专属管理器（场景道具、关卡管理）

## 自动创建物体 Mono 单例

### 核心设计

访问`Instance`时如果实例为空，**自动创建空 `GameObject` + 绑定脚本**。

### C#代码

```c#
public class AutoCreateMonoSingleton : MonoBehaviour
{
    private static AutoCreateMonoSingleton _instance;

    public static AutoCreateMonoSingleton Instance
    {
        get
        {
            if (!_instance)
            {
                var obj = new GameObject(nameof(AutoCreateMonoSingleton));
                _instance = obj.AddComponent<AutoCreateMonoSingleton>();
                DontDestroyOnLoad(obj);
            }

            return _instance;
        }
    }

    private void Awake()
    {
        if (_instance && _instance != this)
        {
            Destroy(gameObject);
        }
        else
        {
            _instance = this;
        }
    }
}
```

## 泛型 Mono 持久单例基类

### 核心设计

泛型封装所有 Mono 单例重复逻辑，所有全局管理器直接继承。

```c#
public abstract class MonoSingletonBase<T> : MonoBehaviour where T : MonoBehaviour
{
    private static T _instance;

    public static T Instance
    {
        get
        {
            if (!_instance)
            {
                var obj = new GameObject(typeof(T).Name);
                _instance = obj.AddComponent<T>();
                DontDestroyOnLoad(obj);
            }

            return _instance;
        }
    }

    protected virtual void Awake()
    {
        if (_instance && _instance != this)
        {
            Destroy(gameObject);
        }
        else
        {
            _instance = this as T;
            DontDestroyOnLoad(gameObject);
        }
    }
}
```

## 所有单例模式横向对比

| 模式           | 线程安全   | 懒加载     | 适用环境           |
| -------------- | ---------- | ---------- | ------------------ |
| 饿汉式         | ✅          | ❌          | 小工具、全局配置   |
| 简单懒汉       | ❌          | ✅          | Unity 单线程主线程 |
| DCL 双重锁     | ✅          | ✅          | 多线程、网络、异步 |
| 静态构造       | ✅          | ✅          | 通用后台逻辑       |
| 普通 Mono 单例 | 主线程安全 | 依赖场景   | 场景内专属管理     |
| 持久 Mono 单例 | 主线程安全 | 依赖初始化 | 全局跨场景管理器   |
