# C# 3.0

[toc]

## 隐式类型本地变量

### var关键字声明
#### 核心定义
- **var关键字**：C# 中的**隐式类型声明**关键字，用于在声明变量时**省略显式类型**，由编译器**自动推断变量的具体类型**
- 核心作用：简化代码书写、减少冗余类型声明、支持匿名类型变量声明，不影响运行时性能与类型安全性
- 本质：**编译时语法糖**，编译后变量会替换为真实的CLR类型，与直接写类型完全一致

#### 核心特性
| 特性 | 说明 |
|------|------|
| 隐式推断 | 编译器根据赋值表达式自动确定变量真实类型，无需手动指定 |
| 类型安全 | 变量仍为强类型，一旦推断完成，类型不可更改，不降低类型安全性 |
| 编译时确定 | 类型推断仅发生在编译阶段，运行时无任何性能开销 |
| 非动态 | 与`dynamic`完全不同，不支持运行时类型变更 |
| 仅局部变量 | 仅限方法内局部变量使用，不可用于字段、参数、返回值 |

#### 基础语法
```csharp
// 标准语法：var 变量名 = 初始化值;
var 变量名 = 初始化表达式;
```

#### 完整代码示例
```csharp
void VarDemo()
{
    // 基本类型推断
    var num = 10; // 推断为 int
    var str = "test"; // 推断为 string
    var flag = true; // 推断为 bool

    // 复杂类型推断
    var list = new List<int>(); // 推断为 List<int>
    var dict = new Dictionary<string, int>(); // 推断为 Dictionary<string, int>

    // 匿名类型（var唯一必须使用的场景）
    var person = new { Name = "张三", Age = 20 };
    Console.WriteLine(person.Name);

    // 类型固定，无法修改
    // num = "abc"; 编译报错
}
```

#### 类型推断规则
- 必须**声明时赋值**，不支持先声明后赋值
- 编译器严格匹配赋值表达式的返回类型，无隐式类型转换
- 空值`null`无法直接推断类型，`var n = null`会编译报错
- 数组、泛型、自定义类型均可正常推断
- 匿名类型**只能用var声明**，无其他合法声明方式

#### 使用范围规则
- ✅ 允许：方法内部**局部变量**、`foreach`迭代变量、`using`变量
- ❌ 禁止：类字段、方法参数、方法返回值、泛型类型参数
- ❌ 禁止：未赋值的变量声明、多变量同时声明

#### 与显式类型、dynamic对比
- **显式类型**：手动指定类型，代码可读性高，适合简单/基础类型
- **var**：编译器推断类型，简化代码，适合长泛型/匿名类型
- **dynamic**：运行时解析类型，弱类型，跳过编译检查，与var无关

#### 适用场景
- 声明匿名类型变量（**唯一强制场景**）
- 简化长泛型变量声明（如`Dictionary<KeyValuePair<int,string>>`）
- LINQ查询结果变量声明
- 类型名称冗长且明显，降低代码冗余

#### 约束限制
- 声明变量时**必须初始化赋值**，无默认推断
- 变量类型一经确定，**不可二次修改**
- 不能用于常量声明，常量需使用`const`+显式类型
- 不能声明委托类型、接口类型的未赋值变量
- 无初始化的构造函数内变量不可使用var

#### 最佳实践
- 类型明显且简洁时，优先使用显式类型（如`int`、`string`）
- 泛型、LINQ、匿名类型场景，推荐使用var简化代码
- 避免过度使用var导致代码可读性下降
- 团队编码规范统一，保持风格一致

### 编译器自动推断类型
#### 核心定义
- **编译器自动推断类型**：C# 编译器在编译阶段**无需显式指定类型**，通过变量赋值、表达式返回值、上下文信息**自动推导变量/返回值的真实类型**的语法能力
- 核心作用：简化代码冗余、支持匿名类型、提升编码效率，是**强类型安全前提下的语法简化**
- 本质：**编译时行为**，不改变运行时类型，不影响性能、不降低类型安全性

#### 核心特性
| 特性 | 说明 |
|------|------|
| 编译期推导 | 仅在编译时完成类型确定，生成IL代码时替换为真实类型 |
| 强类型保留 | 推断后类型固定，不可修改，不丢失类型检查 |
| 上下文依赖 | 依靠赋值、返回值、调用上下文完成推断 |
| 非动态解析 | 与`dynamic`运行时解析完全隔离，无运行时类型开销 |
| 多场景支持 | 支持变量、返回值、泛型参数、数组等多位置类型推断 |

#### 基础语法场景
```csharp
// 1. var 局部变量推断（最常用）
var 变量名 = 初始化值;

// 2. 方法返回值推断（C# 7.0+）
T 方法名<T>(T 参数) => 表达式;

// 3. 数组类型推断
var 数组名 = new[] { 元素1, 元素2 };

// 4. 泛型方法类型参数推断
方法名(参数); // 无需显式写<T>
```

#### 完整代码示例
```csharp
void TypeInferDemo()
{
    // 变量推断
    var age = 25; // 推断 int
    var name = "test"; // 推断 string

    // 数组推断
    var nums = new[] { 1, 2, 3 }; // int[]
    var points = new[] { new { X=1, Y=2 } }; // 匿名类型数组

    // 泛型方法推断（无需写<int>）
    var result = Add(10, 20); 

    // 匿名类型（必须依赖推断）
    var user = new { Id = 1, Nick = "abc" };
}

int Add(int a, int b) => a + b;
```

#### 推断规则
- 必须具备**明确的赋值/表达式来源**，无空推断
- 优先匹配**最精确的类型**，不自动向上/向下转型
- `null` 无法直接推断类型，禁止`var x = null`
- 数组推断要求所有元素类型**完全一致**
- 泛型推断根据**方法参数类型**自动匹配泛型参数
- 匿名类型**只能通过编译器推断声明**

#### 支持使用范围
- ✅ 允许：`var`局部变量、数组类型、泛型方法参数、匿名类型
- ✅ 允许：`foreach`迭代变量、`using`变量、LINQ查询变量
- ❌ 禁止：类字段、方法参数、返回值（除泛型推导）
- ❌ 禁止：未赋值变量、多类型混合赋值、无表达式上下文

#### 与 var、dynamic 核心区别
- **编译器自动推断类型**：编译期确定，强类型安全，所有推断场景的底层机制
- **var**：依赖编译器推断，仅用于局部变量，是推断的**语法载体**
- **dynamic**：运行时解析类型，弱类型，跳过编译检查，与推断无关

#### 匿名类型推断规则
- 匿名类型无显式名称，**必须依靠编译器自动推断**
- 编译器根据对象初始化表达式生成**隐藏强类型**
- 成员名称、类型、顺序完全由初始化器决定
- 跨上下文匿名类型不兼容，仅在方法内有效

#### 泛型类型推断规则
- 调用泛型方法时，编译器根据**实参类型**自动填充泛型参数
- 无需手动写`<类型>`，简化泛型调用语法
- 多参数泛型要求所有参数类型匹配一致，无歧义
- 无法推断时必须显式指定泛型类型

#### 约束限制
- 必须有**明确的类型来源**，无上下文则推断失败
- 推断类型**不可修改**，不支持动态变更
- 不支持委托、接口无实例化推断
- 混合类型赋值（如`int`+`string`）无法推断
- 不能推断`null`、未赋值变量、无返回值表达式

#### 适用场景
- 匿名类型声明与使用（**强制依赖**）
- 简化冗长泛型类型声明
- LINQ查询表达式类型自动匹配
- 数组、集合快速初始化
- 泛型方法简化调用

### 仅支持局部变量
#### 核心定义
- **仅支持局部变量**：C# 中**`var` 隐式类型声明**、**编译器自动推断类型**的**核心使用限制**，规定类型推断与 `var` 关键字**只能用于方法/属性/表达式体内部的局部变量**，禁止用于类级别成员、方法参数等场景
- 核心作用：保障类型定义的清晰性、维护程序集元数据完整性、避免类型推断歧义导致的编译/运行时错误

#### 核心特性
| 特性 | 说明 |
|------|------|
| 作用域限制 | 仅在**局部作用域**内生效（方法体、构造函数体、`for/foreach/using` 代码块） |
| 成员禁用 | 类、结构体、接口中的**字段/属性/事件/方法**均不支持 |
| 签名禁用 | 方法参数、返回值、泛型约束、委托签名**禁止使用** |
| 安全隔离 | 局部作用域内推断不影响外部类型结构，保证类型契约稳定 |

#### 合法使用场景（局部变量）
```csharp
void ValidLocalScopeDemo()
{
    // 方法内局部变量（合法）
    var num = 100;
    var list = new List<string>();

    // for 循环局部变量（合法）
    for (var i = 0; i < 10; i++) { }

    // foreach 迭代变量（合法）
    foreach (var item in list) { }

    // using 局部变量（合法）
    using (var stream = new MemoryStream()) { }

    // 匿名类型局部变量（合法，唯一方式）
    var user = new { Id = 1, Name = "测试" };
}
```

#### 非法使用场景（非局部变量）
```csharp
class InvalidDemo
{
    // 错误1：类字段（成员变量）
    private var age = 20;

    // 错误2：属性
    public var Name { get; set; }

    // 错误3：方法参数
    public void Test(var param) { }

    // 错误4：返回值
    public var GetValue() { return 10; }

    // 错误5：常量
    const var PI = 3.14;
}
```

#### 局部变量判定规则
- 必须定义在**方法/运算符/构造函数/属性访问器**内部
- 必须属于**代码执行块作用域**，而非类型结构定义
- 局部变量仅在当前代码块内生效，作用域结束即销毁
- 编译器可通过**初始化表达式**唯一确定类型，无歧义

#### 禁止非局部使用的原因
- **类型契约必须明确**：类成员、方法签名属于公开类型契约，必须显式声明，不可依赖推断
- **元数据需求**：程序集元数据需要存储明确类型，推断类型无法持久记录
- **避免歧义**：字段/属性可能无初始值、多赋值路径，推断会产生歧义
- **编译机制**：局部变量在编译时即可确定类型，类成员需要跨程序集解析

#### 支持范围边界
- ✅ 允许：方法内局部变量、代码块内临时变量、循环变量、匿名类型变量
- ❌ 禁止：类/结构体字段、属性、方法参数、返回值、常量、接口成员
- ❌ 禁止：委托参数、泛型类型参数、静态成员、实例成员

#### 与局部函数的关系
- 局部函数内部的变量**仍属于局部变量**，支持 `var` 推断
- 局部函数本身的**参数/返回值仍禁止使用 `var`**，必须显式声明
```csharp
void OuterMethod()
{
    // 局部函数
    int LocalFunc(var input) // 错误：局部函数参数禁止 var
    {
        var result = input * 2; // 正确：局部变量
        return result;
    }
}
```

### 隐式类型数组
#### 核心定义
- **隐式类型数组**：C# 中通过`new[]`语法声明数组，**无需显式指定数组元素类型**，由编译器根据数组初始化器中的元素**自动推断出数组类型**
- 核心作用：简化数组声明语法，减少冗余类型书写，配合匿名类型实现数组创建
- 本质：**编译时类型推断**，最终生成强类型数组，与显式声明数组完全等效

#### 核心特性
| 特性 | 说明 |
|------|------|
| 自动推断 | 编译器根据初始化元素自动推导数组元素类型 |
| 强类型安全 | 推断后数组类型固定，元素必须匹配推断类型 |
| 语法简化 | 省略`new 类型[]`，仅用`new[]`完成声明 |
| 匿名类型支持 | 匿名类型只能通过隐式类型数组创建数组 |
| 编译期确定 | 运行时无性能损耗，等效于显式数组 |

#### 基础语法
```csharp
// 标准隐式类型数组语法
var 数组名 = new[] { 元素1, 元素2, 元素3, ... };
```

#### 完整代码示例
```csharp
void ImplicitArrayDemo()
{
    // 1. 基本类型隐式数组（推断为 int[]）
    var nums = new[] { 1, 2, 3, 4 };

    // 2. 字符串隐式数组（推断为 string[]）
    var names = new[] { "张三", "李四", "王五" };

    // 3. 自定义类型数组（推断为 Student[]）
    var students = new[] { new Student(), new Student() };

    // 4. 匿名类型数组（必须使用隐式数组，唯一方式）
    var users = new[]
    {
        new { Id = 1, Name = "小明" },
        new { Id = 2, Name = "小红" }
    };
}

class Student { }
```

#### 类型推断规则
- 所有元素必须为**同一类型**或可隐式转换为同一基类型
- 编译器选取**最佳公共类型**作为数组元素类型
- 元素存在隐式转换时，推断为兼容的基类型（如`int`+`double`推断为`double[]`）
- 禁止混合无隐式转换的类型（如`int`+`string`），会编译报错
- 空初始化器`new[] { }`无法推断类型，必须显式指定

#### 合法与非法场景
```csharp
// 合法：元素类型一致
var arr1 = new[] { 10, 20, 30 }; // int[]

// 合法：存在隐式数值转换
var arr2 = new[] { 1, 2.5, 3 }; // double[]

// 合法：匿名类型数组
var arr3 = new[] { new { A = 1 }, new { A = 2 } };

// 非法：无公共隐式转换类型
// var arr4 = new[] { 1, "abc", true };

// 非法：空数组无法推断
// var arr5 = new[] { };
```

#### 与显式数组对比
- **显式数组**：`int[] arr = new int[3];` 类型明确，适合需要指定类型的场景
- **隐式数组**：`var arr = new[] { 1,2,3 };` 语法简洁，适合元素类型明确的场景
- **匿名类型数组**：**仅支持隐式声明**，无显式声明方案

#### 与 var 配合使用
- 隐式类型数组**通常与`var`配合**使用，实现完全隐式声明
- 也可显式指定变量类型，仅数组使用隐式声明：
```csharp
// 变量显式 + 数组隐式（合法）
string[] names = new[] { "a", "b" };
```

#### 约束限制
- 必须提供**非空初始化器**，无元素则无法推断类型
- 元素必须存在**公共可隐式转换类型**，禁止无关联类型混合
- 不支持多维隐式数组（如`new[,]`），仅支持一维数组
- 不支持`null`作为唯一元素，无法推断类型
- 元素类型不能为指针、无值类型等特殊类型

#### 适用场景
- 快速声明元素类型明确的一维数组
- 创建**匿名类型数组**（唯一可用方式）
- 简化LINQ查询中的数组初始化
- 方法参数中传递临时数组，简化语法

## 自动实现的属性

### 简化属性声明语法
#### 核心定义
- **简化属性声明语法**：C# 提供的**自动实现属性**（Auto-Implemented Properties）语法，无需手动定义私有后备字段，由编译器**自动生成私有字段**，仅需声明`get`和`set`访问器
- 核心作用：大幅简化无逻辑属性的代码书写，无需编写冗余的`get/set`字段访问代码
- 本质：**编译时语法糖**，编译器自动生成私有后备字段和标准访问器，运行时与手动属性完全一致

#### 核心特性
| 特性 | 说明 |
|------|------|
| 自动生成字段 | 编译器隐式创建私有后备字段，无需手动定义 |
| 极简声明 | 仅保留访问器，无方法体、无字段声明 |
| 灵活访问控制 | 支持`public`/`private`/`init`等不同权限访问器 |
| 支持初始化 | 可直接在声明时赋值，无需构造函数 |
| 无性能损耗 | 编译后与手动属性等效，无额外开销 |

#### 基础语法
```csharp
// 标准自动属性
public 类型 属性名 { get; set; }

// 只读自动属性（仅get）
public 类型 属性名 { get; }

// 初始化只读属性（init，仅构造/初始化赋值）
public 类型 属性名 { get; init; }

// 带访问权限控制
public 类型 属性名 { get; private set; }
```

#### 完整代码示例
```csharp
class SimplifiedPropertyDemo
{
    // 1. 标准简化属性（最常用）
    public int Id { get; set; }

    // 2. 只读简化属性
    public string Name { get; }

    // 3. init 仅初始化赋值（不可修改）
    public int Age { get; init; }

    // 4. 私有set，外部只读
    public string Address { get; private set; }

    // 5. 声明时直接初始化
    public bool IsValid { get; set; } = true;

    // 构造函数赋值只读属性
    public SimplifiedPropertyDemo(string name)
    {
        Name = name;
    }
}
```

#### 与传统完整属性对比
```csharp
// 传统完整属性（冗余，需手动写字段）
private string _title;
public string Title
{
    get { return _title; }
    set { _title = value; }
}

// 简化属性声明（等效功能，代码极简）
public string Title { get; set; }
```

#### 访问权限规则
- `{ get; set; }`：读写权限，默认全公开
- `{ get; }`：**纯只读**，只能在构造函数或初始化时赋值
- `{ get; init; }`：**初始化只读**，对象初始化时赋值，创建后不可修改
- `{ get; private set; }`：公开读取，仅类内部可修改
- 访问修饰符必须遵循：**set 权限 ≤ get 权限**

#### 属性初始化规则
- 支持**声明时直接赋值**，无需构造函数
- 只读属性`{ get; }`可通过声明初始化或构造函数赋值
- `init`属性可在**对象初始化器**中赋值
- 初始化值会直接赋值给编译器生成的后备字段
```csharp
// 声明初始化
public int Score { get; set; } = 100;

// 对象初始化器赋值（init 专用）
var demo = new SimplifiedPropertyDemo { Age = 18 };
```

#### 适用场景
- 无额外逻辑（验证、计算、通知）的简单属性
- 数据模型、实体类、DTO 数据传输对象
- 快速定义类的公开数据成员
- 配合对象初始化器简化对象创建

#### 约束限制
- 仅适用于**无自定义逻辑**的属性，不能添加`get/set`方法体
- 无法在访问器中实现数据验证、触发事件、格式转换等逻辑
- 编译器生成的后备字段**无法直接访问**，只能通过属性操作
- 静态属性同样支持简化声明语法
- 接口中的属性仅声明访问器，不属于自动实现属性

#### 适用版本
- C# 3.0+ 支持基础自动属性`{ get; set; }`
- C# 6.0+ 支持只读自动属性`{ get; }`和直接初始化
- C# 9.0+ 支持`init`仅初始化访问器

### 自动生成私有支持字段
#### 核心定义
- **自动生成私有支持字段**：C# 编译器为**自动实现属性**（简化属性）在编译阶段**隐式创建的私有后备字段**，开发者无需手动声明字段，由编译器自动命名、生成并封装
- 核心作用：替代手动编写的私有字段，实现属性的底层数据存储，是简化属性声明的核心支撑机制
- 本质：**编译期语法糖**，仅存在于编译后的 IL 代码中，源代码层面不可见

#### 核心特性
| 特性 | 说明 |
|------|------|
| 隐式创建 | 无需手动编写`private`字段，编译器自动生成 |
| 私有封装 | 生成的字段为**私有（private）**，外部绝对无法访问 |
| 自动命名 | 编译器使用**不可重名的特殊命名规则**（如`<Name>k__BackingField`） |
| 完全托管 | 字段的读写完全由属性`get/set`访问器控制 |
| 无缝等效 | 功能与手动声明的私有支持字段完全一致 |

#### 基础语法对应
```csharp
// 简化属性（源代码）
public string Name { get; set; }

// 编译器自动生成的等效代码（后台逻辑）
private string <Name>k__BackingField;
public string Name
{
    get { return <Name>k__BackingField; }
    set { <Name>k__BackingField = value; }
}
```

#### 生成规则
- 一个自动属性**对应生成一个私有支持字段**
- 字段名称使用**特殊符号命名**，无法在源代码中重复定义，避免冲突
- 字段的**类型与属性类型完全一致**
- 静态属性自动生成**静态私有字段**，实例属性生成实例字段
- 声明时赋值的属性，编译器会将初始值直接赋值给生成字段

#### 访问限制规则
- 自动生成的支持字段**仅能通过属性访问器访问**
- 源代码中**无法直接调用、修改、获取该字段**
- 不支持反射外的任何直接操作，保证封装安全性
- 私有访问级别确保字段不可被外部程序集、子类访问

#### 与手动声明字段对比
```csharp
// 手动声明支持字段（传统写法）
private int _age;
public int Age
{
    get => _age;
    set => _age = value;
}

// 自动生成支持字段（简化写法）
public int Age { get; set; }
```
- 功能完全等效
- 自动生成无需维护字段名称、避免拼写错误
- 手动声明支持自定义逻辑，自动生成仅用于无逻辑属性

#### 适用场景
- 自动实现属性（简化属性）的默认存储机制
- 数据模型、DTO、实体类的无逻辑属性
- 只读属性、init 属性、私有 set 属性的底层存储
- 所有无需自定义`get/set`逻辑的属性场景

#### 约束限制
- 仅为**自动实现属性**生成，带方法体的自定义属性不会生成
- 生成的字段**不可在源代码中直接使用**
- 无法修改字段名称、访问级别、特性标记
- 不能通过字段触发通知、验证等逻辑，必须手动声明字段
- 调试时可通过局部变量窗口查看编译器生成的字段名称

#### 与特性、初始化的关系
- 特性标记在**属性上**，不会自动应用到生成字段
- 属性初始化器`= 值`直接赋值给自动生成字段
- 构造函数为属性赋值，本质是赋值给编译器生成的支持字段
- 只读自动属性的字段为**只读字段**，确保不可变

### 只读/读写自动属性
#### 核心定义
- **只读/读写自动属性**：C# 自动实现属性的两种核心访问权限形态，通过配置 `get`/`set`/`init` 访问器，实现**可读写**或**只读不可改**的属性控制，编译器自动生成私有支持字段
- 核心作用：快速定义数据的读写权限，无需手动编写字段和访问体，兼顾封装性与简洁性
- 本质：基于**自动属性语法糖**的权限控制，编译后生成标准强类型属性

#### 核心特性
| 特性 | 说明 |
|------|------|
| 语法极简 | 无后备字段、无方法体，仅声明访问器 |
| 权限明确 | 读写/只读形态清晰，符合封装原则 |
| 自动存储 | 编译器统一生成私有支持字段 |
| 赋值可控 | 只读属性限制赋值时机，读写属性自由赋值 |
| 无性能损耗 | 与手动属性完全等效 |

#### 读写自动属性
##### 定义
同时拥有 `get` 和 `set` 访问器，支持**读取 + 修改**属性值
##### 基础语法
```csharp
public 类型 属性名 { get; set; }
```
##### 赋值规则
- 任意位置可读取
- 任意位置可赋值（类内/类外均可控）
- 支持声明时初始化
##### 代码示例
```csharp
public class Demo
{
    // 读写自动属性
    public int Age { get; set; } = 18;
}

// 使用
var obj = new Demo();
obj.Age = 20; // 可读可写
```

#### 只读自动属性
##### 定义
仅拥有 `get` 访问器，**不允许外部/后期修改**，只能在**声明时**或**构造函数内**赋值
##### 基础语法
```csharp
public 类型 属性名 { get; }
```
##### 赋值规则
- 任何位置可读取
- **只能赋值两次**：声明初始化 / 构造函数赋值
- 构造函数外无法赋值（编译报错）
##### 代码示例
```csharp
public class Demo
{
    // 声明时初始化
    public string Name { get; } = "默认名";

    public Demo()
    {
        // 构造函数内可赋值
        Name = "构造函数赋值";
    }

    public void Test()
    {
        // Name = "修改"; ❌ 编译错误
    }
}
```

#### 初始化只读属性（`init`）
##### 定义
C# 9.0 新增，仅 `get + init`，允许**对象初始化器赋值**，创建后永久只读
##### 基础语法
```csharp
public 类型 属性名 { get; init; }
```
#### 赋值规则
- 可在声明时初始化
- 可在**对象初始化器**赋值
- 创建完成后**永久不可修改**
##### 代码示例
```csharp
public class Demo
{
    public int Id { get; init; }
}

// 使用
var obj = new Demo { Id = 100 }; // ✅ 允许
// obj.Id = 200; ❌ 禁止
```

#### 私有设置读写属性
##### 定义
公开读取，仅**类内部可修改**，外部只读
##### 基础语法
```csharp
public 类型 属性名 { get; private set; }
```
##### 赋值规则
- 外部可读不可写
- 类内部可自由赋值
##### 代码示例
```csharp
public class Demo
{
    public int Status { get; private set; }

    public void SetStatus(int value)
    {
        Status = value; // ✅ 允许
    }
}
```

#### 权限对比表
| 属性类型 | 访问器 | 外部读取 | 外部修改 | 类内修改 | 赋值时机 |
|---------|--------|----------|----------|----------|----------|
| 读写自动属性 | get; set; | ✅ | ✅ | ✅ | 任意 |
| 只读自动属性 | get; | ✅ | ❌ | ✅ | 声明/构造 |
| init 只读属性 | get; init; | ✅ | ❌ | ✅ | 声明/初始化器 |
| 私有 set 属性 | get; private set; | ✅ | ❌ | ✅ | 类内任意 |

#### 赋值规则总结
- 读写自动属性：**任意赋值**
- 只读自动属性：**仅构造/声明赋值**
- `init` 自动属性：**仅初始化器/声明赋值**
- 私有 set 属性：**仅类内可赋值**

#### 约束限制
- 自动属性**不允许自定义访问体逻辑**
- 只读属性不能添加 `set`
- `init` 访问器**C# 9.0+ 才可使用**
- 声明后类型固定，不可动态变更

#### 适用场景
- 读写自动属性：通用数据模型、DTO、配置项
- 只读自动属性：不可变字段、标识、名称
- `init` 只读属性：不可变对象、记录类型、初始化赋值
- 私有 set 属性：安全状态、内部可控字段

## 匿名类型
### 无需定义类即可创建对象
#### 核心定义
- **匿名类型**：C# 中无需手动编写`class`类定义，直接通过**对象初始化器**临时创建的**只读类型对象**
- 核心作用：快速封装临时数据集合，无需维护单独类文件，用于临时数据传递、临时数据封装
- 本质：编译器在编译时**自动生成名称隐藏的密封类**，属性为只读，无手动定义成本

#### 核心特性
| 特性 | 说明 |
|------|------|
| 免类定义 | 无需声明class、无需写构造函数/属性，直接创建对象 |
| 只读属性 | 所有属性自动为**只读**，创建后不可修改 |
| 编译器生成 | 编译时自动生成密封类，隐藏名称不可显式调用 |
| 局部使用 | 仅在当前方法/局部作用域内使用 |
| 强类型安全 | 依旧是强类型，只是类型名称由编译器生成 |

#### 基础语法
```csharp
// 直接创建匿名对象，无需定义类
var 变量名 = new { 属性名1 = 值1, 属性名2 = 值2, ... };
```

#### 完整代码示例
```csharpvoid AnonymousTypeDemo()
{
    // 直接创建对象：无需定义类，一行代码完成
    var student = new
    {
        Id = 1001,
        Name = "小明",
        Age = 18,
        IsGraduated = false
    };

    // 直接访问属性
    Console.WriteLine(student.Name);
    Console.WriteLine(student.Age);

    // 编译错误：属性是只读的，不能修改
    // student.Name = "小红";
}
```

#### 声明规则
- 属性名自定义，值可以是常量、变量、表达式
- 可嵌套其他匿名对象
- 必须配合`var`使用（无类型名称，无法显式声明）
- 属性顺序、名称、类型一致时，编译器视为**同一匿名类型**

#### 只读特性规则
- 匿名类型的所有属性**自动生成只读自动属性**
- 仅能在创建时赋值，创建后**无法修改**
- 无`set`访问器，保证数据不可变

#### 常用使用场景
- LINQ查询的`select`投影，封装临时结果
- 方法内临时数据传递，替代短生命周期类
- 临时数据绑定、测试数据快速构造
- API返回临时数据封装

#### 约束限制
- 仅支持**只读属性**，不能定义方法、事件、字段
- 无法显式指定类型，只能用`var`接收
- 不能作为方法参数、返回值类型（跨作用域无效）
- 作用域仅限当前方法，无法跨方法传递使用
- 不支持继承、实现接口，编译器生成为密封类

#### 与普通类对比
- 普通类：需手动定义，支持读写、方法、继承，长期复用
- 匿名类型：无需定义，只读属性，临时使用，自动生成

### 基于对象初始化器创建
#### 核心定义
- **基于对象初始化器创建**：匿名类型**唯一的创建方式**，通过 `new { }` 语法结构，直接在大括号内定义属性名与属性值，**无需类定义、无需构造函数**，由编译器完成类型生成与对象实例化
- 核心定义：对象初始化器是匿名类型的载体，匿名类型依赖对象初始化器完成声明与赋值

#### 核心特性
| 特性 | 说明 |
|------|------|
| 语法载体 | 匿名类型必须通过 `new { }` 初始化器创建 |
| 即写即创 | 声明属性的同时完成对象创建 |
| 隐式生成 | 编译器根据初始化器自动生成只读属性与隐藏类 |
| 强类型匹配 | 属性名、类型、顺序决定匿名类型的唯一标识 |
| 只读赋值 | 仅能在初始化器中赋值，创建后不可修改 |

#### 基础语法
```csharp
// 匿名类型 = 对象初始化器标准格式
var 匿名对象 = new { 属性名1 = 值1, 属性名2 = 值2, ... };
```

#### 完整创建示例
```csharp
void CreateByInitializerDemo()
{
    // 直接通过对象初始化器创建匿名对象
    var product = new
    {
        Id = 10086,
        Name = "笔记本电脑",
        Price = 5999.99,
        IsAvailable = true
    };

    // 访问属性
    Console.WriteLine(product.Name);
    Console.WriteLine(product.Price);
}
```

#### 初始化器赋值规则
- 必须在 `new { }` 内部以 **键值对** 形式声明属性
- 属性名**自定义**，值可以是常量、变量、表达式、方法返回值
- 多个属性之间用**逗号分隔**，最后一个属性后逗号可省略
- 赋值同时完成**属性定义 + 类型推断 + 对象初始化**
- 所有属性在初始化器中一次性赋值，无二次修改机会

#### 简化赋值（投影初始化）
- 当变量名与属性名**完全相同时**，可省略 `属性名 = `
- 编译器自动使用**变量名作为属性名**，变量值作为属性值
```csharp
void ProjectionDemo()
{
    int id = 10;
    string title = "测试";

    // 简化写法：变量名直接作为属性名
    var model = new { id, title };

    // 等效完整写法
    // var model = new { id = id, title = title };
}
```

#### 嵌套初始化器创建
- 匿名类型支持在初始化器中**嵌套另一个匿名对象**
- 内部依然使用 `new { }` 对象初始化器
```csharp
var user = new
{
    Name = "小明",
    // 嵌套匿名对象初始化器
    Address = new { City = "北京", Street = "长安街" }
};
```

#### 与普通对象初始化器对比
- **普通类对象初始化器**：先有类定义，再初始化属性
  ```csharp
  Student student = new Student { Id = 1, Name = "小红" };
  ```
- **匿名类型初始化器**：**无类定义**，初始化器同时承担「定义类型 + 创建对象」

#### 约束限制
- 匿名类型**只能**通过对象初始化器创建，不支持 `new 类名()`
- 初始化器内**不允许编写方法、事件、索引器**，仅支持属性
- 不允许空初始化器 `new { }`，必须至少定义一个属性
- 初始化完成后，对象**不可修改**，属性只读

#### 适用场景
- LINQ 查询 `select` 投影临时数据模型
- 方法内临时数据封装、短周期数据传递
- 快速创建测试数据、API 临时返回结构
- 无需复用的轻量级数据容器

### 只读属性
#### 核心定义
- **只读属性**：匿名类型在编译器生成时，**所有属性自动实现为只读形式**，仅允许在对象初始化器中赋值，创建完成后**无法修改任何属性值**
- 本质：匿名类型会被编译为**密封类**，每个属性均只包含 `get` 访问器，不生成 `set` 或 `init` 方法

#### 核心特性
| 特性 | 说明 |
|------|------|
| 不可修改 | 对象创建后属性值固定，不能重新赋值 |
| 仅初始化赋值 | 只能在 `new { }` 初始化器中赋值一次 |
| 自动只读 | 无需手动声明，编译器默认全部设为只读 |
| 强类型安全 | 类型与值均固定，避免意外修改 |

#### 语法表现
```csharp
// 创建匿名对象（初始化时赋值）
var person = new { Name = "张三", Age = 20 };

// 读取：正常允许
string name = person.Name;

// 赋值：编译报错
// person.Name = "李四";
```

#### 赋值规则
- 仅在**对象初始化阶段**可赋值
- 构造完成后任何位置均不能修改属性
- 类内部、外部均无修改权限
- 不支持 `private set` 这类半读写形式

#### 与普通只读自动属性对比
- 普通只读属性：可在**构造函数**中赋值
- 匿名类型只读属性：**只能在初始化器**中赋值，无构造函数可用

#### 设计目的
- 保证匿名对象**不可变**，数据稳定
- 适配 LINQ 查询投影场景，避免数据被篡改
- 简化编译器生成逻辑，无需处理修改逻辑

#### 约束限制
- 匿名类型**不支持**读写属性，全部强制只读
- 无法通过任何语法在创建后修改属性
- 如需可变对象，必须使用**显式定义的类**

#### 适用场景
- LINQ 查询临时投影结果
- 方法内临时只读数据容器
- 一次性传递、无需修改的轻量级对象
- 匿名类型作为字典键、集合元素（不可变性保证哈希稳定）

### 重写Equals、GetHashCode、ToString方法
#### 核心定义
- **自动重写基方法**：C# 编译器在生成匿名类型时，**自动重写 `Equals`、`GetHashCode`、`ToString`** 三个核心方法，无需手动实现
- 核心作用：让匿名类型支持**值比较**、**哈希表存储**、**友好字符串输出**，具备完整的值类型行为
- 本质：编译器为隐藏的匿名类自动生成方法实现，基于**属性值**而非引用地址判断相等性

#### 核心特性
| 特性 | 说明 |
|------|------|
| 自动重写 | 无需任何代码，编译器默认生成三个方法 |
| 值相等性 | `Equals` 按**所有属性的值**比较，而非对象引用 |
| 哈希一致性 | `GetHashCode` 由所有属性**联合计算**，保证相等对象哈希码相同 |
| 字符串格式化 | `ToString` 自动拼接所有属性名与值 |
| 类型匹配 | 只有**属性名、类型、顺序完全一致**才视为同一匿名类型 |

#### Equals 方法重写规则
- 两个匿名对象**属性数量、名称、类型、顺序完全一致** → 视为**同一类型**
- 同一类型下**所有属性值都相等** → `Equals` 返回 `true`
- 不同匿名类型（属性/名称不同）→ 直接返回 `false`
- 相比默认引用比较，更符合**临时数据容器**的使用预期

#### GetHashCode 方法重写规则
- 哈希码由**所有属性的哈希值联合计算**生成
- 只要两个对象`Equals`相等，`GetHashCode`**一定相等**
- 支持匿名对象作为 **Dictionary 键、HashSet 元素**
- 匿名对象不可变 → 哈希码永久稳定

#### ToString 方法重写规则
- 自动格式化为可读性字符串：`{ 属性名 = 值, 属性名 =值, ... }`
- 包含所有属性的名称与值，方便调试、打印、日志输出
- 无需手动拼接字符串，开箱即用

#### 完整代码示例
```csharp
void OverrideMethodDemo()
{
    // 两个匿名对象：属性名、类型、值完全相同
    var a = new { Id = 1, Name = "小明" };
    var b = new { Id = 1, Name = "小明" };

    // 1. Equals 比较：值相等 → true
    bool isEqual = a.Equals(b); // true

    // 2. GetHashCode：相等对象哈希码一致
    bool sameHash = a.GetHashCode() == b.GetHashCode(); // true

    // 3. ToString 自动格式化输出
    Console.WriteLine(a.ToString()); 
    // 输出：{ Id = 1, Name = 小明 }
}
```

#### 匿名类型相等判断逻辑
1. 检查是否为**同一个匿名类型**（属性名、类型、顺序必须完全匹配）
2. 逐一比较**每个属性的值是否相等**
3. 全部相等 → 相等；任意不等 → 不等

#### 与默认对象方法对比
- **默认对象方法**：比较引用地址、哈希基于引用、ToString 显示类型名称
- **匿名类型重写后**：比较属性值、哈希基于属性值、ToString 显示数据内容

#### 约束限制
- 方法实现由编译器生成，**无法自定义修改**
- 仅匿名类型自动重写，普通类需手动重写
- 匿名对象属性必须全部**可计算哈希**（值类型/字符串等）

#### 适用场景
- 匿名对象用于 **LINQ 分组、去重、连接**
- 作为 **Dictionary / HashSet** 集合的键
- 需要**值比较**而非引用比较的临时数据
- 调试时快速查看对象属性内容
