# C++ 联合体（Union）与 POD 类型
## 联合体 Union
### 定义与本质
- 特殊聚合数据类型，所有成员共享同一段内存
- 同一时刻仅能激活一个成员
- 内存大小 = 最大成员的内存大小
- 核心用途：内存复用、类型变体存储

### C++98 传统联合体
**限制条件**

1. 仅支持 **POD 类型** 成员
2. 无自定义构造/析构函数
3. 无拷贝/移动构造/赋值函数
4. 无虚函数、无虚基类
5. 无非 POD 嵌套成员

**合法代码**

```cpp
union Data {
    int num;
    char ch;
    double val;
};
```

**非法代码**

```cpp
union Data {
    int num;
    string str; // 错误：非POD类型
};
```

**基础使用**

```cpp
Data d;
d.num = 100;
d.ch = 'A';
```

### C++11 扩展联合体
**核心特性**

1. 支持任意类型：string、vector、自定义类、带虚函数类
2. 编译器**不自动生成**：构造/析构/拷贝/移动函数
3. 非 POD 成员必须手动：**定位 new 构造**、**显式析构**
4. 可自定义特殊成员函数
5. 内存复用规则不变

**定位 new 语法**

```cpp
new(&成员变量) 类型(构造参数);
```

**显式析构语法**

```cpp
成员变量.~类型名();
```

**含 string 示例**

```cpp
union MyUnion {
    int i;
    string s;
    MyUnion() { new(&s) string(); }
    ~MyUnion() { s.~string(); }
};
```

**含 vector 示例**

```cpp
union VecUnion {
    int a;
    vector<int> v;
    VecUnion() { new(&v) vector<int>(); }
    ~VecUnion() { v.~vector(); }
};
```

**含自定义类示例**

```cpp
class Test {
public:
    Test(){}
    ~Test(){}
};
union ClassUnion {
    int x;
    Test t;
    ClassUnion() { new(&t) Test();
    }
    ~ClassUnion() {
        t.~Test();
    }
};
```

#### 成员切换规则
1. 析构当前活跃成员
2. 定位 new 构造新成员
3. 更新类型标签

```cpp
u.s.~string();
new(&u.vec) vector<int>();
```

### 带标签联合体 Tagged Union
**作用**

记录当前活跃成员，保证安全访问、安全析构

**结构**

```cpp
enum Tag { INT, STR, VEC };
struct TaggedUnion {
    Tag tag;
    union {
        int i;
        string s;
        vector<int> v;
    };
};
```

**构造函数**

```cpp
TaggedUnion() : tag(STR) { new(&s) string(); }
```

**析构函数**

```cpp
~TaggedUnion() {
    switch(tag) {
        case STR: s.~string(); break;
        case VEC: v.~vector(); break;
        default: break;
    }
}
```

**成员切换函数**

```cpp
void setInt(int x) {
    destroy();
    i = x;
    tag = INT;
}
void setStr(string t) {
    destroy();
    new(&s) string(t);
    tag = STR;
}
void destroy() {
    switch(tag) {
        case STR: s.~string(); break;
        case VEC: v.~vector(); break;
    }
}
```

### C++17 `std::variant`
**定位**

类型安全的联合体，现代 C++ 首选方案

**优势**

1. 自动管理构造/析构
2. 自动跟踪活跃类型
3. 无内存泄漏风险
4. 无需标签、无需手动析构

**基础用法**

```cpp
variant<int, string, vector<int>> var;
var = 10;
cout << get<int>(var);
var = "hello";
cout << get<string>(var);
var = vector<int>{1,2,3};
```

**常用接口**

```cpp
var.index(); // 获取当前类型索引
holds_alternative<int>(var); // 判断是否为int
get<int>(var); // 获取int值
get<0>(var); // 按索引获取
```

**错误访问**

```cpp
var = 10;
get<string>(var); // 抛异常
```

## POD 类型体系

**POD (Plain Old Data)** 是 C++ 中用于描述**内存布局简单、语义纯粹、与 C 语言完全兼容**的一类数据类型。核心在于：**可以安全地用 `memcpy`/`memset` 操作、二进制序列化、与 C 代码互通**。

### 平凡类型（Trivial）

生命周期操作（构造、拷贝、赋值、析构）**完全由编译器默认生成**，无任何自定义逻辑：

- 拥有**平凡的默认构造函数**（隐式生成或 `= default`）
- 拥有**平凡的拷贝 / 移动构造、拷贝 / 移动赋值**
- 拥有**平凡的析构函数**（不执行任何操作）
- **没有虚函数、没有虚基类**

**条件**

1. 平凡默认构造
2. 平凡析构
3. 平凡拷贝/移动构造/赋值
4. 无虚函数、无虚基类
5. 所有成员均为平凡类型

**特征**

1. 可安全逐字节拷贝
2. 无需初始化即可使用
3. memset/memcpy 安全

**判断**

```cpp
is_trivial<T>::value
is_trivial_v<T> // C++17
```

### 标准布局类型（Standard-layout）

**内存布局与 C 兼容、可预测、无编译器插入的隐藏数据（如虚表指针）**：

- 所有**非静态成员**访问权限相同（全 `public`/`private`/`protected`）
- **没有虚函数、没有虚基类**
- 继承简单：**最多一个基类含非静态成员**，且**第一个非静态成员 ≠ 基类类型**
- 所有非静态成员、基类本身都是**标准布局类型**

**条件**

1. 无虚函数、无虚基类
2. 所有成员访问权限一致
3. 符合 C 语言内存布局
4. 基类无非静态成员
5. 所有成员均为标准布局

**特征**[]()

1. 内存布局可预测
2. 可与 C 语言结构体交互
3. 偏移量固定

**判断**

```cpp
is_standard_layout<T>::value
is_standard_layout_v<T>
```

### 哪些是 POD 类型？

- 标量类型

  （天生 POD）

  - 算术类型：`bool`, `char`, `int`, `float`, `double` 等
  - 枚举类型
  - 指针、指针到成员、`nullptr_t`
  - 以上类型的 `const`/`volatile` 限定版本

- POD 类 / 结构体 / 联合体

  - 仅含 POD 成员
  - 满足平凡 + 标准布局
  - 空类 / 空结构体

- **POD 数组**（元素是 POD）

### C++98 POD 定义
1. 无自定义构造/析构/拷贝/移动
2. 无虚函数、无虚基类
3. 无继承
4. 所有成员均为 POD
5. 成员访问权限一致
6. 与 C 语言二进制兼容

### C++11 POD 拆分
```
POD = 平凡类型(Trivial) + 标准布局类型(Standard Layout)
```

### C++11 POD 类型
**条件**

同时满足：平凡类型 + 标准布局类型

**新特性**

1. 允许类内初始化
2. 允许单标准布局基类
3. 更宽松、更实用

**判断**

```cpp
is_pod<T>::value
is_pod_v<T> // C++17
```

**示例判断**

```cpp
struct A { int a; };
// is_trivial<A> = true
// is_standard_layout<A> = true
// is_pod<A> = true
struct B { B(){} int a; };
// is_trivial<B> = false
// is_pod<B> = false
struct C { virtual void f(){} };
// is_standard_layout<C> = false
```

### POD 核心用途
1. C/C++ 混合编程、跨语言交互
2. 二进制文件读写
3. 网络数据序列化
4. 内存操作：memset、memcpy
5. 底层系统开发

### C++17/20 演进
1. C++17：提供 _v 类型变量模板
2. C++20：废弃 is_pod，推荐分开判断平凡+标准布局

## 版本对比表
### 联合体对比
| 特性 | C++98 Union | C++11 Union | C++17 variant |
|------|-------------|-------------|---------------|
| 支持类型 | POD | 任意类型 | 任意类型 |
| 构造析构 | 自动 | 手动管理 | 自动管理 |
| 类型安全 | 不安全 | 需标签 | 安全 |
| 内存风险 | 低 | 高 | 无 |
| 代码复杂度 | 低 | 高 | 低 |
| 推荐度 | 低 | 中 | 高 |

### POD 版本对比
| 版本 | 规则 | 核心变化 |
|------|------|----------|
| C++98 | 严格单一定义 | 无继承、无自定义函数 |
| C++11 | 拆分为平凡+标准布局 | 更宽松、支持基类 |
| C++17 | 简化 _v 语法 | 易用性提升 |
| C++20 | 废弃 is_pod | 更精准分开判断 |
