# 函数式编程

`std::function`、`std::bind` 是 C++11 为函数式编程提供的核心工具，配合传统的**函数对象**，解决了 C++ 中 “函数作为一等公民” 的关键问题 —— 统一管理不同类型的可调用对象（函数指针、lambda、函数对象、类成员函数），并支持灵活的参数绑定与复用。

**核心背景**：可调用对象的碎片化问题

C++ 中 “可调用对象” 包含多种形式：

1. 普通函数 / 函数指针；
2. 类成员函数（需绑定`this`指针）；
3. 函数对象（重载`operator()`的类实例）；
4. Lambda 表达式（本质是匿名函数对象）。

C++11 前，不同可调用对象的类型不统一，无法用同一类型存储 / 传递；`std::function` 作为 “类型擦除” 的包装器，统一了所有可调用对象的接口；`std::bind` 则解决了参数绑定（如固定部分参数、调整参数顺序）的问题。

## 函数对象（Function Object）

函数对象（也称仿函数，Functor）是**重载了`operator()`的类 / 结构体的实例**，本质是 “行为像函数的对象”。相比普通函数，函数对象可携带状态（成员变量），支持更灵活的逻辑定制。

- **可携带状态**：通过成员变量保存上下文（如上述的`threshold`），普通函数无法做到；
- **类型明确**：每个函数对象有独立类型，可作为模板参数（如 STL 算法的谓词）；
- **可内联优化**：编译器可优化`operator()`的调用，性能优于函数指针；
- **Lambda 的本质**：C++11 的 Lambda 表达式编译后会被转换为匿名函数对象（带自动生成的类型）。

```c++
// 1. 基础函数对象：无状态（仅封装逻辑）
struct IsEven {
    // 重载operator()，行为像函数
    bool operator()(int n) const {
        return n % 2 == 0;
    }
};

// 2. 带状态的函数对象：可携带上下文
struct ThresholdFilter {
    int threshold; // 状态：阈值
    // 构造函数初始化状态
    ThresholdFilter(int t) : threshold(t) {}
    // 按阈值筛选
    bool operator()(int n) const {
        return n > threshold;
    }
};
// 使用无状态函数对象
auto it1 = find_if(vec.begin(), vec.end(), IsEven());
// 使用带状态函数对象（阈值=3）
ThresholdFilter filter(3);
auto it2 = find_if(vec.begin(), vec.end(), filter);
```

## std::function（可调用对象包装器）

`std::function` 是 C++11 提供的**类型安全的可调用对象包装器**，属于模板类（定义在`<functional>`头文件），能存储 / 调用任意符合 “签名” 的可调用对象，实现了 “类型擦除”—— 无论底层是函数指针、Lambda、函数对象，都可通过统一的`std::function`类型管理。

```c++
// 模板参数：函数签名（返回值类型(参数类型列表)）
std::function<返回值类型(参数类型1, 参数类型2, ...)> func;
```

- 若包装的是类成员函数，需将`this`指针作为第一个参数（或结合`std::bind`）；
- 空的`std::function`调用会抛出`std::bad_function_call`异常，可通过`operator bool()`判断是否有效。

**统一管理不同类型的可调用对象**

```c++
// 普通函数
int add(int a, int b) {
    return a + b;
}

// 函数对象
struct Multiply {
    int operator()(int a, int b) const {
        return a * b;
    }
};
// 定义std::function：签名为int(int, int)
function<int(int, int)> calc;
// 包装普通函数
calc = add;
// 包装函数对象
calc = Multiply();
// 包装Lambda表达式
calc = [](int a, int b) { return a - b; };
```

**包装类成员函数（需绑定 this）**

```c++
class Calculator {
public:
    int add(int a, int b) {
        return a + b;
    }
    static int multiply(int a, int b) { // 静态成员函数无需this
        return a * b;
    }
};
Calculator obj;
// 1. 包装非静态成员函数：需将this作为第一个参数
function<int(Calculator*, int, int)> mem_func = &Calculator::add;
cout << mem_func(&obj, 2, 3) << endl; // 输出：5
// 2. 包装静态成员函数：无需this，直接包装
function<int(int, int)> static_func = &Calculator::multiply;
cout << static_func(2, 3) << endl; // 输出：6
```

**作为回调函数（核心应用）**

```c++
// 注册回调函数
void set_callback(function<void(string)> cb) {
    // 触发回调
    cb("回调消息");
}
// 传递Lambda作为回调
set_callback([](string msg) {
    cout << "收到回调：" << msg << endl; // 输出：收到回调：回调消息
});
```

## std::bind（参数绑定器）

`std::bind` 是 C++11 提供的**参数绑定工具**（定义在`<functional>`），用于：

1. 固定可调用对象的部分参数（“柯里化”）；
2. 调整参数的传递顺序；
3. 绑定类成员函数的`this`指针；
4. 将多参数函数适配为少参数函数（匹配`std::function`的签名）。

```c++
// 基本形式：绑定可调用对象+参数（用std::placeholders::_N表示占位符）
auto bound_func = std::bind(可调用对象, 参数1, 参数2, ...);
```

- `std::placeholders::_1`、`_2`...：表示绑定后的函数调用时传入的第 1、2... 个参数；
- 绑定类成员函数时，第一个参数必须是`&类名::成员函数`，第二个参数是`this`指针 / 对象（值 / 引用）。

**固定部分参数（柯里化）**

```c++
// 原函数：3个参数
int calc(int a, int b, int c) {
    return a * b + c;
}
// 绑定前两个参数为2和3，第三个参数用占位符_1
auto bound_calc = bind(calc, 2, 3, placeholders::_1);
// 调用时仅需传入第三个参数
cout << bound_calc(4) << endl; // 等价于calc(2,3,4) → 输出：10
cout << bound_calc(5) << endl; // 等价于calc(2,3,5) → 输出：11
```

**调整参数顺序**

```c++
void print(int a, int b) {
    cout << "a=" << a << ", b=" << b << endl;
}
// 交换参数顺序：_2对应第一个传入参数，_1对应第二个
auto reversed_print = bind(print, placeholders::_2, placeholders::_1);
reversed_print(10, 20); // 等价于print(20,10) → 输出：a=20, b=10
```

**绑定类成员函数（核心）**

```c++
class MyClass {
public:
    int add(int a, int b) {
        return a + b;
    }
};
MyClass obj;
// 绑定成员函数+this指针，固定第一个参数为10，第二个参数用占位符
auto bound_add = bind(&MyClass::add, &obj, 10, placeholders::_1);
cout << bound_add(20) << endl; // 等价于obj.add(10,20) → 输出：30
```

**适配 `std::function` 的签名**

```c++
// 目标：std::function<int(int)> 需接收单参数函数
function<int(int)> func;
// 原函数是双参数，用bind绑定一个参数，适配签名
func = bind(add, placeholders::_1, 5); // add(a,5)
cout << func(3) << endl; // 等价于add(3,5) → 输出：8
```

**`std::bind` 的注意事项**

**占位符作用域**：`std::placeholders` 需在`std`命名空间下（或`using namespace std::placeholders;`）；

**参数生命周期**：若按值绑定对象（如`bind(&MyClass::add, obj, ...)`），需确保对象生命周期长于绑定后的函数；按引用绑定（`&obj`）需避免悬空引用；

**C++14 替代方案**：Lambda 表达式可替代大部分`std::bind`场景，语法更直观（如`auto bound = [&obj](int x) { return obj.add(10, x); }`）。

| 特性     | 函数对象（Functor）              | std::function                | std::bind                               |
| -------- | -------------------------------- | ---------------------------- | --------------------------------------- |
| 本质     | 重载`operator()`的类实例         | 可调用对象的类型擦除包装器   | 参数绑定工具（返回绑定后的可调用对象）  |
| 核心作用 | 封装可复用的函数逻辑（可带状态） | 统一管理不同类型的可调用对象 | 固定 / 调整参数，适配函数签名           |
| 类型     | 编译期确定的具体类型             | 运行时类型擦除               | 返回未指定类型的可调用对象（auto 接收） |
| 性能     | 无开销（可内联）                 | 轻微运行时开销（间接调用）   | 无额外开销（编译期处理）                |
| 灵活性   | 中等（需手动定义类）             | 高（支持所有可调用对象）     | 高（灵活绑定参数）                      |
| 典型场景 | STL 算法谓词、高性能逻辑封装     | 回调函数、统一接口           | 参数柯里化、成员函数绑定                |
