# 面向对象

## 特殊成员函数

### 六大特殊成员函数

| 函数名         | 作用                     | 作用                 |
| -------------- | ------------------------ | -------------------- |
| 默认构造函数   | `T()`                    | 创建对象时初始化     |
| 拷贝构造函数   | `T(const T&)`            | 用已有对象创建新对象 |
| 拷贝赋值运算符 | `T& operator=(const T&)` | 对象之间赋值         |
| 析构函数       | `~T()`                   | 对象销毁时释放资源   |
| 移动构造函数   | `T(T&&)`                 | 转移临时对象资源     |
| 移动赋值运算符 | `T& operator=(T&&)`      | 转移赋值临时对象资源 |

```c++
class Test
{
public:
    // 1 默认构造
    Test() = default;
    // 2 析构函数
    ~Test() = default;
    // 3 拷贝构造
    Test(const Test&) = default;
    // 4 拷贝赋值
    Test& operator=(const Test&) = default;
    // 5 移动构造
    Test(Test&&) noexcept = default;
    // 6 移动赋值
    Test& operator=(Test&&) noexcept = default;
};
```

### 编译器自动生成规则

写了**拷贝操作** → 不生成**移动操作**

写了**移动操作** → **拷贝操作被禁用**

写了**析构函数** → 不生成**移动操作**

### 浅拷贝与深拷贝

#### 浅拷贝

浅拷贝是**逐字节的位拷贝**，仅复制对象的**成员变量值**，不区分普通成员与指针成员。

- 对于**非指针普通成员**：直接复制值，两个对象拥有独立的数据副本；
- 对于指针成员：仅复制指针存储的内存地址，而非指针指向的堆内存数据。

最终结果是：多个对象的指针成员指向同一块堆内存。

浅拷贝是 C++ 的**默认拷贝行为**：编译器自动生成的**拷贝构造函数**和**赋值运算符重载函数**，均采用浅拷贝实现。

### 三五法则 / 零规则

#### 三法则（The Rule of Three）

**核心**：如果类需要**自定义析构函数、拷贝构造函数、拷贝赋值运算符**中的任意一个，就必须手动实现全部三个。

```c++
class Test {
public:
    // 1. 析构函数
    ~Test();
    // 2. 拷贝构造（深拷贝）
    Test(const Test& other);
    // 3. 拷贝赋值（深拷贝）
    Test& operator=(const Test& other);
};
```

#### 五法则（The Rule of Five）

**核心**：**三法则 + 移动构造函数 + 移动赋值运算符**。

原因：自定义拷贝 / 析构后，编译器**不会自动生成移动函数**，必须手动实现。

```c++
class Test {
public:
    // 1. 析构
    ~Test();
    // 2. 拷贝构造
    Test(const Test& other);
    // 3. 拷贝赋值
    Test& operator=(const Test& other);
    // 4. 移动构造（C++11）
    Test(Test&& other) noexcept;
    // 5. 移动赋值（C++11）
    Test& operator=(Test&& other) noexcept;
};
```

#### 零规则（The Rule of Zero）

**核心**：**不手动定义任何特殊成员函数**，全部交给编译器自动生成。

**实现方式**：使用标准库容器（`vector`/`string`/`unique_ptr`）管理资源，无需手动处理内存。
