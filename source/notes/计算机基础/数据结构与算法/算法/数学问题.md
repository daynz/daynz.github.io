# 数学问题

## 最大公约数和最小公倍数

### GCD（最大公约数）

#### 定义

两个非零整数 `a`、`b` 的最大公约数，是能同时整除 `a` 和 `b` 的最大正整数。

#### 核心算法：欧几里得算法（辗转相除法）

- **原理**：`gcd(a, b) = gcd(b, a % b)`，直到 `b = 0` 时，`a` 就是最大公约数。
- **优势**：时间复杂度 `O(log(min(a,b)))`，效率极高，是算法考试的首选。

#### 边界处理（健壮性关键）

- 负数：GCD 是正整数，需先取绝对值；
- 0 值：`gcd(a, 0) = |a|`（0 和任何数的最大公约数是该数的绝对值）；
- 溢出：用 `long long` 避免 int 运算溢出。

### LCM（最小公倍数）

#### 定义

两个非零整数 `a`、`b` 的最小公倍数，是能被 `a` 和 `b` 同时整除的最小正整数。

#### 核心公式

```c++
lcm(a, b) = abs(a * b) / gcd(a, b)
```

#### 防溢出优化（算法考试必写）

直接计算 `a*b` 容易溢出，因此改写为：`lcm(a, b) = |a| / gcd(a, b) * |b|`（先除后乘，减少溢出概率）。

#### 边界处理

- 0 值：0 和任何数的 LCM 无意义（算法题通常要求返回 0 或提前判断）；
- 溢出：全程用 `long long` 运算。

```c++
// 【核心】健壮的 GCD 实现（支持正负、0、防溢出）
long long gcd(long long a, long long b)
{
    // 步骤1：统一转为正数（GCD是正整数）
    a = llabs(a); // llabs 是 long long 版本的绝对值，避免 int 溢出
    b = llabs(b);

    // 步骤2：欧几里得算法核心逻辑
    while (b != 0)
    {
        long long remainder = a % b;
        a = b;
        b = remainder;
    }

    // 步骤3：返回结果（a=0时说明输入都是0，返回0）
    return a;
}

long long gcd(long long a, long long b) 
{
    a = llabs(a);
    b = llabs(b);
    return b == 0 ? a : gcd(b, a % b);
}

// 【核心】健壮的 LCM 实现（依赖GCD，防溢出、处理边界）
long long lcm(long long a, long long b)
{
    // 边界1：如果任一数为0，LCM无意义，返回0（算法题通用处理）
    if (a == 0 || b == 0)
    {
        return 0;
    }

    // 步骤1：先算GCD
    long long gcd_val = gcd(a, b);

    // 步骤2：先除后乘防溢出，同时取绝对值（LCM是正整数）
    return llabs(a) / gcd_val * llabs(b);
}
```
