# 树-结构实现

## 二叉树

### 一般二叉树

采用链表节点结构，是二叉树最通用的存储方式，空间利用率高，可表示任意形态二叉树。每个节点包含：

- 数据域
- 左孩子指针
- 右孩子指针

```c++
template <typename T>
class BinaryTree {
private:
	struct Node
	{
        T data;
        std::unique_ptr<Node> left;
        std::unique_ptr<Node> right;
        explicit Node(const T& val) : data(val), left(nullptr), right(nullptr) {}
        explicit Node(T&& val) : data(std::move(val)), left(nullptr), right(nullptr) {}
     };
    std::unique_ptr<Node> root;  // 根节点
    size_t node_count;           // 节点数量
};
```

### 完全二叉树

使用数组存储节点，适用于完全二叉树。

- 根节点存于下标 $0$
- **下标为 $i$ 的节点，左孩子下标为 $2i+1$，右孩子下标为 $2i+2$**
- 优点：访问速度快、结构简单
- 缺点：空间利用率低，不适用于稀疏二叉树
