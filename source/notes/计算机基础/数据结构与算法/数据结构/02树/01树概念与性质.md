# 树-概念与性质

## 二叉树

### 基本定义

其核心特征为：树中每个节点**最多包含两个子节点**，通常被称为**左子节点**与**右子节点**，且子树具有严格的左右次序，不可随意互换。

二叉树由有限个节点组成，该集合可以为空（空二叉树）；若非空，则由一个根节点及两棵互不相交的左、右子树构成，左右子树本身同样满足二叉树的定义。

### 核心术语

1. **节点（Node）**：构成二叉树的基本单元，包含数据域及指向左、右子节点的指针（或引用）。
2. **根节点（Root）**：二叉树最顶层节点，无父节点，是整棵树的起始点。
3. **父节点与子节点**：若一个节点含有子节点，则该节点为父节点，其下属节点为子节点。
4. **叶节点（Leaf Node）**：无任何子节点的节点，又称终端节点。
5. **度（Degree）**：节点拥有的子节点数量。二叉树中节点的度只能为 0、1 或 2。
6. **深度（Depth）**：从根节点到当前节点的路径层数，根节点深度通常记为 0 或 1。
7. **高度（Height）**：从当前节点到最远叶节点的最长路径层数，叶节点高度为 0 或 1。
8. **层数**：根节点为第 0 层或第 1 层，其子节点为下一层，以此类推。

### 基本性质

1. 在二叉树的第 $i$ 层上，最多有 $2i$ 个节点（约定根为第 0 层）。
2. 深度为 $k$ 的二叉树，最多包含 $2k+1−1$ 个节点。
3. 对任意一棵非空二叉树，若叶节点数为 $n_0$，度为 2 的节点数为 $n_2$，则满足 $n_0=n_2+1$。
4. 具有 $n$ 个节点的完全二叉树，其高度为 $⌊log2n⌋$。

## 完全二叉树

### 基本定义

一棵深度为 k 的二叉树，如果满足以下两个条件，则称为**完全二叉树**：

1. 除最后一层外，**其余每一层的节点数都达到最大值**（即上层是满二叉树）；
2. 最后一层的所有节点**都连续集中在最左侧**，不允许出现右节点存在而左节点空缺的情况。

### 基本性质

1. 具有 n 个节点的完全二叉树，其高度为$h=⌊log2n⌋$（根节点通常视为第 0 层或第 1 层）
2. 若对完全二叉树按**层序从左到右编号**（从 0 或 1 开始），则：
   - 下标为 i 的节点，左孩子下标为 $2i+1$
   - 右孩子下标为 $2i+2$
   - 父节点下标为 $⌊(i−1)/2⌋$
3. 叶子节点只会出现在**最后两层**，且全部靠左。
4. 度为 1 的节点**最多只有一个**，且一定只有左孩子，没有右孩子。

### 存储特点

完全二叉树**最适合使用数组（顺序存储）**：

- 空间利用率高，无冗余空位置；
- 可通过下标公式直接定位父子节点；
- 不需要指针，访问效率高。

## 二叉搜索树

**二叉搜索树（Binary Search Tree，简称 BST）**，也称作二叉排序树、二叉查找树，是一种具备有序特性的二叉树，是实现动态查找、插入与删除操作的经典数据结构。

### 定义

一棵二叉树若满足以下**有序性质**，则称为二叉搜索树：

1. 若左子树非空，则**左子树上所有节点的值均小于根节点的值**；
2. 若右子树非空，则**右子树上所有节点的值均大于根节点的值**；
3. 左、右子树本身也分别是一棵二叉搜索树；
4. 树中通常**不存在值相等的节点**（重复值可约定统一放左或右子树）。

### 核心性质

1. **中序遍历有序**：对一棵二叉搜索树执行**中序遍历**（左→根→右），得到的序列一定是**严格递增的有序序列**。(这是判断与验证 BST 最常用的依据)
2. 查找路径唯一：从根节点出发，根据 “小于则左、大于则右” 的规则，可唯一确定目标节点的查找路径。
3. 结构不唯一：同一组关键字可以构造出**多棵形态不同**的合法二叉搜索树。

### 基本操作与时间复杂度

设节点总数为 n。

#### 查找

- 从根开始比较，小于则走左子树，大于则走右子树，相等则查找成功。
- 平均时间复杂度：$O(logn)$
- 最坏时间复杂度：$O(n)$（树退化成一条链）

#### 插入

- 先按查找逻辑找到应插入的空位置；
- 新节点一定作为**叶子节点**插入。
- 复杂度同查找。

#### 删除

删除相对复杂，分三种情况：

1. 删除**叶子节点**：直接删除即可。
2. 删除**仅有一个子节点**的节点：用其子节点替代自身。
3. 删除有两个子节点的节点：
   - 找到其**前驱节点**（左子树最大值）或**后继节点**（右子树最小值）；
   - 用前驱 / 后继的值替换当前节点值，再删除前驱 / 后继节点。复杂度仍为 $O(logn)$ 平均、$O(n)$ 最坏。

## 堆

**堆（Heap）** 是一种特殊的**完全二叉树**数据结构，通常以数组形式实现，主要用于高效获取集合中的**最大值或最小值**，是实现优先队列的标准结构。

### 堆的定义与结构

堆必须满足两个条件：

1. **结构性质**

   它是一棵**完全二叉树**，节点按层序从左到右依次排列，因此可以用数组紧凑存储。

2. **堆序性质**

   - **大顶堆（最大堆）**：任意父节点的值 **≥** 其子节点的值，堆顶为全局最大值。
   - **小顶堆（最小堆）**：任意父节点的值 **≤** 其子节点的值，堆顶为全局最小值。

> 注意：堆**只保证父子关系有序，不保证兄弟节点有序**，因此堆不是二叉搜索树。

### 存储方式

堆使用**数组顺序存储**，利用完全二叉树下标关系：

- 下标从 0 开始：
  - 节点 $i$ 的左孩子：$2i + 1$
  - 节点 $i$ 的右孩子：$2i + 2$
  - 节点 $i$ 的父节点：$⌊(i − 1) / 2⌋$

这种存储方式无指针开销、访问极快。

### 核心操作

堆的关键操作是**上浮（sift up）**和**下沉（sift down）**，用于维护堆序性质。

#### 插入元素

1. 将新元素添加到数组末尾；
2. 与父节点比较，若违反堆序则交换上浮，直到满足堆序或到达堆顶。时间复杂度：$O(log n)$

#### 删除堆顶

1. 用最后一个元素替换堆顶；
2. 从堆顶开始向下调整，与较大 / 较小子节点交换，直到堆序恢复。时间复杂度：$O(log n)$

#### 建堆

将一个普通数组直接调整成堆，有两种方式：

- 逐个插入：$O (n log n)$
- 从最后一个非叶子节点向前批量下沉：$O(n)$

## 四叉树

**四叉树**（Quadtree）是一种树形数据结构，每个节点**恰好划分出四个子区域**，分别为：西北、东北、西南、东南（或左上、右上、左下、右下）。它主要用于**二维空间数据的索引、划分与检索**，是处理平面空间信息最经典的树形结构之一。

### 基本定义

一棵四叉树满足：

1. 每个节点要么是**叶子节点**，不再划分；
2. 要么是**非叶子节点**，且**严格分为四个子节点**，对应二维平面的四个象限；
3. 递归划分规则一致，子区域依然是四叉树结构。

划分方式通常按区域中心分割：

- 左上（NW）
- 右上（NE）
- 左下（SW）
- 右下（SE）

### 核心特点

- 专门用于**二维空间**（一维用二叉树，三维用八叉树）
- 空间划分自适应：密集区域细分成更多层级，稀疏区域少划分
- 天然支持**范围查询、邻近查询、碰撞检测**
- 可有效减少冗余计算，避免暴力遍历所有对象

### 常见四叉树类型

#### 点四叉树

用于存储**二维点数据**（坐标点），根据点的坐标落入哪个象限递归插入。

#### 区域四叉树

将一个**矩形区域**不断四等分，常用于图像、栅格地图、地形数据。

- 区域内数据一致则停止细分（叶子节点）
- 数据不一致则继续四等分

#### 索引线性四叉树

使用编码（如 Morton 码、四进制编码）表示层级与位置，方便存储与检索。

### 基本操作

#### 插入

根据坐标判断落入哪个象限，递归向下，直到满足停止条件（如达到最大深度、区域内点数量少于阈值）。

#### 查询

- 点查询：判断点落在哪个分支，快速定位
- 范围查询：只遍历与查询区域相交的节点
- 碰撞检测：只检查同一或相邻象限内的物体

#### 删除与更新

类似插入，定位到对应节点后修改数据，并可按需向上合并子节点（压缩空间）。

### 时间复杂度

- 构建：平均 $O(nlogn)$
- 点查询、范围查询：平均 $O(logn)$
- 最坏情况退化为 $O(n)$（极端分布）

## 八叉树

**八叉树（Octree）是用于三维空间索引与划分**的树形数据结构，可看作是四叉树在三维空间的扩展。它通过递归地将三维立方体空间等分为八个子立方体，实现对空间物体的分层管理，是计算机图形学、三维游戏、物理仿真与点云处理中的核心结构。

### 基本定义

1. 八叉树的每个非叶子节点，会将其所代表的**正方体空间**沿 X、Y、Z 三个轴切分，均匀划分为 **8 个子节点**，对应三维空间的 8 个卦限。
2. 子节点可继续细分，直到满足停止条件：
   - 达到设定的最大深度
   - 空间内物体数量少于阈值
   - 空间足够小无需再分
3. 叶子节点用于存储实际的三维物体、体素数据或空间属性。

八个子区域一般按空间方位命名，例如：

- 上、前、左
- 上、前、右
- 上、后、左
- 上、后、右
- 下、前、左
- 下、前、右
- 下、后、左
- 下、后、右

### 核心特点

- 专为**三维空间**设计（一维：二叉树，二维：四叉树，三维：八叉树）
- 自适应空间划分：物体密集处细分深，空旷处少细分
- 大幅减少三维空间的遍历与检测成本
- 天然支持空间裁剪、碰撞检测、视线剔除

### 典型分类

#### 稀疏八叉树

只存储有物体或有数据的节点，大量空节点不实际分配内存，节省空间。

#### 稠密八叉树

完整存储所有层级节点，多用于体素建模、三维网格重建。

#### 线性八叉树

使用编码（如 Morton 码、八进制位置码）表示节点路径，便于序列化存储与检索。

### 基本操作

#### 构建

从整个场景包围盒开始，递归判断是否需要切分，直到满足终止条件。

#### 插入

根据物体的三维坐标与包围盒，判断其落入哪 1～8 个子空间，递归插入对应节点。

#### 查询

- 点查询：快速定位点所在的最小叶节点
- 范围查询：只遍历与查询立方体相交的分支
- 碰撞检测：仅检测同节点或相邻节点内的物体

#### 裁剪与优化

- 空节点合并
- 动态增删后重新平衡
- 按视角动态调整细分精度（LOD）

### 时间复杂度

- 构建：平均 $O(nlogn)$
- 点查询、区域查询：平均 $O(logn)$
- 空间剔除、碰撞检测：远优于暴力遍历 $O(n^2)$
