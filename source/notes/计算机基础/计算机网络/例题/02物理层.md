## 信道极限容量

### 一、奈氏准则专项（无噪声信道的最大传输速率）

奈氏准则核心：**无噪声下，信道最大码元速率（波特率）由信道带宽决定**，数据速率（bps）需结合调制方式的“比特/码元”数（$log_2M$，$M$为调制进制数）。  
关键公式：  
- 低通信道（带宽$B$）：最大码元速率 $R_B ≤ 2B$（单位：Baud）  
- 带通信道（带宽$B$）：最大码元速率 $R_B ≤ B$（单位：Baud）  
- 数据速率 $R_b = R_B × log_2M$（单位：bps）  


#### 题目1：基础低通信道速率计算
某低通信道带宽为10kHz，无噪声干扰，若采用**2ASK调制**（二进制，$M=2$），求：  
（1）该信道的最大码元速率；  
（2）该信道的最大数据速率。  


##### 解析：
（1）低通信道符合奈氏准则“最大码元速率 = 2×带宽”：  
最大码元速率 $R_B = 2×B = 2×10kHz = 20Baud$（注：Baud是码元速率单位，1Baud表示1秒传输1个码元）。  

（2）2ASK为二进制调制，1个码元携带1比特信息（$log_22=1$）：  
最大数据速率 $R_b = R_B × log_2M = 20Baud × 1 = 20kbps$。  


#### 题目2：带通信道+多进制调制对比
某带通信道带宽为2MHz，无噪声，分别采用以下两种调制方式：  
方式1：**4PSK调制**（$M=4$，四进制相移键控）；  
方式2：**16QAM调制**（$M=16$，十六进制正交振幅调制）。  
求两种方式下的最大数据速率，并说明多进制调制的优势。  


##### 解析：
带通信道符合奈氏准则“最大码元速率 = 带宽”，即 $R_B = B = 2MHz$。  

（1）方式1（4PSK）：  
$log_24=2$（1个码元携带2比特），故数据速率：  
$R_{b1} = 2MHz × 2 = 4Mbps$。  

（2）方式2（16QAM）：  
$log_216=4$（1个码元携带4比特），故数据速率：  
$R_{b2} = 2MHz × 4 = 8Mbps$。  

（3）多进制调制优势：**在信道带宽不变时，通过提高每个码元携带的比特数，提升数据速率**（即“频带利用率”更高）。  


### 二、香农公式专项（有噪声信道的信道容量）
香农公式核心：**有噪声下，信道容量（最大数据速率）由带宽和信噪比共同决定**，与调制方式无关（仅给出理论上限）。  
关键公式：  
- 信道容量 $C = B × log_2(1 + S/N)$（单位：bps）  
- 信噪比（dB）与线性值换算：$SNR_{dB} = 10×log_{10}(S/N)$ → $S/N = 10^{(SNR_{dB}/10)}$  
（注：$S/N$是信号功率与噪声功率的比值，无单位；$SNR_{dB}$是分贝值，需先转线性值再代入公式）  


#### 题目3：基础信噪比换算+信道容量计算
某信道带宽为4kHz，已知信道的信噪比为30dB，求该信道的最大容量（香农极限）。  


##### 解析：
步骤1：将信噪比dB值转为线性值$S/N$：  
由 $SNR_{dB}=10×log_{10}(S/N)$，得 $S/N = 10^{(30/10)} = 10^3 = 1000$。  

步骤2：代入香农公式计算容量：  
$C = B × log_2(1 + S/N) = 4kHz × log_2(1+1000)$。  
因 $log_21024=10$（$2^{10}=1024$），$1001≈1024$，故 $log_21001≈10$。  
因此 $C≈4kHz × 10 = 40kbps$（精确值：$log_21001≈9.966$，$C≈39.864kbps$，通常近似为40kbps）。  


#### 题目4：信噪比与带宽的影响分析
某通信系统需实现100Mbps的信道容量，现有两种方案：  
方案1：信道带宽为20MHz，求所需的最小信噪比（以dB为单位）；  
方案2：信噪比固定为20dB，求所需的最小信道带宽。  


##### 解析：
（1）方案1（已知$C=100Mbps$，$B=20MHz$，求$SNR_{dB}$）：  
① 由香农公式变形得 $1 + S/N = 2^{(C/B)}$：  
$C/B = 100Mbps / 20MHz = 5$，故 $1 + S/N = 2^5 = 32$ → $S/N = 31$。  
② 转为dB值：$SNR_{dB} = 10×log_{10}31 ≈ 10×1.491 = 14.91dB$（最小信噪比约15dB）。  

（2）方案2（已知$C=100Mbps$，$SNR_{dB}=20dB$，求$B$）：  
① 先转$S/N$线性值：$S/N = 10^{(20/10)} = 100$ → $1 + S/N = 101$。  
② 由香农公式变形得 $B = C / log_2(1 + S/N)$：  
$log_2101≈6.658$，故 $B ≈ 100Mbps / 6.658 ≈ 15.02MHz$（最小带宽约15MHz）。  


#### 题目5：奈氏与香农的综合对比（实际速率上限）
某带通信道带宽为5MHz，信噪比为25dB，若采用**64QAM调制**（$M=64$），忽略处理延迟，求该信道的**实际最大数据速率**（提示：实际速率受奈氏准则和香农公式双重限制，取两者最小值）。  


##### 解析：
步骤1：计算奈氏准则下的最大数据速率（无噪声理论上限）：  
带通信道最大码元速率 $R_B = B = 5MHz$；  
64QAM的$log_264=6$（1个码元带6比特），故奈氏速率：  
$R_{b(奈氏)} = 5MHz × 6 = 30Mbps$。  

步骤2：计算香农公式下的信道容量（有噪声理论上限）：  
① $SNR_{dB}=25dB$ → $S/N=10^{(25/10)}=10^{2.5}≈316.23$ → $1+S/N≈317.23$。  
② 香农容量：$C = 5MHz × log_2317.23 ≈5MHz × 8.32 ≈41.6Mbps$。  

步骤3：实际最大数据速率取两者最小值：  
因有噪声时香农容量（41.6Mbps）高于奈氏速率（30Mbps），故实际速率上限为**30Mbps**（调制方式限制了速率，即使噪声允许更高容量，码元速率也无法突破奈氏上限）。  

## 调制与编码

### 一、信号调制专项（波特率与比特率、调制方式对比）

信号调制核心：**将数字信号加载到模拟载波上**，不同调制方式（ASK、FSK、PSK、QAM）的“频带利用率”不同（即单位带宽传输的比特率），核心关系是“比特率 = 波特率 × log₂M”（$M$为调制进制数）。  


#### 题目6：基础波特率与比特率换算
某通信系统采用**2FSK调制**（二进制频移键控），若码元速率（波特率）为1200Baud，求该系统的数据速率；若改为**8PSK调制**（八进制相移键控），波特率不变，数据速率变为多少？  


##### 解析：
（1）2FSK（$M=2$）：  
$log_22=1$，故数据速率 $R_b = 1200Baud × 1 = 1200bps$。  

（2）8PSK（$M=8$）：  
$log_28=3$，故数据速率 $R_b = 1200Baud × 3 = 3600bps$。  

（关键结论：相同波特率下，进制数$M$越大，数据速率越高）  


#### 题目7：QAM调制的频带利用率计算
5G NR（新空口）系统中，某频段采用**256QAM调制**，若该频段分配的信道带宽为10MHz（带通信道），求：  
（1）该调制方式下的频带利用率（单位：bps/Hz）；  
（2）该信道的最大数据速率。  


##### 解析：
（1）频带利用率定义：“单位带宽的最大数据速率”，即 $η = R_b / B$。  
256QAM的$log_2256=8$（1个码元带8比特）；带通信道的$R_B=B$，故：  
$R_b = B × 8$ → $η = (B×8)/B = 8bps/Hz$（频带利用率为8bps/Hz）。  

（2）最大数据速率：  
$R_b = B × 8 = 10MHz × 8 = 80Mbps$。  


#### 题目8：调制方式与传输距离的关联（实际应用场景）
某无线通信链路（带通信道）需在1km距离内传输5Mbps数据，信号衰减导致信噪比仅为10dB，可供选择的调制方式有**4QAM**（$M=4$）和**16QAM**（$M=16$）。已知：  
- 4QAM的接收灵敏度（最小接收功率）为-90dBm；  
- 16QAM的接收灵敏度为-85dBm（进制数越高，需更高接收功率，抗衰减能力越弱）。  
忽略其他干扰，仅考虑信号衰减（1km衰减为20dB），发射端最大输出功率为-70dBm，判断哪种调制方式可行。  


##### 解析：
步骤1：计算接收端实际功率（接收功率=发射功率-衰减）：  
接收功率 = -70dBm - 20dB = -90dBm。  

步骤2：判断两种调制方式的接收功率是否满足灵敏度要求：  
- 4QAM：接收灵敏度-90dBm，实际接收功率=-90dBm（≥灵敏度，满足要求）；  
- 16QAM：接收灵敏度-85dBm，实际接收功率=-90dBm（<灵敏度，不满足要求）。  

步骤3：验证数据速率是否达标（结合香农公式）：  
信噪比10dB → $S/N=10^{10/10}=10$ → 香农容量 $C=B×log_2(1+10)=B×log_211≈B×3.459$。  
需传输5Mbps，故所需带宽 $B≥5Mbps/3.459≈1.445MHz$（带通信道）。  
4QAM的$log_24=2$，若取$B=2MHz$（满足$B≥1.445MHz$），则$R_b=2MHz×2=4Mbps$（不足5Mbps）；取$B=3MHz$，则$R_b=3MHz×2=6Mbps$（≥5Mbps，可行）。  

结论：**仅4QAM调制方式可行**（16QAM抗衰减能力不足，接收功率不达标）。
