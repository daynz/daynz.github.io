## return default返回的内容

`return default` 会根据当前方法的**返回值类型**，返回该类型的**默认值**。

## 泛型的优缺点

- 优点
    1. **类型安全**：编译时就检查类型，避免运行时类型转换出错，减少 bug。
    2. **避免装箱拆箱**：不用把值类型转成 object，大幅减少 GC 和性能损耗，Unity 里非常关键。
    3. **代码复用**：一套逻辑支持多种类型，不用为 int、float、自定义类写重复代码。
    4. **可读性高**：代码更简洁，不用大量类型判断和强转。
    5. **通用性强**：适合写工具类、管理器、数据结构，比如对象池、列表、缓存。

- 缺点
    1. **调试复杂**：泛型报错信息有时不直观，定位问题稍麻烦。
    2. **学习成本**：约束、协变逆变、泛型方法 / 类理解起来有门槛。
    3. **反射支持弱**：泛型类型用反射时写法更繁琐。
    4. **Unity 特殊限制**：部分旧版本、序列化、热更对泛型支持有限制，不能直接序列化泛型字段。
    5. **滥用会混乱**：过度设计泛型会让逻辑晦涩，不利于团队维护。
