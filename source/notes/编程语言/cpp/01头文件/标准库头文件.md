# C++ 标准库头文件

C++ 标准库的接口由下列头文件的汇集定义。

| 头文件         | 引入 C++ 版本 | 功能说明                                                     |
| -------------- | ------------- | ------------------------------------------------------------ |
| `<cstdlib>`    | 早期标准      | 通用工具：程序控制、动态内存分配、随机数、排序等             |
| `<csignal>`    | 早期标准      | 信号管理的函数与宏常量                                       |
| `<csetjmp>`    | 早期标准      | 保存（及跳转）到执行环境的宏（与函数）                       |
| `<cstdarg>`    | 早期标准      | 变长实参列表的处理                                           |
| `<typeinfo>`   | 早期标准      | 运行时类型信息工具                                           |
| `<bitset>`     | 早期标准      | `std::bitset` 类模板                                         |
| `<functional>` | 早期标准      | 函数对象、函数调用、绑定操作及引用包装                       |
| `<cstddef>`    | 早期标准      | 标准宏与 `typedef`                                           |
| `<ctime>`      | 早期标准      | C 风格日期 / 时间工具                                        |
| `<utility>`    | 早期标准      | 多种工具组件                                                 |
| `<new>`        | 早期标准      | 低层内存管理工具                                             |
| `<memory>`     | 早期标准      | 高层内存管理工具                                             |
| `<climits>`    | 早期标准      | 整数类型的极限                                               |
| `<cfloat>`     | 早期标准      | 浮点类型的极限                                               |
| `<limits>`     | 早期标准      | 查询算术类型属性的一致方式                                   |
| `<exception>`  | 早期标准      | 异常处理工具                                                 |
| `<stdexcept>`  | 早期标准      | 标准异常对象                                                 |
| `<cassert>`    | 早期标准      | 比较其实参与零的条件编译宏                                   |
| `<cerrno>`     | 早期标准      | 含有最后一次错误号的宏                                       |
| `<cctype>`     | 早期标准      | 确定窄字符类别的函数                                         |
| `<cwctype>`    | 早期标准      | 确定宽字符的类别的函数                                       |
| `<cstring>`    | 早期标准      | 多种窄字符串处理函数                                         |
| `<cwchar>`     | 早期标准      | 多种宽与多字节字符串处理函数                                 |
| `<string>`     | 早期标准      | `std::basic_string` 类模板                                   |
| `<clocale>`    | 早期标准      | C 本地化工具                                                 |
| `<locale>`     | 早期标准      | 本地化工具                                                   |
| `<iosfwd>`     | 早期标准      | 输入 / 输出库中所有类的前置声明                              |
| `<ios>`        | 早期标准      | `std::ios_base` 类、`std::basic_ios` 类模板与数个 `typedef`  |
| `<istream>`    | 早期标准      | `std::basic_istream` 类模板与数个 `typedef`                  |
| `<ostream>`    | 早期标准      | `std::basic_ostream`、`std::basic_iostream` 类模板与数个 `typedef` |
| `<iostream>`   | 早期标准      | 数个标准流对象                                               |
| `<fstream>`    | 早期标准      | `std::basic_fstream`、`std::basic_ifstream`、`std::basic_ofstream` 类模板及数个 `typedef` |
| `<sstream>`    | 早期标准      | `std::basic_stringstream`、`std::basic_istringstream`、`std::basic_ostringstream` 类模板与数个 `typedef` |
| `<cstdio>`     | 早期标准      | C 风格输入输出函数                                           |
| `<iomanip>`    | 早期标准      | 格式化输入与输出的辅助函数                                   |
| `<streambuf>`  | 早期标准      | `std::basic_streambuf` 类模板                                |

## C++11

| 头文件                 | 引入 C++ 版本         | 功能说明                                                     |
| ---------------------- | --------------------- | ------------------------------------------------------------ |
| `<ratio>`              | C++11                 | 编译时有理数算术                                             |
| `<cfenv>`              | C++11                 | 浮点环境访问函数                                             |
| `<chrono>`             | C++11                 | C++ 时间工具                                                 |
| `<typeindex>`          | C++11                 | `std::type_index`                                            |
| `<initializer_list>`   | C++11                 | `std::initializer_list` 类模板                               |
| `<type_traits>`        | C++11                 | 编译时类型信息                                               |
| `<tuple>`              | C++11                 | `std::tuple` 类模板                                          |
| `<regex>`              | C++11                 | 支持正则表达式处理的类、算法及迭代器                         |
| `<atomic>`             | C++11                 | 原子操作库                                                   |
| `<condition_variable>` | C++11                 | 线程等待条件                                                 |
| `<thread>`             | C++11                 | `std::thread` 类与支持函数                                   |
| `<mutex>`              | C++11                 | 互斥元件                                                     |
| `<future>`             | C++11                 | 异步计算元件                                                 |
| `<random>`             | C++11                 | 随机数生成器与分布                                           |
| `<unordered_set>`      | C++11                 | `std::unordered_set` 与 `std::unordered_multiset` 无序关联容器 |
| `<unordered_map>`      | C++11                 | `std::unordered_map` 与 `std::unordered_multimap` 无序关联容器 |
| `<cuchar>`             | C++11                 | C 风格 Unicode 字符转换函数                                  |
| `<cstdint>`            | C++11                 | 定宽整数类型与其他类型的极限                                 |
| `<cinttypes>`          | C++11                 | 格式化宏、`intmax_t` 与 `uintmax_t` 数学与转换               |
| `<forward_list>`       | C++11                 | `std::forward_list` 容器                                     |
| `<codecvt>`            | C++11（C++17 中弃用） | Unicode 转换设施                                             |
| `<scoped_allocator>`   | C++11                 | 嵌套分配器类                                                 |
| `<system_error>`       | C++11                 | 定义 `std::error_code`，依赖平台的错误码                     |

| `<bit>`             | C++20         | 位操纵函数                                                  |

| `<barrier>`         | C++20         | 屏障                                                        |

| `<compare>`         | C++20         | 三路比较运算符支持                                          |
| `<version>`         | C++20         | 提供依赖实现的库信息                                        |
| `<source_location>` | C++20         | 提供获得源码位置的手段                                      |
| `<span>`            | C++20         | `std::span` 视图                                            |
