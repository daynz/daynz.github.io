# 结构化绑定

C++17 引入的**结构化绑定（Structured Bindings）** 是一种全新的变量声明语法，允许将复合类型（如结构体、数组、std::pair/tuple）的成员 / 元素直接绑定到一组变量上，无需手动解构复合类型。这一特性大幅简化了复合类型的访问代码，让代码更简洁、更具可读性，是现代 C++ 提升代码表达力的核心语法糖。

核心价值：**将复合类型的多个成员 / 元素 “解包” 为独立变量**，消除手动提取成员的冗余代码，让复合类型的访问逻辑更直观，同时保持类型安全。

## 背景

C++17 之前，访问复合类型的多个成员 / 元素需要手动声明变量并逐一赋值，代码冗余且可读性差：

1. **结构体 / 类成员访问**：需逐个提取成员，变量名与成员名重复，代码冗长；
2. **数组 / 容器元素访问**：需通过下标 / 迭代器手动赋值，逻辑分散；
3. **std::pair/tuple 访问**：需通过 `std::get<N>()` 模板函数，代码不直观且易出错。

```c++
// 1. 结构体解构冗余
struct Point { int x; int y; };
Point p{10, 20};
int x = p.x; // 手动提取
int y = p.y;
// 2. tuple 访问不直观
std::tuple<int, std::string, double> t{1, "hello", 3.14};
int a = std::get<0>(t);    // 需记住索引，易写错
std::string b = std::get<1>(t);
double c = std::get<2>(t);
// 3. 数组元素提取繁琐
int arr[3] = {1, 2, 3};
int first = arr[0];
int second = arr[1];
```

## 核心语法与基础使用

结构化绑定的基本形式为：

```c++
// 通用语法
auto [变量1, 变量2, ...] = 复合类型表达式;
// 或（指定引用/const）
const auto& [变量1, 变量2, ...] = 复合类型表达式;
auto&& [变量1, 变量2, ...] = 复合类型表达式;
```

**核心规则**：

- 绑定的变量数量必须与复合类型的成员 / 元素数量完全匹配；
- 绑定的变量是复合类型成员 / 元素的 “别名”（而非拷贝），修改绑定变量会影响原对象（除非用 `const`）；
- 支持 `auto`/`const auto`/`auto&`/`auto&&` 等类型推导。

**支持的复合类型**

结构化绑定支持三类复合类型，覆盖绝大多数常用场景：

**绑定数组**

```c++
int arr[3] = {10, 20, 30};
// 绑定数组所有元素
auto [a, b, c] = arr;
std::cout << a << ", " << b << ", " << c << std::endl; // 10, 20, 30
// 引用绑定（修改绑定变量会影响原数组）
auto& [ra, rb, rc] = arr;
ra = 100;
std::cout << arr[0] << std::endl; // 100
```

**绑定结构体 / 类（公有数据成员）**

```c++
// 绑定简单结构体
struct Person {
    std::string name;
    int age;
    double score;
};
Person p{"Alice", 25, 95.5};
// const 引用绑定（只读，避免拷贝）
const auto& [name, age, score] = p;
std::cout << name << ", " << age << ", " << score << std::endl;
// Alice,25,95.5
// 普通绑定（拷贝，修改不影响原对象）
auto [n, a, s] = p;
n = "Bob";
std::cout << p.name << std::endl; // Alice（原对象未变）
```

**绑定 std::pair/std::tuple**

```c++
// 绑定 std::pair
std::pair<std::string, int> pair1{"apple", 5};
auto [fruit, count] = pair1;
std::cout << fruit << ": " << count << std::endl; // apple: 5
std::tuple<int, std::string, bool> tuple1{100, "pass", true};
auto [id, status, is_ok] = tuple1;
std::cout << id << ", " << status << ", " << std::boolalpha << is_ok << std::endl;
// 输出：100, pass, true
```

**高级用法：绑定返回值**

结构化绑定最常用的场景之一是直接绑定函数返回的复合类型，大幅简化代码：

```c++
// 函数返回结构体
Point get_point() {
    return {100, 200};
}
// 函数返回 tuple
std::tuple<std::string, int, double> get_student_info() {
    return {"Charlie", 20, 88.8};
}
// 绑定函数返回的结构体
auto [x, y] = get_point();
std::cout << x << ", " << y << std::endl; // 100, 200
// 绑定函数返回的 tuple
auto [name, age, score] = get_student_info();
std::cout << name << ", " << age << ", " << score << std::endl; // Charlie, 20, 88.8
```

## 核心使用场景

**遍历关联容器（std::map/std::unordered_map）**

结构化绑定彻底简化了关联容器的遍历，无需通过 `first`/`second` 访问键值对：

```c++
std::map<std::string, int> score_map{
    {"math", 90},
    {"english", 85},
    {"chinese", 95}
};
// 传统遍历（繁琐）
for (const auto& pair : score_map) {
    std::cout << pair.first << ": " << pair.second << std::endl;
}
// 结构化绑定遍历（简洁）
for (const auto& [subject, score] : score_map) {
    std::cout << subject << ": " << score << std::endl;
}
```

**解构多返回值函数**

C++ 不支持原生多返回值，但可通过 `std::tuple`/ 结构体 + 结构化绑定模拟，代码更直观：

```c++
// 计算最小值、最大值、平均值
std::tuple<int, int, double> calc_stats(const std::vector<int>& nums) {
    if (nums.empty()) return {0, 0, 0.0};
    int min_val = nums[0], max_val = nums[0];
    double sum = 0.0;
    for (int num : nums) {
        min_val = std::min(min_val, num);
        max_val = std::max(max_val, num);
        sum += num;
    }
    return {min_val, max_val, sum / nums.size()};
}
std::vector<int> nums{1, 2, 3, 4, 5};
// 直接解构多返回值
auto [min, max, avg] = calc_stats(nums);
std::cout << "Min: " << min << ", Max: " << max << ", Avg: " << avg << std::endl;
// 输出：Min: 1, Max: 5, Avg: 3
```

**绑定匿名结构体 / 临时对象**

结构化绑定可直接绑定临时对象或匿名结构体，进一步简化代码：

```c++
// 绑定匿名结构体临时对象
auto [width, height] = []() -> struct { int w; int h; } {
    return {800, 600}; // 匿名结构体返回值
}();
std::cout << "Resolution: " << width << "x" << height << std::endl; // 800x600
// 绑定临时 pair
auto [key, value] = std::make_pair("temp", 123);
std::cout << key << ": " << value << std::endl; // temp: 123
```

## 核心规则与注意事项

- 关键限制

  - **私有 / 保护成员不可绑定**：结构化绑定仅支持访问**公有数据成员**，无法绑定类的私有 / 保护成员；

  - **变量数量必须匹配**：绑定的变量数必须与复合类型的成员 / 元素数完全一致（如数组有 3 个元素，必须绑定 3 个变量）；

  - **不可单独绑定部分成员**：无法只绑定复合类型的第 1、3 个成员，必须按顺序绑定全部；

  - **绑定变量不可重定义**：结构化绑定的变量是 “无名实体的别名”，无法取地址（`&name` 非法），也不能作为函数参数传递（需拷贝 / 引用）。

- 类型推导与引用

| 绑定方式            | 行为                         | 适用场景                 |
| ------------------- | ---------------------------- | ------------------------ |
| `auto [a,b]`        | 拷贝绑定，修改不影响原对象   | 小型对象、只读访问       |
| `auto& [a,b]`       | 左值引用绑定，修改影响原对象 | 大型对象、需修改原对象   |
| `const auto& [a,b]` | 常量左值引用，只读，避免拷贝 | 大型对象、只读访问       |
| `auto&& [a,b]`      | 万能引用，适配左值 / 右值    | 绑定临时对象（避免拷贝） |

- 与 C++20 的扩展

  - C++20 对结构化绑定进行了扩展，支持：

    - 绑定到类的 `std::tuple_size`/`std::tuple_element` 自定义特化（支持非公有成员）；

    - 绑定到 lambda 捕获的复合类型；

    - 忽略部分成员（用 `std::ignore`，但仍需绑定全部变量）。

# `if constexpr`

C++17 引入的**if constexpr（编译期 if）** 是模板元编程与泛型编程的里程碑特性，它能在**编译阶段**根据常量表达式条件，**选择性地编译 / 丢弃代码分支**，彻底解决了传统运行期 if 在模板中无法消除无效代码、编译报错、冗余实例化的痛点，是编译期分支控制的核心工具。

核心价值：**编译期条件分支 + 无效分支完全丢弃（不生成代码、不参与编译检查）**，替代复杂的模板特化、标签分发，让泛型代码的分支逻辑简洁、安全、高效。

## 背景

C++11/14 中，模板内使用普通**运行期 if**存在致命缺陷：

1. **全分支编译**：即使条件永远不成立，无效分支也会参与编译，直接触发语法错误；
2. **无法消除无效代码**：运行期条件无法在编译期剔除冗余逻辑，导致编译失败、代码冗余；
3. **替代方案繁琐**：只能用模板全特化 / 偏特化、标签分发实现编译期分支，代码冗长、可读性极差。

```c++
// C++14 痛点：普通if在模板中编译失败
template <typename T>
auto get_value(T t) {
    // 运行期if：两个分支都会编译！
    if constexpr (std::is_pointer_v<T>) {
        return *t;      // 若T不是指针，此行会编译报错
    } else {
        return t;
    }
}// 调用：get_value(10) → T=int，指针分支无效，但仍会编译 → 报错
```

## 核心语法与基础使用

`if constexpr` 是**编译期语句**，语法与普通 if 几乎一致，仅多了`constexpr`关键字：

```c++
if constexpr (常量表达式) {
    // 条件成立：编译此分支
} else {
    // 条件不成立：丢弃此分支（不编译、不生成代码）
}
```

**核心规则**

1. **条件必须是编译期常量**：必须能在编译阶段计算出`true/false`（如`std::is_integral_v`、`sizeof`、常量值）；
2. **无效分支完全丢弃**：不参与语法检查、不生成目标代码、不占用运行时开销；
3. **可搭配 else/else if**：支持多分支编译期判断；
4. **作用域与普通 if 一致**：分支内定义的变量仅在当前分支可见；
5. **仅适用于函数模板 / 泛型代码**：非模板代码中使用等价于普通 if（无代码丢弃效果）。

```c++
// C++17 if constexpr：完美解决编译错误
#include <type_traits>
template <typename T>
auto get_value(T t) {
    // 编译期判断：T是否为指针类型
    if constexpr (std::is_pointer_v<T>) {
        return *t;      // T是指针时才编译
    } else {
        return t;       // T非指针时才编译
    }
}
// 编译期判断类型分类
template <typename T>
void check_type(T) {
    if constexpr (std::is_integral_v<T>) {
        std::cout << "整数类型" << std::endl;
    } else if constexpr (std::is_floating_point_v<T>) {
        std::cout << "浮点类型" << std::endl;
    } else {
        std::cout << "其他类型" << std::endl;
    }
}
```

## 核心使用场景

**替代模板特化，简化泛型分支**

`if constexpr` 直接替代繁琐的模板特化，用一个函数实现多场景逻辑：

```c++
// C++14：需要2个模板特化实现相同功能
template <typename T> struct Sum { static T calc(T t) { return t; } };
template <typename T, typename... Args>
struct Sum<T, Args...> { static T calc(T t, Args... args) { return t + Sum<Args...>::calc(args...); } };
// C++17：if constexpr + 折叠表达式，单行搞定
template <typename... Args>
auto sum(Args... args) {
    if constexpr (sizeof...(args) == 0) {
        return 0; // 空参数包：返回0
    } else {
        return (args + ...); // 非空：折叠求和
    }
}
std::cout << sum() << std::endl;      // 0
std::cout << sum(1,2,3) << std::endl; // 6
```

**编译期容器 / 类型适配**

根据类型特性，编译期选择不同的操作逻辑：

```c++
// 通用打印函数：支持容器/普通值
template <typename T>
void print(T t) {
    // 编译期判断：T是否支持迭代（是否为容器）
    if constexpr (requires { t.begin(); t.end(); }) {
        for (auto& x : t) std::cout << x << " ";
    } else {
        std::cout << t;
    }
    std::cout << std::endl;
}
print(10);                // 普通值：10
print(std::vector<int>{1,2,3}); // 容器：1 2 3
```

**编译期安全的类型转换**

```c++
// 编译期判断是否可转换，避免运行时错误
template <typename To, typename From>
To safe_cast(From from) {
    if constexpr (std::is_convertible_v<From, To>) {
        return static_cast<To>(from);
    } else {
        // 无效分支直接丢弃，无编译错误
        return To{};
    }
}
```

**结合折叠表达式，极致简化可变参数**

```c++
// 批量打印：空参数包/非空参数包分支处理
template <typename... Args>
void print_all(Args... args) {
    if constexpr (sizeof...(args) == 0) {
        std::cout << "无参数" << std::endl;
    } else {
        (std::cout << ... << args) << std::endl;
    }
}
print_all();        // 无参数
print_all(1, "ab"); // 1ab
```

**模板元编程：编译期计算 / 断言**

```c++
// 编译期计算阶乘
constexpr long long factorial(int n) {
    if constexpr (n <= 1) {
        return 1;
    } else {
        return n * factorial(n - 1);
    }
}
// 编译期常量：factorial(5) = 120
static_assert(factorial(5) == 120, "计算错误");
```

## 核心规则与注意事项

| 特性     | if constexpr                | 普通 if                   |
| -------- | --------------------------- | ------------------------- |
| 执行时机 | **编译期**                  | **运行期**                |
| 无效分支 | **完全丢弃**（不编译）      | 编译 + 保留（运行时跳过） |
| 适用场景 | 模板 / 泛型代码、编译期分支 | 运行时动态条件            |
| 语法检查 | 仅检查有效分支              | 检查所有分支              |

**重要限制**

1. **非模板函数中无优化效果**：普通函数使用`if constexpr`等价于普通 if，不会丢弃代码；
2. **条件必须是常量表达式**：不能使用运行时变量（如函数参数、全局变量）；
3. **跨分支变量不可共享**：无效分支中定义的变量，在其他分支中无法访问；
4. **不能替代运行时逻辑**：动态条件（如用户输入）必须用普通 if。

# 折叠表达式

C++17 引入的**折叠表达式（Fold Expressions）** 是可变参数模板（Variadic Templates）的革命性增强，允许以简洁的语法对参数包（Parameter Pack）执行 “折叠” 运算（如求和、求积、逻辑与 / 或）。这一特性彻底解决了 C++11/14 中可变参数模板需递归展开、代码冗长且易出错的问题，让泛型编程中对参数包的批量操作变得直观、高效。

核心价值：**将可变参数包的递归展开逻辑简化为单行表达式**，支持一元 / 二元折叠，覆盖所有常见的参数包运算场景，大幅降低可变参数模板的使用成本，提升代码可读性和性能。

## 背景

C++11 引入可变参数模板，但对参数包的操作需通过**递归模板展开**实现，存在以下痛点：

1. **代码冗余**：需编写递归函数模板 + 终止条件，逻辑分散，代码量翻倍；
2. **可读性差**：递归展开的嵌套逻辑难以理解，调试成本高；
3. **性能损耗**：递归模板实例化可能引入额外开销（虽编译器常优化）；
4. **功能受限**：复杂运算（如混合逻辑与算术运算）的递归实现极易出错。

```c++
// C++14 痛点：递归展开参数包求和
// 终止条件：无参数时返回0
template <typename T>
T sum(T val) {
    return val;
}
// 递归展开：逐个累加参数
template <typename T, typename... Args>
T sum(T first, Args... rest) {
    return first + sum(rest...);
}
// 调用：sum(1,2,3,4) → 1 + sum(2,3,4) → ... → 10
std::cout << sum(1, 2, 3, 4) << std::endl; // 10
// 问题：需编写2个函数模板，参数越多递归越深，代码冗余
```

## 核心语法与基础使用

折叠表达式针对**参数包 `...`** 设计，分为两类：

| 折叠类型 | 语法形式                                                     | 说明                     |
| -------- | ------------------------------------------------------------ | ------------------------ |
| 一元折叠 | `(包名 运算符 ...)` 或 `(... 运算符 包名)`                   | 仅参数包 + 运算符        |
| 二元折叠 | `(包名 运算符 ... 运算符 初始值)` 或 `(初始值 运算符 ... 运算符 包名)` | 参数包 + 运算符 + 初始值 |

**核心规则**：

- 运算符需满足**结合律**（如 `+`/`*`/`&&`/`||`/`,` 等）；
- 一元折叠要求参数包非空（否则编译错误）；
- 二元折叠支持空参数包（使用初始值）；
- 折叠表达式可直接作为表达式使用（返回运算结果）。

### 一元折叠（无初始值）

适用于参数包非空的场景，分为**左折叠**和**右折叠**（多数运算符下结果一致，如 `+`/`*`）：

```c++
// 一元左折叠：( ( (1 + 2) + 3 ) + 4 )
template <typename... Args>
auto sum_left(Args... args) {
    return (args + ...); // 等价于：(... + args)（+是交换律）
}
// 一元右折叠：( 1 + ( 2 + ( 3 + 4 ) ) )
template <typename... Args>
auto sum_right(Args... args) {
    return (... + args);
}
// 一元折叠：逻辑与（所有参数为true才返回true）
template <typename... Args>
bool all_true(Args... args) {
    return (... && args); // 左折叠/右折叠结果一致
}
std::cout << sum_left(1, 2, 3, 4) << std::endl;  // 10
std::cout << sum_right(1, 2, 3, 4) << std::endl; // 10
std::cout << std::boolalpha << all_true(true, true, false) << std::endl; // false
```

### 二元折叠（带初始值）

支持空参数包，通过初始值兜底，是更通用的场景：

```c++
// 二元左折叠：求和（空参数包返回0）
template <typename... Args>
auto sum_with_init(Args... args) {
    // ( ( (0 + 1) + 2 ) + 3 ) → 6
    return (args + ... + 0); 
}
// 二元右折叠：字符串拼接（空参数包返回空字符串）
template <typename... Args>
std::string concat(Args... args) {
    // "hello" + ( " " + ( "world" + "" ) ) → "hello world"
    return (args + ... + std::string(""));
}
    std::cout << sum_with_init() << std::endl; // 0（空参数包）
    std::cout << sum_with_init(1, 2, 3) << std::endl; // 6
    std::cout << concat("hello", " ", "world") << std::endl; // hello world
```

## 核心使用场景

**简化可变参数函数模板**

折叠表达式彻底替代递归展开，让可变参数函数模板极简：

```c++
// 场景1：批量打印参数（逗号表达式折叠）
template <typename... Args>
void print_all(Args... args) {
    // 逐个打印参数，逗号表达式确保顺序执行
    (std::cout << ... << args) << std::endl;
    // 等价于：std::cout << args1 << args2 << ... << argsN << std::endl;
}
// 场景2：参数包求最大值（二元折叠）
template <typename T, typename... Args>
T max_val(T first, Args... args) {
    // 初始值为first，逐个比较取最大值
    return (first > ... > args) ? first : (... > args ? ... : args);
    // 简化版（C++17）：return (std::max({first, args...}));
}
// 场景3：参数包累加至容器
template <typename Container, typename... Args>
void push_all(Container& c, Args... args) {
    // 逐个调用push_back，逗号表达式折叠
    (c.push_back(args), ...);
}
print_all(1, "hello", 3.14, true); // 1hello3.14true
std::cout << max_val(5, 2, 8, 3) << std::endl; // 8
std::vector<int> vec;
push_all(vec, 1, 2, 3, 4);
for (int num : vec) { std::cout << num << " "; } // 1 2 3 4
```

**类模板中的参数包处理**

折叠表达式可用于类模板的静态断言、成员初始化等场景：

```c++
// 检查所有模板参数是否为整数类型
template <typename... Args>
struct AllIntegral {
    // 静态断言：所有参数都是整数类型
    static constexpr bool value = (... && std::is_integral_v<Args>);
};
// 检查：int、long是整数，double不是
static_assert(AllIntegral<int, long>::value, "Not all integral"); // 通过
// static_assert(AllIntegral<int, double>::value, "Not all integral"); // 编译错误
std::cout << AllIntegral<int, char>::value << std::endl; // 1（true）
```

**与 lambda 结合的灵活运算**

折叠表达式可嵌套在 lambda 中，实现更灵活的参数包运算：

```c++
// 通用参数包运算器
template <typename Op, typename... Args>
auto fold_with_op(Op op, Args... args) {
    return (op(args, ...));
}
// 自定义求和运算
auto sum_op = [](auto... args) { return (args + ...); };
std::cout << fold_with_op(sum_op, 1, 2, 3) << std::endl; // 6
// 自定义乘积运算
auto mul_op = [](auto... args) { return (args * ...); };
std::cout << fold_with_op(mul_op, 2, 3, 4) << std::endl; // 24
```

**替代递归模板元编程**

折叠表达式可简化编译期计算，替代复杂的递归模板元编程：

```c++
// 编译期计算参数包的乘积（C++17 折叠表达式）
template <typename... Args>
constexpr auto product(Args... args) {
    return (args * ... * 1); // 二元折叠，空参数包返回1
}
// 编译期计算：2*3*4=24
constexpr int val = product(2, 3, 4);
static_assert(val == 24, "Product error");
std::cout << val << std::endl; // 24
```

## 核心规则与注意事项

- 关键限制与行为

  - **参数包非空（一元折叠）**：一元折叠要求参数包至少有一个参数，否则编译错误（如 `sum_left()` 会报错）；

  - 运算符结合律：
    - 左折叠 `(args + ...)`：`((a+b)+c)+d`；
    - 右折叠 `(... + args)`：`a+(b+(c+d))`；
    - 交换律运算符（`+`/`*`/`&&`/`||`）：左 / 右折叠结果一致；
    - 非交换律运算符（`-`/`/`）：左 / 右折叠结果不同（需注意顺序）。

- **逗号表达式的特殊性**：逗号运算符是左结合的，折叠时按参数顺序执行；
- **类型一致性**：运算的参数类型需支持对应的运算符（如 `+` 需重载），否则编译错误。
- **与递归展开的性能对比**

| 特性         | 折叠表达式                 | 递归展开                    |
| ------------ | -------------------------- | --------------------------- |
| 代码量       | 单行表达式，极简           | 需递归函数 + 终止条件，冗长 |
| 编译速度     | 更快（无需多次模板实例化） | 较慢（递归实例化）          |
| 运行时性能   | 相同（编译器优化后）       | 相同（编译器优化后）        |
| 可读性       | 极高（直观的运算逻辑）     | 低（嵌套递归逻辑）          |
| 空参数包支持 | 二元折叠支持               | 需额外终止条件              |
