# 一、语言核心语法

这类特性直接扩展或优化了 C++ 的基础语法规则，简化代码编写逻辑

## `auto` 与 `decltype`

### `auto`
`auto` 的核心是**让编译器根据上下文自动推导类型**，

**1. 变量类型推导 (C++11 起)**

**用法**：替代显式类型声明，编译器从初始化值推导变量类型（必须初始化）。
**示例**：

```cpp
// 基础类型推导：auto 推导为 int
auto num = 10; 
// 复杂类型推导：避免冗长的迭代器类型书写
std::vector<int> vec = {1, 2, 3};
auto it = vec.begin(); // 推导为 std::vector<int>::iterator
```
**说明**：`auto` 推导变量时会忽略顶层 `const`/`volatile`（如需保留需显式加 `const auto`）。

**2. 函数返回类型推导 (C++14 起)**

**用法**：函数返回值写 `auto`，编译器从 `return` 语句推导返回类型（无需尾随返回类型）。
**示例**：

```cpp
// auto 推导返回类型为 int（C++14 起）
auto add(int a, int b) {
    return a + b;
}
// 结合 const：推导为 const std::string
const auto get_str() {
    return std::string("hello");
}
```
**说明**：若函数有多个 `return`，所有返回值类型必须可隐式转换为同一类型。

**3. 非类型模板形参推导 (C++17 起)**

**用法**：模板非类型参数用 `auto`，编译器从实参推导参数类型，提升模板通用性。
**示例**：

```cpp
// 非类型模板参数用 auto（C++17 起）
template <auto N>
void print_num() {
    std::cout << "值：" << N << "，类型：" << typeid(N).name() << "\n";
}
print_num<10>();    // N 推导为 int，输出：值：10，类型：int
print_num<3.14>();  // N 推导为 double，输出：值：3.14，类型：double
print_num<'a'>();   // N 推导为 char，输出：值：a，类型：char
```
**说明**：替代传统的 `template <typename T, T N>` 写法，简化模板定义。

### `decltype`
`decltype` 核心是**精确获取实体/表达式的类型（含值类别）**，**编译期类型推导**，以下是关键用法：

**1. 检查实体/表达式的类型和值类别 (C++11 起)**

**用法**：`decltype(实体/表达式)` 直接返回对应类型，保留 `const`、引用等属性。
**示例**：
```cpp
int a = 10;
const int& b = a;
std::vector<int> vec = {1, 2, 3};

// 推导实体类型：decltype(a) 为 int
decltype(a) x = 20; 
// 推导实体类型：decltype(b) 为 const int&
decltype(b) y = x;  
// 推导表达式类型：vec[0] 是 int&，故 decltype(vec[0]) 为 int&
decltype(vec[0]) z = vec[1]; 

z = 100; // 修改 vec[1] 的值
std::cout << vec[1]; // 输出 100
```
**说明**：

- 若表达式是“单纯的变量名”，`decltype` 保留其原始类型；
- 若表达式是“带运算的语句”（如 `a + b`），`decltype` 推导为右值类型。

**2. 推导函数返回值类型 (C++14 起，配合 `auto`)**

**用法**：`auto func(...) -> decltype(表达式)`（C++11 尾随返回），或 `decltype(auto)`（C++14 简化），精确推导返回值类型（保留引用/const）。
**示例**：
```cpp
// 方式1：C++11 尾随返回类型（基于 decltype 推导）
template <typename T, typename U>
auto add1(T a, U b) -> decltype(a + b) {
    return a + b;
}
// add1 推导返回类型为 double（int + double）
std::cout << add1(3, 5.5) << "\n"; // 输出 8.5

// 方式2：C++14 decltype(auto)（直接推导返回值类型，保留引用）
decltype(auto) get_ref(int& x) {
    return x; // 返回 int&（而非 auto 推导的 int）
}
int num = 100;
auto& ref = get_ref(num);
ref = 200;
std::cout << num << "\n"; // 输出 200（验证返回的是引用）
```
**说明**：`decltype(auto)` 是 C++14 新增，专门用于“按表达式原样推导类型”，解决 `auto` 会丢弃引用/const 的问题。

## 尾置返回类型

```c++
// 尾置写法：返回类型在参数列表后，用->引导
auto add(int a, int b) -> int {
    return a + b;
}
```

- `auto`：作为 “占位符”，告诉编译器返回类型由后面的 `->` 部分指定；
- `-> 类型`：紧跟参数列表，明确函数的实际返回类型；
- 核心优势：**可以直接使用函数参数的类型**，这是传统写法无法做到的。

**应用**

- *返回类型依赖函数参数的类型**

比如定义一个函数，返回两个参数相加的结果，结果类型由参数类型决定

```c++
// 尾置写法：完美解决
auto add_auto(int a, double b) -> decltype(a + b) {
    return a + b;
}
// 传统写法无法直接实现（返回类型无法引用参数a/b的类型）
// 错误示例：无法在返回类型位置使用decltype(a+b)，因为a/b还未声明
// decltype(a+b) add_auto(int a, double b) { ... }
```

- **模板函数中返回类型依赖模板参数**

```c++
// 模板函数：返回两个任意类型参数的乘积
template <typename T, typename U>
auto multiply(T a, U b) -> decltype(a * b) {
    return a * b;
}
```

## 委托与继承的构造函数

### 委托构造函数

- 语法：在构造函数的初始化列表中，直接调用同类的其他构造函数（而非初始化成员变量）。

- 核心规则：
  1. 委托构造函数不能同时初始化成员变量（初始化列表只能写委托的构造函数）；
  2. 委托构造函数的函数体在被委托的构造函数执行完成后才会执行；
  3. 不能形成构造函数委托环（如 A 委托 B，B 又委托 A），否则编译报错。

```c++
class Person {
private:
    string name;
    int age;
    string addr;
public:
    // 基础构造函数（被委托的核心构造）
    Person(string n, int a, string ad) : name(n), age(a), addr(ad) {
        cout << "基础构造" << endl;
    }
    // 委托构造：无参→调用基础构造（传默认值）
    Person() : Person("unknown", 0, "unknown") {
        cout << "无参构造（委托后）" << endl;
    }
    // 委托构造：单参数→调用基础构造
    Person(string n) : Person(n, 0, "unknown") {
        cout << "带name构造（委托后）" << endl;
    }
    // 委托构造：双参数→调用基础构造
    Person(string n, int a) : Person(n, a, "unknown") {
        cout << "带name+age构造（委托后）" << endl;
    }
};
```

### 继承构造函数

- 语法：`using 基类名::基类名;`（在派生类的公有区域声明）。

- 核心规则：
  1. 继承的是基类的**所有重载构造函数**（除了拷贝 / 移动构造）；
  2. 派生类继承的构造函数会自动初始化基类部分，派生类新增的成员需通过类内初始值或其他方式初始化；
  3. 如果派生类自定义了与基类构造函数签名相同的构造函数，继承的构造函数会被覆盖（优先使用派生类自定义的）。

```c++
class Derived : public Base {
public:
    // 继承基类所有构造函数
    using Base::Base;
};
class Derived : public Base {
public:
    using Base::Base;
    // 自定义与基类单参构造签名相同的构造函数
    Derived(int x) : Base(x * 2) {
        cout << "派生类自定义构造" << endl;
    }
};
```

## 花括号或等号初始化器

C++11 引入了**统一初始化语法**（Uniform Initialization），核心是通过`{}`（花括号）或`=`结合`{}`的方式，为变量、对象、数组、容器等提供一致的初始化方式，解决了传统初始化（括号、等号混用）的语法歧义与不一致问题；而`=`初始化器则是对传统拷贝初始化的兼容与扩展。

| 初始化方式            | 语法示例                 | 适用场景                       |
| --------------------- | ------------------------ | ------------------------------ |
| 花括号初始化（直接）  | `T a{值};` / `T a={值};` | 所有类型（变量、对象、数组等） |
| 等号 + 花括号（拷贝） | `T a = {值};`            | 兼容传统写法，等价于直接花括号 |

- **核心特性与优势**
  1. **消除语法歧义**：解决了传统`()`初始化的 “最令人头痛的解析”（Most Vexing Parse）问题；
  2. **禁止窄化转换**：花括号初始化会严格检查类型转换，不允许 “不安全的窄化”（如 double→int、int→char）；
  3. **统一适用所有类型**：变量、数组、类对象、STL 容器、动态分配内存均可用`{}`初始化。

### `std::initializer_list`

当类定义了接收 `std::initializer_list` 的构造函数时，列表初始化会优先调用该构造函数（而非其他匹配的构造函数）

```c++
class MyContainer {
public:
    // 构造函数1：接收 initializer_list（列表初始化优先调用）
    MyContainer(std::initializer_list<int> list) {
        for (int val : list) {
            m_data.push_back(val);
        }
    }
    // 构造函数2：接收两个 int
    MyContainer(int a, int b) {
        m_data.push_back(a);
        m_data.push_back(b);
    }
private:
    std::vector<int> m_data;
};
MyContainer c1{1, 2}; // 优先调用 initializer_list 构造
// 若要调用两个 int 构造，需用括号初始化：
MyContainer c2(1, 2); // 调用两个 int 构造
```

- 空列表初始化的区别

- 基础类型：空列表初始化会置 0（如 `int a{};` → `a=0`）；
- 类对象：空列表初始化调用默认构造函数；

## 范围 `for`

```c++
for (元素类型 变量名 : 可迭代对象) {
    // 循环体：变量名代表当前遍历的元素
}
```

- **核心规则**：
  1. “可迭代对象” 需满足：有`begin()`/`end()`成员（或全局`begin()`/`end()`函数），且返回的迭代器支持`++`/`*`/`!=`操作；
  2. 遍历顺序：从第一个元素到最后一个元素，不可反向 / 跳步；
  3. 若需修改元素，需将 “变量名” 声明为**引用**（`&`）。

- **避免常见错误**

```c++
// 错误1：遍历临时对象（临时对象会被销毁，引用失效）
for (int& num : vector<int>{1,2,3}) { ... } // 编译报错（C++11）/未定义行为（C++17后）
// 正确：用值或const&遍历临时对象
for (const int& num : vector<int>{1,2,3}) {
    cout << num << " ";
}
// 错误2：遍历空容器（不会报错，循环体不执行）
vector<int> empty_vec;
for (int num : empty_vec) {
    cout << num; // 无输出
}
// 错误3：遍历过程中修改容器大小（如push_back/pop_back）
vector<int> vec = {1,2,3};
for (int num : vec) {
	vec.push_back(4); // 未定义行为：遍历中修改容器大小
}
```

- **遍历自定义可迭代对象**

```c++
// 自定义简单容器类
class MyContainer {
public:
    int data[5] = {10,20,30,40,50};
    // 实现begin()/end()，返回指针（指针可作为迭代器）
    int* begin() { return data; }
    int* end() { return data + 5; }
};
MyContainer mc;
// 范围for遍历自定义容器
for (int num : mc) {
    cout << num << " "; // 输出：10 20 30 40 50
}
```

## `final` 与 `override`

### `final`

- **作用**
  - 禁止类继承（加在类名后）
  - 禁止虚函数重写（加在函数后）
- **使用规则**
  1. `final` 修饰类时，类的所有成员函数（包括虚函数）都无法被派生类重写；
  2. `final` 修饰虚函数时，仅禁止该函数被重写，类仍可被继承，其他函数可正常重写；
  3. `final` 不能用于非虚函数（无意义，编译器可能警告）。

### `overrider`

- **作用**
  - 显式标记派生类中的函数是对基类虚函数的**重写**，编译器会强制检查：
    1. 基类中是否存在该签名的虚函数；
    2. 派生类函数的签名（返回值、参数、const/volatile 属性）是否与基类完全一致。若不满足，直接编译报错，避免 “意外重载而非重写” 的隐蔽错误。
- **使用规则**
  1. 仅能用于**派生类的虚函数重写**，非虚函数 / 基类函数加`override`会报错；
  2. `override` 是 “说明符”，不是函数签名的一部分，不影响函数重载；
  3. 推荐所有重写基类虚函数的场景都加`override`，强制编译器校验。

## 预置与弃置的函数

### 预置`default`

显式要求编译器**生成该函数的默认版本**，即使类中存在其他自定义构造 / 成员函数（打破 “自定义构造后编译器不生成默认构造” 的规则）。

`default` 仅能用于**编译器可自动生成的特殊成员函数**（默认构造、析构、拷贝 / 移动构造 / 赋值）

```c++
class Person {
public:
    // 自定义带参构造
    Person(string name) : name_(name) {}
    // 显式要求编译器生成默认构造函数（预置）
    Person() = default;
    string name_;
};
```

### 弃置`delete`

显式禁止编译器生成某个函数（通常是拷贝构造、赋值运算符），也可用于禁止特定重载版本的函数，比传统 “私有化且不实现” 更直观、更安全。

`delete` 可用于**任意函数**（特殊成员函数 / 普通函数），不限于编译器自动生成的函数；被 `delete` 的函数仍会参与重载决议，但选中后会直接编译报错；

```c++
class NonCopyable {
public:
    NonCopyable() = default;
    // 显式弃置拷贝构造 → 禁止拷贝
    NonCopyable(const NonCopyable&) = delete;
    // 显式弃置拷贝赋值 → 禁止赋值
    NonCopyable& operator=(const NonCopyable&) = delete;
};
```

**应用**

- 禁止类的拷贝 / 移动

```c++
// 禁止拷贝+移动的类（仅能创建/销毁，不能拷贝/赋值）
class UniqueObj {
public:
    UniqueObj() = default;
    ~UniqueObj() = default;
    // 弃置拷贝构造+赋值
    UniqueObj(const UniqueObj&) = delete;
    UniqueObj& operator=(const UniqueObj&) = delete;
    // 弃置移动构造+赋值（C++11）
    UniqueObj(UniqueObj&&) = delete;
    UniqueObj& operator=(UniqueObj&&) = delete;
};
```

- 禁止特定重载版本的函数

```c++
// 只允许int类型的print，禁止double/char等类型
void print(int a) {
    cout << "int: " << a << endl;
}
// 弃置double版本
void print(double) = delete;
// 弃置char版本
void print(char) = delete;

```

- 禁止隐式类型转换

```c++
class MyInt {
public:
    // 只允许显式构造（int→MyInt），禁止隐式转换
    explicit MyInt(int a) : val_(a) {}
    // 弃置double版本的构造 → 禁止double→MyInt（即使隐式）
    MyInt(double) = delete;
    int val_;
};
```

## 有作用域枚举

有作用域枚举（也叫强类型枚举，`enum class`/`enum struct`）是 C++11 对传统枚举（`enum`）的升级，核心解决了传统枚举的**作用域污染**、**隐式类型转换**、**底层类型不固定**三大问题，让枚举类型更安全、更规范。

- 特性
  - 作用域隔离，避免命名冲突。枚举值不再暴露到全局作用域，必须通过`枚举名::枚举值`访问
  - 禁止隐式类型转换，强类型安全。有作用域枚举的枚举值**不能直接转换为整数**，也不能与整数比较，必须显式转换
  - 显式指定底层类型，提升跨平台一致性
  - 可前置声明（传统枚举需指定底层类型才能前置声明）

```c++
// 基本语法：enum class + 枚举名 + { 枚举值 }
enum class Color { Red, Green, Blue };
// 显式指定底层类型（推荐）
enum class Fruit : int { Apple, Banana, Orange };

// 传统枚举1
enum Color { Red, Green, Blue }; // 枚举值默认从0开始：Red=0, Green=1, Blue=2
// 传统枚举2
enum Fruit { Apple, Banana, Red }; // 编译报错：Red重复定义（作用域污染）
```

| 特性     | 传统枚举（enum）     | 有作用域枚举（enum class） |
| -------- | -------------------- | -------------------------- |
| 作用域   | 枚举值暴露到全局     | 枚举值仅在枚举作用域内     |
| 类型转换 | 隐式转换为整数       | 禁止隐式转换，需显式 cast  |
| 底层类型 | 编译器自动选择       | 默认 int，可显式指定       |
| 命名冲突 | 不同枚举不能有同名值 | 支持同名值，无冲突         |
| 前置声明 | 需指定底层类型       | 可直接前置声明             |

## 类型别名

C++11 对 “类型别名” 提供了两种方式：传统的 `typedef` 和新增的 `using` 别名声明（`using =` 语法）。其中 `using` 是对 `typedef` 的升级，解决了 `typedef` 在模板场景下的语法缺陷，核心目的是为复杂类型（如指针、数组、模板）起简洁、易读的别名，提升代码可读性和维护性。

**typedef 的核心缺陷**：`typedef` 无法直接为**模板类型**起别名（需借助模板特化，语法繁琐）

| 场景              | typedef 写法           | using 写法（推荐）                            |
| ----------------- | ---------------------- | --------------------------------------------- |
| 基本类型          | `typedef int Int;`     | `using Int = int;`                            |
| 指针类型          | `typedef int* IntPtr;` | `using IntPtr = int*;`                        |
| 模板类型（C++11） | 不支持（需模板特化）   | `template<typename T> using Vec = vector<T>;` |

- **模板别名（类型别名模板）**：`using` 可直接为模板类型起别名，无需模板特化

```c++
// 为vector<T>起别名Vec<T>（模板别名）
template <typename T>
using Vec = vector<T>;

// 为map<K,V>起别名Map<K,V>
template <typename K, typename V>
using Map = map<K, V>;
```

- **简化嵌套命名空间 / 类的类型**

```c++
// 嵌套命名空间的复杂类型
namespace ns1 {
    namespace ns2 {
        class MyClass {};
    }
}

// 用using起别名，简化类型书写
using MyClass = ns1::ns2::MyClass;
```

- **与尾置返回类型配合（简化函数返回类型）**

```c++
// 复杂返回类型：vector<int>的迭代器
using VecIntIter = vector<int>::iterator;

// 尾置返回类型+别名，简化函数声明
auto getIter(vector<int>& vec) -> VecIntIter {
    return vec.begin();
}
```

| 特性                        | typedef              | using（C++11）                 |
| --------------------------- | -------------------- | ------------------------------ |
| 基本类型别名                | 支持                 | 支持（语法更直观）             |
| 复杂类型别名（指针 / 数组） | 支持（语法反直觉）   | 支持（语法更清晰）             |
| 模板别名（类型别名模板）    | 不支持（需模板特化） | 原生支持（核心优势）           |
| 可读性                      | 差（别名在末尾）     | 优（“别名 = 原类型” 符合直觉） |
| 兼容性                      | 兼容所有 C++ 版本    | C++11 及以上                   |

## 变参数模板

变参数模板是 C++11 引入的核心特性，允许模板接受**数量不确定、类型不确定**的模板参数（包括类型参数和非类型参数），彻底解决了传统模板 “参数数量固定” 的限制，是实现泛型可变参数功能（如`std::tuple`、`std::make_shared`）的基础。

**核心概念与语法**

- 变参数模板的核心是**参数包（Parameter Pack）**
- **类型参数包**：`typename... Args` / `class... Args`，表示任意数量（0 个或多个）的类型参数；
- **非类型参数包**：`T... Args`（T 为非类型类型，如 int、指针），表示任意数量的非类型参数；
- **展开参数包**：通过`...`运算符将参数包 “展开” 为单个参数，是变参数模板的核心操作。

```c++
// 1. 变参数模板函数
template <typename... Args> // Args是类型参数包
void func(Args... args) {   // args是函数参数包（与Args一一对应）
    // 展开参数包的逻辑
}

// 2. 变参数模板类
template <typename... Args>
class MyTuple {};
```

**核心使用场景与实现原理**

**变参数模板函数（递归展开）**

- （递归展开）最基础的参数包展开方式，分为两步：
  1. **递归函数**：处理参数包的第一个参数，剩余参数递归传递；
  2. **终止函数**：处理参数包为空的情况（递归出口）。

```c++
// 步骤1：终止函数（参数包为空时调用）
void print() {
    cout << "参数包展开完成" << endl;
}

// 步骤2：递归函数（处理第一个参数，剩余参数递归）
template <typename T, typename... Args>
void print(T first, Args... rest) {
    // 处理第一个参数
    cout << "参数：" << first << endl;
    // 展开剩余参数包（递归调用）
    print(rest...);//参数包展开，将rest拆分为单个参数传递给下一层递归。
}
```

**变参数模板类（递归特化）**

```c++
// 步骤1：通用变参数模板类（递归）
template <typename... Args>
class MyTuple;
// 步骤2：特化1：单个参数的情况（递归中间态）
template <typename T>
class MyTuple<T> {
public:
    T value;
    MyTuple(T v) : value(v) {}
};
// 步骤3：特化2：多个参数的情况（递归拆分）
template <typename T, typename... Args>
class MyTuple<T, Args...> : public MyTuple<Args...> {
public:
    T value;
    // 构造函数：接收第一个参数 + 剩余参数包
    MyTuple(T v, Args... rest) : MyTuple<Args...>(rest...), value(v) {}
};
// 创建包含int、double、string的元组
MyTuple<int, double, string> t(10, 3.14, "hello");
// 访问成员（需手动实现get方法，此处仅演示结构）
cout << t.value << endl; // 输出第一个参数：10
cout << static_cast<MyTuple<double, string>&>(t).value << endl; // 输出：3.14
```

**C++17 折叠表达式（简化参数包展开）**

C++17 引入**折叠表达式（Fold Expression）**，无需递归即可展开参数包，语法大幅简化，支持`+`/`*`/`,`/`&&`/`||`等运算符。

```c++
// 折叠表达式：(args + ...) 表示所有参数依次相加
template <typename... Args>
auto sum(Args... args) {
    return (args + ...); // 等价于：arg1 + arg2 + arg3 + ...
}
template <typename... Args>
void print(Args... args) {
    // 逗号表达式折叠：依次打印每个参数，最后返回0（避免空表达式）
    (cout << ... << args) << endl;
}
```

**变参数模板与 std::forward（完美转发）**

变参数模板常与`std::forward`结合，实现**完美转发**（保留参数的左值 / 右值属性），是`std::make_shared`、`std::emplace_back`的核心实现原理。

```c++
// 通用工厂函数：创建任意类型的对象，转发任意参数
template <typename T, typename... Args>
shared_ptr<T> create_obj(Args&&... args) {
    // 完美转发参数包到T的构造函数
    return make_shared<T>(std::forward<Args>(args)...);
}

class Person {
public:
    Person(string name, int age) : name_(name), age_(age) {
        cout << "Person构造：" << name_ << ", " << age_ << endl;
    }
    string name_;
    int age_;
};
// 传递左值参数
string name = "Tom";
auto p1 = create_obj<Person>(name, 18);

// 传递右值参数（临时对象）
auto p2 = create_obj<Person>("Jerry", 20);
```

**变参数模板的核心规则**

- **参数包的限制**：

  - 参数包必须是模板参数列表的**最后一个参数**（如`template <typename T, typename... Args>`合法，`template <typename... Args, typename T>`非法）；

  - 参数包可包含 0 个参数（如`print()`调用终止函数）；

- **展开时机**：参数包仅能通过`...`展开，未展开的参数包无法直接使用；

- **兼容性**：递归展开兼容 C++11/14，折叠表达式仅支持 C++17 及以上；

- **非类型参数包**：支持数值、指针、引用等非类型参数，示例：

  - ```c++
    // 非类型参数包（int类型）
    template <int... N>
    int sum_nums() {
        return (N + ...); // C++17折叠表达式
    }
    ```

## `std::tuple`元组

`std::tuple` 是 C++11 引入的通用多元组容器（定义在 `<tuple>` 头文件），能存储**任意数量、任意类型**的元素，是对传统`std::pair`（仅能存储两个元素）的扩展。它是 C++ 泛型编程的核心工具，常用于函数多返回值、异构数据聚合、模板元编程等场景。

**构造与初始化**

```c++
// 1. 直接构造（指定类型）
tuple<int, string, double> t1(10, "hello", 3.14);
// 2. 用std::make_tuple（自动推导类型，推荐）
auto t2 = make_tuple(20, "world", 6.28);
// 3. 空tuple（无元素）
tuple<> t_empty;
// 4. 列表初始化（C++11及以上）
tuple<int, bool> t3 = {100, true};
```

**元素访问：std::get（编译期索引）**

```c++
auto t = make_tuple(10, "hello", 3.14);
// 1. 按索引访问（从0开始）
cout << get<0>(t) << endl; // 输出：10（int）
cout << get<1>(t) << endl; // 输出：hello（string）
cout << get<2>(t) << endl; // 输出：3.14（double）
// 2. 按类型访问（仅当该类型唯一时可用）
cout << get<double>(t) << endl; // 输出：3.14
get<string>(t) = "hi"; // 修改元素值
// 错误示例：索引不是编译期常量
int idx = 1;
cout << get<idx>(t) << endl; // 编译报错
```

**核心操作函数**

| 函数                    | 功能                             | 示例                                           |
| ----------------------- | -------------------------------- | ---------------------------------------------- |
| `std::tuple_size`       | 编译期获取 tuple 的元素个数      | `tuple_size<decltype(t)>::value` → 3           |
| `std::tuple_element`    | 编译期获取指定索引的元素类型     | `tuple_element<1, decltype(t)>::type` → string |
| `std::swap`             | 交换两个 tuple 的内容（同类型）  | `t1.swap(t2)` 或 `swap(t1, t2)`                |
| `std::tie`              | 将变量绑定到 tuple，用于解包元素 | `tie(a, b, c) = t`                             |
| `std::forward_as_tuple` | 创建右值引用的 tuple（完美转发） | `forward_as_tuple(10, "hi")`                   |

**比较操作**

`tuple` 支持全量比较运算符（`==`/`!=`/`<`/`>`等），比较规则：

1. 按索引顺序逐个比较元素；
2. 第一个不相等的元素决定整体比较结果；
3. 仅当所有元素类型都支持对应比较运算符时可用。

**函数返回多个值（核心场景）**

传统函数返回多值需用输出参数 / 结构体，`tuple` 可直接返回异构多值，配合`tie`解包更简洁。

```c++
// 返回三个值：int、string、double
tuple<int, string, double> get_data() {
    return make_tuple(100, "test", 99.9);
}
// 方式1：tie解包
int a;
string b;
double c;
tie(a, b, c) = get_data();
cout << a << ", " << b << ", " << c << endl;
// 方式2：C++17结构化绑定（更简洁）
// auto [a, b, c] = get_data();
```

**存储异构数据集合**

替代自定义结构体，快速聚合不同类型的数据。

```c++
// 存储学生信息：学号（int）、姓名（string）、成绩（double）、是否及格（bool）
tuple<int, string, double, bool> student(101, "Tom", 85.5, true);

cout << "学号：" << get<0>(student) << endl;
cout << "姓名：" << get<1>(student) << endl;
cout << "成绩：" << get<2>(student) << endl;
cout << "是否及格：" << boolalpha << get<3>(student) << endl;
```

**与变参数模板结合（模板元编程）**

`tuple` 是变参数模板的典型应用，可配合变参数模板实现通用的元素遍历 / 处理。

```c++
// 递归遍历tuple（C++11）
// 终止函数：索引等于元素个数时停止
template <size_t Index = 0, typename... Args>
typename enable_if<Index == sizeof...(Args)>::type
print_tuple(const tuple<Args...>& t) {}

// 递归函数：打印当前索引元素，递归处理下一个
template <size_t Index = 0, typename... Args>
typename enable_if<Index < sizeof...(Args)>::type
print_tuple(const tuple<Args...>& t) {
    cout << get<Index>(t) << " ";
    print_tuple<Index + 1>(t);
}

int main() {
    auto t = make_tuple(10, "hello", 3.14, true);
    print_tuple(t); // 输出：10 hello 3.14 true
    return 0;
}
```

**与 std::pair 互转**

`tuple` 支持与`pair`相互转换（仅当`tuple`有两个元素时）：

```c++
// tuple转pair
tuple<int, string> t(1, "a");
pair<int, string> p = make_pair(get<0>(t), get<1>(t));
// C++11简化：pair<int, string> p = t;（直接赋值）
// pair转tuple
pair<double, bool> p2(3.14, true);
tuple<double, bool> t2 = p2;
cout << get<0>(t2) << ", " << get<1>(t2) << endl; // 输出：3.14, true
```

**std::tuple 进阶：C++14/C++17 扩展**

**C++14：`std::make_tuple` 支持完美转发**

`std::make_tuple` 在 C++14 中支持`std::forward`，可保留参数的左值 / 右值属性：

```c++
string s = "hello";
// 左值引用：tuple存储引用
auto t1 = make_tuple(ref(s));
get<0>(t1) = "world";
cout << s << endl; // 输出：world
// 右值引用：tuple存储临时对象
auto t2 = make_tuple(move(s));
cout << get<0>(t2) << endl; // 输出：world
cout << s << endl; // 输出空（s已被移动）
```

**C++17：结构化绑定（Structured Binding）**

C++17 引入结构化绑定，直接将`tuple`解包到变量，无需`std::tie`，语法更直观：

```c++
auto t = make_tuple(10, "hello", 3.14);
// 结构化绑定：直接定义变量接收元素
auto [a, b, c] = t;
cout << a << ", " << b << ", " << c << endl; // 输出：10, hello, 3.14
```

## `nullptr`

`nullptr` 是 C++11 引入的专门用于表示 “空指针” 的关键字，核心解决了传统 C++ 中用 `NULL`/`0` 表示空指针的**类型歧义问题**，让空指针的表达更精准、类型更安全。

在 C++11 前，程序员通常用 `NULL` 或 `0` 表示空指针，但二者存在严重的类型歧义：

- `NULL` 本质是宏定义，通常展开为 `0`（整数）或 `((void*)0)`（void 指针）；
- 在函数重载、模板推导等场景中，`0`/`NULL` 会被解析为**整数**而非指针，导致不符合预期的行为。
- `0`/`NULL` 是**整数类型**，而非指针类型，编译器优先匹配`int`重载版本，违背了 “传递空指针” 的本意。

**基本定义与类型**

- `nullptr` 是 C++11 关键字，专属表示 “空指针”，其类型为 `std::nullptr_t`（一种独立的指针类型）；
- `nullptr_t` 可隐式转换为**任意指针类型**（如`char*`、`int*`、`void*`），但**不能转换为整数类型**，彻底解决类型歧义。

| 特性         | 0（整数）                    | NULL（宏）                  | nullptr（C++11 关键字）    |
| ------------ | ---------------------------- | --------------------------- | -------------------------- |
| 类型         | int（整数）                  | 通常为 int（0）或 void*     | std::nullptr_t（指针类型） |
| 隐式转换     | 可转换为任意整数 / 指针      | 可转换为整数 / 指针（歧义） | 仅转换为指针类型（无歧义） |
| 函数重载匹配 | 优先匹配 int，不匹配指针     | 同 0（歧义）                | 仅匹配指针重载             |
| 模板推导     | 推导为 int，无法匹配指针参数 | 同 0                        | 推导为指针类型             |
| 语义         | 整数 0（非专属空指针）       | 空指针的 “妥协表示”         | 专属空指针（语义精准）     |
