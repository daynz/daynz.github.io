# `std::optional<T>`

`std::optional<T>` 是 C++17 引入的**可空（可选）值包装器**，用于表示 **“有值 / 无值”**两种状态，专门替代**指针判空、哨兵值、错误码**等不安全的 “空值” 表达方案，是现代 C++ 处理**可选返回值、可选参数 ** 的标准工具。

核心价值：**类型安全表达 “有 / 无值”，明确语义、避免空指针、消除魔数（-1、nullptr），代码可读性与安全性大幅提升**。

## 背景

传统表达 “可选值” 的方式全是缺陷：

1. **用指针**：`T* func()` → 空指针风险、内存泄漏、语义模糊；
2. **用哨兵值**：返回 `-1`/`0`/`""` 表示失败 → 易误用、语义不明确；
3. **用布尔 + 输出参数**：`bool get(T& out)` → 代码臃肿、无法链式调用。

```c++
// 传统痛点：用-1表示“无值”，极易出错
int find_index(const vector<int>& v, int target) {
    for(int i=0; i<v.size(); i++)
        if(v[i]==target) return i;
    return -1; // 魔数哨兵值
} // 调用时必须手动判断-1，忘记就越界崩溃
```

## 核心语法与基础使用

`std::optional<T>` 是一个**值类型**（不是指针），内部存储：

- 要么：一个合法的 `T` 实例（有值）
- 要么：无任何值（空状态）

它**不分配堆内存**，直接在内部存储对象，零额外开销。

| 操作                          | 作用                                    |
| ----------------------------- | --------------------------------------- |
| `std::optional<T> opt{}`      | 创建空 optional                         |
| `std::optional<T> opt{t}`     | 创建有值 optional                       |
| `opt.has_value()` / `if(opt)` | 判断是否有值                            |
| `*opt`                        | 直接取值（无值则未定义行为）            |
| `opt.value()`                 | 取值，无值抛 `std::bad_optional_access` |
| `opt.value_or(def)`           | 有值返回值，无值返回默认值 def          |
| `opt.reset()`                 | 清空为无值                              |

**头文件**

```c++
#include <optional>
```

**最常用场景：函数可选返回值**

```c++
std::optional<int> find_index(const std::vector<int>& v, int target) {// 正确语义：找到返回int，没找到返回“空”
    for(int i=0; i<v.size(); i++)
        if(v[i]==target) return i; // 自动包装为 optional
    return {}; // 空 optional（无值）
}
```

**调用与判断**

```c++
auto res = find_index(v, 5);
// 判断是否有值
if (res.has_value()) {
    // 取值
    std::cout << *res;      // 解引用（推荐）
    std::cout << res.value(); // 成员函数（越界抛异常）
} else {
    std::cout << "未找到";
}
```

## 核心使用场景

1. **函数可能失败的返回值**（查找、解析、计算）
2. **可选函数参数**（替代指针默认参数 nullptr）
3. **类的可选成员变量**
4. **缓存 / 懒加载**（初始无值，生成后有值）

**直接当 bool 使用**

```c++
if (res) { // 等价 res.has_value()
    std::cout << *res;
}
```

**`value_or` 一行处理默认值**

```c++
int idx = find_index(v,5).value_or(-1);// 没找到就返回-1
```

**原地构造（避免拷贝）**

```c++
std::optional<std::string> opt;
opt.emplace("hello"); // 原地构造，无拷贝
```

## 核心规则与注意事项

- **`*opt` 必须在有值时使用**，否则是未定义行为；
- **`value()` 无值会抛异常**，适合必须有值的场景；
- **`optional` 是值语义**，拷贝、移动和 `T` 一致；
- 可存储**任何类型**（基础类型、结构体、对象）

# `std::variant<T...>`

`std::variant<T...>` 是 C++17 引入的**类型安全联合体（Type-Safe Union）**，用于表示**一组指定类型中的 “某一种”**，同一时刻只存储其中**一种类型**的值。

它完全替代了 C 风格的 `union`，**没有未定义行为、自动管理生命周期、类型安全、支持复杂对象**，是现代 C++ 处理多类型值的标准方案。

核心价值：**类型安全的 “多类型二选一 / 多选一”，替代不安全 union，明确持有类型，不悬空、不泄漏、不崩溃**。

## 背景

传统 union 只能存**简单类型**，不支持构造 / 析构函数，极易踩坑：

```c++
// 危险：不能存 string、vector 等复杂对象
union Data {
    int i;
    std::string s; // 未定义行为！
};
```

问题：

1. 不支持非平凡类型（string、vector、自定义对象）
2. 不知道当前存储的是什么类型
3. 手动管理生命周期，极易内存泄漏 / 崩溃

## 核心语法与基础使用

| 操作                           | 作用                           |
| ------------------------------ | ------------------------------ |
| `v = value`                    | 赋值，自动替换当前类型         |
| `std::holds_alternative<T>(v)` | 判断当前是否持有 T 类型        |
| `std::get<T>(v)`               | 获取 T 类型值，类型错误抛异常  |
| `std::get<index>(v)`           | 按索引获取值                   |
| `std::get_if<T>(&v)`           | 返回指针，错误返回 nullptr     |
| `v.index()`                    | 返回当前类型的索引（0,1,2...） |
| `std::monostate`               | 空状态，用于解决无默认构造问题 |

- `std::variant<T1, T2, T3,...>`：能持有**类型列表中的某一种**
- 同一时刻**只存一个值**
- **类型安全**：永远知道当前存储的类型
- **自动管理内存**：正确构造 / 析构，支持任意复杂类型
- **栈上分配**：无额外堆开销

**头文件**

```c++
#include <variant>
```

```c++
// 可以存储 int、string、double 中的一种
std::variant<int, std::string, double> v;
v = 10;               // 当前存储 int
v = "hello";          // 自动销毁旧值，存储 string
v = 3.14;             // 自动销毁旧值，存储 double
```

**判断类型 + 取值**

```c++
std::variant<int, std::string> v = "test";
if (std::holds_alternative<std::string>(v)) {
    // 安全获取
    std::cout << std::get<std::string>(v); // test
}
// 或用索引
if (v.index() == 1) {
    // 第1个类型是 string
}
```

**安全获取（不抛异常）**

```c++
// 正确 → 返回值指针
if (auto* s = std::get_if<std::string>(&v)) {
    std::cout << *s;
}
// 错误 → 返回 nullptr
if (auto* i = std::get_if<int>(&v)) {
    // 不会进入
}
```

**访问：std::visit（最强大）**

`std::visit` 可以**用一个 lambda 处理所有类型**，是 variant 的标准访问方式：**自动匹配当前存储的类型**。

```c++
std::visit([](auto&& val) {
    using T = std::decay_t<decltype(val)>;
    if constexpr (std::is_same_v<T, int>) {
        std::cout << "int: " << val;
    } else if constexpr (std::is_same_v<T, std::string>) {
        std::cout << "string: " << val;
    }
}, v);
```

**关键工具：`std::monostate`**

如果 variant 中所有类型**都不能默认构造**，必须用它作为 “空状态”：

```c++
std::variant<std::monostate, A, B> v;// 解决无法默认初始化的问题
```

| 特性         | `std::variant`      | C `union`  |
| ------------ | ------------------- | ---------- |
| 支持复杂类型 | string/vector/ 对象 | 不支持     |
| 类型安全     | 知道当前类型        | 手动记录   |
| 生命周期     | 自动构造 / 析构     | 手动管理   |
| 异常安全     | 安全                | 未定义行为 |
| 用途         | 现代 C++ 多类型值   | C 遗留代码 |

## 核心使用场景

- 函数返回多类型结果

```c++
std::variant<int, std::string> parse(const std::string& input);
```

- **配置项、动态值**
- **抽象语法树（AST）节点**
- **状态机、事件类型**
- **替代多态、减少继承**

## 注意事项

1. **不能直接使用 `\*`**，必须用 `get`/`get_if`/`visit`
2. **类型错误会抛异常**（`std::bad_variant_access`）
3. 是**值语义**，会拷贝 / 移动内部对象
4. 同一时刻只能存**一种类型**
5. 不允许引用类型（如 `variant<int&>` 非法）

# `std::any`

`std::any` 是 C++17 引入的**类型安全的任意类型容器**，提供了一种**可存储任意单一类型值**、且能在运行时安全获取与检查的机制，彻底解决了传统 `void*` 无类型检查、不安全、易造成未定义行为的痛点。

核心价值：**安全存储任意类型值 + 运行时类型检查 + 自动内存管理**，替代不安全的 `void*`，用于需要存储**未知 / 任意类型**的场景。

`std::any` 就是 **类型安全版的 `void\*`**。

## 背景

在没有 `std::any` 前，C++ 想存储 “任意类型” 只能用 **`void\*`**，但问题极大：

1. **完全无类型安全**：不知道原始类型，强转错误直接崩溃
2. **手动管理内存**：容易泄漏、悬空指针
3. **不支持复杂对象**：无法正确构造 / 析构

```c++
// 危险的 void* 用法
void* data = new int(10);
int val = *static_cast<int*>(data);    // 正确
double err = *static_cast<double*>(data); // 未定义行为！崩溃
```

## 核心语法与基础使用

| 操作                   | 作用                                         |
| ---------------------- | -------------------------------------------- |
| `std::any a`           | 创建空实例                                   |
| `a.has_value()`        | 是否有值                                     |
| `a.type()`             | 返回 `std::type_info`，可判断类型            |
| `std::any_cast<T>(&a)` | **安全指针形式**，失败返回 `nullptr`（推荐） |
| `std::any_cast<T>(a)`  | 值形式，失败**抛异常**                       |
| `a.reset()`            | 清空，释放内部对象                           |

- 可以**存储任何类型**（int、string、自定义类、指针…）
- 是**值类型**，会拷贝 / 移动存储的对象
- **自动管理生命周期**，无需手动释放
- **运行时记录类型信息**，错误转换会抛异常而非崩溃
- 不属于模板，是**通用类型**（这一点和 `variant` 不同）

**头文件**

```c++
#include <any>
```

```c++
// 空 any
std::any a;
// 存储 int
a = 10;
// 存储 string
a = std::string("hello");
// 存储自定义对象
a = MyClass{};
```

**指针转换（不抛异常，最安全）**

```c++
std::any a = 10;
if (auto* p = std::any_cast<int>(&a)) {
    std::cout << "int: " << *p << "\n";
} else {
    std::cout << "类型不匹配\n";
}
//直接值转换（失败抛异常）
try {
    int val = std::any_cast<int>(a);
} catch (const std::bad_any_cast& e) {
    // 类型错误
}
```

**判断是否存储了值 & 类型**

```c++
std::any a;
if (!a.has_value()) {
    // 空
}
a = 3.14;
// 判断当前存储的类型
if (a.type() == typeid(double)) {
    // 是 double
}
```

| 特性     | `std::any`            | `std::variant<T...>` | `std::optional<T>` |
| -------- | --------------------- | -------------------- | ------------------ |
| 存储类型 | **任意类型**          | 固定列表中的一种     | 一种类型或空       |
| 类型检查 | 运行时                | 编译期 + 运行时      | 有值 / 无值        |
| 安全性   | 类型安全              | 类型安全             | 类型安全           |
| 用途     | 未知类型、动态类型    | 已知几种可能类型     | 可能为空的值       |
| 开销     | 较高（堆 / 类型擦除） | 小（栈）             | 极小（栈）         |

## 核心使用场景

**动态消息 / 事件数据**

**配置系统、动态参数**

**需要存储未知类型的容器**（如 `std::vector<std::any>`）

**插件系统、跨模块数据传递**

**替代 `void\*` 做安全通用数据传输**

## 注意事项

1. **有运行时开销**（类型擦除、可能堆分配）
2. **类型检查在运行时**，编译期不报错
3. 推荐优先使用 **`any_cast<T>(&a)`** 指针形式，避免异常
4. 存储**值语义**对象，会自动拷贝 / 析构
5. 不能存储**引用**，但可存储**指针**

# `std::string_view`

`std::string_view` 是 C++17 引入的**字符串只读视图**，本质是 **“指针 + 长度”**的轻量级结构，用于**安全、高效、零拷贝 ** 读取字符串数据。

核心价值：**只读字符串的 “零成本封装”**，完美解决 `const char*` 不安全、`std::string` 传参拷贝开销大的痛点，是现代 C++ **字符串只读参数的首选类型**。

## 背景

处理只读字符串时，传统方式有严重缺陷：

1. **`const char\*`**：无长度信息，极易越界，不安全；
2. **`const std::string&`**：传字符串字面量 / 字符数组时，会**隐式构造临时 string**，产生**内存分配 + 拷贝**，性能损耗大。

```c++
void print(const std::string& str) { ... }// 问题：传入 "hello" 会构造临时 string，有开销
```

## 核心语法与基础使用

| 操作                   | 作用                        |
| ---------------------- | --------------------------- |
| `str.size()`           | 获取长度（O (1)，不含`\0`） |
| `str.data()`           | 获取原始指针                |
| `str[i]`               | 访问第 i 个字符             |
| `str.substr(pos, len)` | 取子串 **（零拷贝！）**     |
| `str.empty()`          | 判断空                      |
| `str.remove_prefix(n)` | 前缀跳过 n 字符             |
| `str.remove_suffix(n)` | 后缀截断 n 字符             |

- **轻量级结构**：仅含 `const char*`（数据指针）+ `size_t`（长度）；
- **只读视图**：**不可修改**原始字符串，仅用于读取；
- **零拷贝**：**不分配内存、不拷贝数据**，仅包装已有字符串；
- **通用接口**：拥有和 `std::string` 几乎一致的读取接口，使用成本极低。

**头文件**

```c++
#include <string_view>
```

**万能接收所有字符串类型**

```c++
// 只读字符串参数，首选 string_view！
void print(std::string_view str) {
    std::cout << str << "\n";
}
// 兼容所有字符串形式，零拷贝！
std::string s = "hello";
const char* cstr = "world";
print(s);       // 兼容 string
print(cstr);    // 兼容 const char*
print("test");  // 兼容字面量（无临时string）
```

| 特性       | `std::string_view` | `const std::string&`   | `const char*`    |
| ---------- | ------------------ | ---------------------- | ---------------- |
| 拷贝开销   | **零拷贝**         | 构造临时对象（有开销） | 无               |
| 长度获取   | **O(1)**           | O(1)                   | O(n)（strlen）   |
| 安全性     | 安全（带长度）     | 安全                   | 不安全（易越界） |
| 可修改     | 只读               | 只读                   | 只读             |
| 二进制数据 | ✅ 支持             | ✅ 支持                 | ❌ 依赖`\0`       |

## 核心使用场景

- 函数**只读字符串参数**
- 临时字符串解析、子串操作
- 纯读取、无修改的字符串传递

## 注意事项

- 字符串视图**不拥有数据**，生命周期由外部保证：不要返回局部 string 的 string_view

# 并行算法 (Parallel Algorithms)

C++17 为 **STL 算法**（如 `std::sort`/`std::for_each`/`std::transform`）引入了**并行执行策略**，让你**仅加一个参数**，就能自动利用多核 CPU 加速，无需手动写线程、锁、线程池。

核心价值：**一行代码让 STL 算法自动多核并行，无痛加速 CPU 密集型任务**，是现代 C++ 性能优化的最简单利器。

## 核心概念

C++17 做了两件事：

1. **给所有 STL 算法增加了并行版本**
2. **新增 3 种执行策略**，你只需要传给算法即可

**完全兼容原有代码**，只多一个参数。

**头文件**

```c++
#include <execution>
```

| 策略                            | 含义               | 用法                   |
| ------------------------------- | ------------------ | ---------------------- |
| **`std::execution::seq`**       | 串行（和原来一样） | 单线程顺序执行         |
| **`std::execution::par`**       | **并行**           | 多核并行执行（最常用） |
| **`std::execution::par_unseq`** | 并行 + 向量化      | 多核 + SIMD 指令级并行 |

**并行遍历**

```c++
std::vector<int> v(1000000, 1);
std::for_each(v.begin(), v.end(), [](int& x) { x *= 2; });// 普通串行
std::for_each(std::execution::par, v.begin(), v.end(), [](int& x) { x *= 2; });// C++17 并行加速
```

**并行排序**

```c++
std::sort(v.begin(), v.end());// 普通 sort
std::sort(std::execution::par, v.begin(), v.end());// 并行 sort
```

**并行变换**

```c++
std::transform(std::execution::par, v.begin(), v.end(), v.begin(),
    [](int x) { return x * 10; });
```

**支持的 STL 算法**

所有常用算法都支持并行（几乎全覆盖）：

- `for_each`
- `sort` / `stable_sort`
- `transform`
- `find_if` / `count_if`
- `replace` / `fill`
- `reduce`（并行版累加）
- `inclusive_scan` 等

## 注意事项

- 函数不能有数据竞争
  - 并行同时执行，不能写共享变量（不加锁会崩溃）

- 函数不能依赖顺序
  - 执行顺序不确定

- 不能抛异常
  - 并行异常行为复杂
- **纯函数最好**：只读写自己的元素
- 必须链接 TBB 或 使用 GCC 并行库

# 嵌套命名空间定义

C++17 引入了**嵌套命名空间简写语法**，允许**一行直接定义多层命名空间**，彻底告别传统繁琐的逐层嵌套写法，让命名空间代码更简洁、清爽、易维护。

核心价值：**一行定义多级命名空间，消除冗余大括号，代码更紧凑，符合现代 C++ 极简风格**。

## 背景

C++11/14 中，定义**多层嵌套命名空间**必须**逐层写大括号**，代码冗余、缩进繁琐、阅读困难：

```c++
// C++14 痛点：嵌套命名空间必须逐层写，冗余冗长
namespace my_project {
    namespace core {
        namespace utils {
            // 代码
            int add(int a, int b) { return a + b; }
        }
    }
}
```

## 核心语法与基础使用

**一行定义多层命名空间**，用 `命名空间1::命名空间2::命名空间3` 直接表示层级：

```c++
// C++14 及之前
namespace A { namespace B { namespace C {
} } }
// C++17
namespace A::B::C {
}
```

## 核心规则

1. **完全等价**

   简写语法和传统嵌套写法**语义完全相同**，编译器处理一致。

2. **自动创建不存在的命名空间**

   如果外层命名空间未定义，会**自动创建**。

   ```c++
   // 自动创建 a → b → c
   namespace a::b::c {}
   ```

3. **可混合内联命名空间**

   C++20 支持 `inline` 嵌套：

   ```c++
   namespace a::inline b::c {}
   ```

4. **仅用于定义，不用于访问**

   - 定义：`namespace a::b {}`
   - 访问：`a::b::func()`
