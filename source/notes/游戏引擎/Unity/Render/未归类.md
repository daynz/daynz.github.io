# `RenderTextureDescriptor`

**`RenderTextureDescriptor`** 是 Unity 引擎中用于**完整定义 `RenderTexture`（渲染纹理）所有属性**的核心结构体，是程序化创建、配置、复用 `RenderTexture` 的标准方式。它替代了传统零散参数的创建方式，将宽高、格式、深度、MSAA、Mipmap、维度、随机读写等所有属性集中管理，支持**复制、缓存、批量复用**，是现代 Unity 渲染与后处理、离屏渲染、实时纹理生成的基础配置单元。

## 核心定义与定位

### 官方定义

> A struct that contains **all information required to create a `RenderTexture`**. It can be copied, cached, and reused to easily create `RenderTextures` that share the same properties. **Avoid default constructor** (it doesn’t initialize some flags to recommended values).
>
> 一种结构体，包含创建渲染纹理所需的全部信息。该结构体可被复制、缓存与复用，便于创建具有相同属性的渲染纹理。避免使用默认构造函数（其不会将部分标志初始化为推荐值）。

### 核心作用

- **统一配置载体**：一个结构体包含 `RenderTexture` 的全部属性，替代多参数重载。
- **安全复用**：复制、缓存、传递，避免重复定义、参数遗漏、兼容性错误。
- **SRP 标准接口**：URP/HDRP 中 `cameraTargetDescriptor`、`GetTemporaryRT` 均以它为标准输入。
- **精确控制**：支持 `GraphicsFormat`、深度模板格式、MSAA、随机读写等底层级配置。

### 构造函数

```csharp
// 标准构造（宽, 高, 颜色格式, 深度缓冲位数）
RenderTextureDescriptor desc = new RenderTextureDescriptor(
    int width,        // 像素宽
    int height,       // 像素高
    RenderTextureFormat colorFormat, // 颜色格式
    int depthBufferBits       // 深度位数：0/16/24/32
);
// 全参数（含维度、体积深度）
RenderTextureDescriptor(
    int width, int height, int volumeDepth,
    RenderTextureDimension dimension,
    RenderTextureFormat colorFormat,
    int depthBufferBits
);
```

## 完整属性详解

### 基础尺寸与维度

- **width / height**：宽/高（像素），离屏渲染常用 `Screen.width/height` 或 1/2 降采样。
- **volumeDepth**：3D/体积纹理深度（2D 为 1）。
- **dimension**：纹理维度（枚举 `RenderTextureDimension`）
  - `Tex2D`：标准 2D 纹理（最常用）
  - `Cube`：立方体贴图（反射/天空盒）
  - `Tex3D`：3D 体积纹理
  - `Tex2DArray`：2D 纹理数组

### 颜色缓冲（核心）
- **`colorFormat`**：旧版颜色格式（`RenderTextureFormat`）
  - `Default`：平台默认（ARGB32/RGB565）
  - `ARGB32`：8888（标准、带透明）
  - `RGB565`：16 位（低内存、无透明）
  - `RGBAFloat`：32 位浮点（HDR、光照数据）
  - `RHalf` / `RGBAHalf`：16 位浮点（性能/精度平衡）
- **graphicsFormat**：现代底层图形格式（`GraphicsFormat`，优先使用）
  - 更精确：`R8G8B8A8_UNorm`、`R16G16B16A16_SFloat`、`B10G11R11_UFloatPack32`（HDR 高效）
- **sRGB**：是否为 sRGB 颜色空间（色彩校正）。
- **`enableRandomWrite`**：开启 UAV 随机读写（Shader Model 5.0+，计算着色器、全局光照）。

### 深度/模板缓冲（关键）
- **`depthBufferBits`**：深度缓冲位数
  - `0`：无深度（UI、后处理中间纹理）
  - `16`：16 位深度（无模板，节约内存）
  - `24`：24 位深度 + 8 位模板（标准，支持模板测试）
  - `32`：32 位浮点深度（高精度，如阴影、延迟渲染）
- **`depthStencilFormat`**：深度模板底层格式（`GraphicsFormat`）
  - `D24_UNorm_S8_UInt`：24 深度 + 8 模板（最常用）
  - `D32_SFloat`：32 位浮点深度（无模板）
  - `D16_UNorm`：16 位深度（无模板）

### 多重采样（MSAA）
- **`msaaSamples`**：MSAA 采样数（1/2/4/8）
- **`bindMS`**：是否绑定为多采样纹理（不自动 resolve，用于 shader 直接采样 MSAA 纹理）。

### Mipmap
- **`useMipMap`**：启用 Mipmap
- **`autoGenerateMips`**：自动生成 Mipmap（否则手动 `GenerateMips()`）。

### 性能与动态缩放
- **`useDynamicScale`**：启用动态分辨率缩放
- **`useDynamicScaleExplicit`**：显式控制动态缩放
- **`shadowSamplingMode`**：阴影采样模式（深度纹理专用）。

### 其他
- **`vrUsage`**：VR 纹理用途（单眼/双眼/多维）
- **flags**：高级标志（如 `RenderTextureCreationFlag`）
- **memoryless**：无内存模式（移动平台，仅 tile 缓存，节约带宽）。

## 与核心 API 的关联
### 永久 `RenderTexture`（标准创建）
```csharp
// 1. 定义描述符
RenderTextureDescriptor desc = new RenderTextureDescriptor(1024, 1024, RenderTextureFormat.ARGB32, 24);
desc.msaaSamples = 4;          // 4x MSAA
desc.useMipMap = true;         // 开启Mipmap
desc.autoGenerateMips = true;
desc.enableRandomWrite = true; // 支持UAV

// 2. 创建RT
RenderTexture rt = new RenderTexture(desc);
rt.Create(); // 显式创建（或首次使用自动创建）

// 3. 使用
camera.targetTexture = rt;
material.mainTexture = rt;
```

### 临时 `RenderTexture`（URP/SRP 后处理，最常用）
```csharp
// 从相机复制描述符（保证分辨率/格式一致）
RenderTextureDescriptor desc = renderingData.cameraData.cameraTargetDescriptor;
desc.depthBufferBits = 0;      // 中间纹理：关闭深度（省资源）
desc.msaaSamples = 1;          // 后处理通常关闭MSAA
desc.enableRandomWrite = false;
// 申请临时RT（自动池化，性能高）
int tempRT = Shader.PropertyToID("_TempBlurRT");
cmd.GetTemporaryRT(tempRT, desc);
// 渲染/Blit
cmd.Blit(source, tempRT, blurMaterial);
// 释放
cmd.ReleaseTemporaryRT(tempRT);
```

### 深度纹理（阴影、延迟渲染）
```csharp
// 纯深度纹理（无颜色）
RenderTextureDescriptor depthDesc = new RenderTextureDescriptor(
    Screen.width, Screen.height, RenderTextureFormat.Depth, 32);
depthDesc.dimension = RenderTextureDimension.Tex2D;
depthDesc.enableRandomWrite = true; // 计算着色器采样深度

RenderTexture depthRT = new RenderTexture(depthDesc);
depthRT.Create();
```

### HDR 浮点纹理（ bloom、光照缓冲）
```csharp
RenderTextureDescriptor hdrDesc = new RenderTextureDescriptor(
    Screen.width, Screen.height, RenderTextureFormat.RGBAHalf, 24);
hdrDesc.sRGB = false; // HDR为线性空间
hdrDesc.useMipMap = true;
hdrDesc.autoGenerateMips = true;
```

### 立方体贴图（反射、环境探针）
```csharp
RenderTextureDescriptor cubeDesc = new RenderTextureDescriptor(
    512, 512, RenderTextureFormat.ARGB32, 24);
cubeDesc.dimension = RenderTextureDimension.Cube; // 立方体贴图
cubeDesc.volumeDepth = 6; // 6个面
```

### URP `RenderFeature` 标准模板
```csharp
public override void Configure(CommandBuffer cmd, RenderTextureDescriptor cameraDescriptor)
{
    // 复制相机描述符，修改所需属性
    RenderTextureDescriptor myDesc = cameraDescriptor;
    myDesc.width /= 2; // 1/2降采样
    myDesc.height /= 2;
    myDesc.depthBufferBits = 0;
    myDesc.msaaSamples = 1;

    // 配置输入输出
    ConfigureInput(ScriptableRenderPassInput.Color);
    _targetHandle = RTHandles.Alloc(myDesc, name: "_MyEffectRT");
}
```

## 最佳实践与避坑

1. **优先使用 `cameraTargetDescriptor` 复制**：保证与相机分辨率、格式、平台兼容。
2. **临时纹理必用 `GetTemporaryRT`**：池化复用，避免 GC 与内存碎片。
3. **深度按需关闭**：后处理中间纹理设 `depthBufferBits=0` 显著提升性能。
4. **MSAA 传递**：需 MSAA 时保持 `msaaSamples` 与相机一致；后处理通常设为 1。
5. **避免默认构造**：`new RenderTextureDescriptor()` 部分标志未初始化，易出 Bug。
6. **平台兼容**：移动平台优先 `RGB565`/`ARGB1555`；PC/主机可用 `RGBAFloat`。
