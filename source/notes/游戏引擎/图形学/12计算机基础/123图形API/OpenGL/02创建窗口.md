# 创建窗口

## 创建窗口的步骤

- 初始化GLFW   `glfwInit()`
  - 管理窗口需要使用GLFW库，因此首先需要**初始化GLFW库**

- 创建窗口对象 `glfwCreateWindow()`
  - 创建窗口对象
- 设置上下文 
  - `glfwMakeContextCurrent()`设置**当前窗口为当前线程的主上下文**
- 加载glad     
  - `gladLoadGLLoader((GLADloadproc)glfwGetProcAddress)`

  - glad库用于管理OpenGL的函数指针,调用OpenGL函数前需要**初始化GLAD**

- 设置视口     
  - `glViewport()`设置渲染窗口的尺寸大小
- 主循环      
  - `while(!glfwWindowShouldClose(window))`渲染循环

- 回收资源   
  - `glfwTerminate()`

## 头文件

```cpp
#include <glad/glad.h>
#include <GLFW/glfw3.h>
```

GLAD必须在前面(GLAD中包含了正确的OpenGL头文件，例如:GL/gl.h)

## 主函数

### 初始化GLFW

```cpp
glfwInit();
glfwWindowHint(GLFW_CONTEXT_VERSION_MAJOR, 3);
glfwWindowHint(GLFW_CONTEXT_VERSION_MINOR, 3);
glfwWindowHint(GLFW_OPENGL_PROFILE, GLFW_OPENGL_CORE_PROFILE);
```

- *可选：使用`glfwWindowHint()`配置GLFW*
  - 第一个参数代表选项的名称，以`GLFW_`开头的枚举值中选择
  - 第二个参数接受一个整型，用来设置这个选项的值
  - 该函数的所有的选项以及对应的值都可以在 [GLFW’s window handling](http://www.glfw.org/docs/latest/window.html#window_hints) 这篇文档中找到
  - 如果编译后得到大量的 *undefined reference* (未定义的引用)错误，没有正确地链接GLFW库。

### 创建窗口对象

```cpp
GLFWwindow* glfwCreateWindow(
    int width,                // 窗口的宽度
    int height,               // 窗口的高度
    const char* title,        // 窗口的标题
    GLFWmonitor* monitor,     // 监视器，用于全屏模式，传NULL则为窗口模式
    GLFWwindow* share         // 共享资源的窗口，传NULL则不共享
);
```

```cpp
GLFWwindow* window = glfwCreateWindow(1920, 1080, "CreateWindow", NULL, NULL);
if (!window)
{
    glfwTerminate();
    return -1;
}
```

### 设置窗口上下文为当前线程的主上下文

```cpp
void glfwMakeContextCurrent(GLFWwindow* window);
```

```cpp
glfwMakeContextCurrent(window);
```

### 加载glad

```cpp
auto glad = gladLoadGLLoader((GLADloadproc)glfwGetProcAddress);
if (!glad)
{
    glfwTerminate();
    return -1;
}
```

- `gladLoadGLLoader`：这是 GLAD 提供的一个函数，用于加载 OpenGL 函数指针。它需要一个函数指针作为参数，这个函数指针指向一个能够加载 OpenGL 函数的函数。

- `GLADloadproc`：`GLADloadproc` 是 GLAD 定义的一个函数指针类型，用于指向加载 OpenGL 函数的函数。

- `glfwGetProcAddress`：这是 GLFW 库提供的函数，用于获取 OpenGL 函数的地址。当你创建了一个 OpenGL 上下文后，这个函数可以用来获取 OpenGL 函数的指针。

- 给GLAD传入了用来加载系统相关的OpenGL函数指针地址的函数，`glfwGetProcAddress`根据我们编译的系统定义了正确的函数

### 设置视口(可选)

```cpp
void glViewport(
    GLint x,                      // 视口左下角的 x 坐标
    GLint y,                      // 视口左下角的 y 坐标
    GLsizei width,                // 视口的宽度
    GLsizei height               // 视口的高度
);
```

```cpp
glViewport(0, 0, 1920, 1080)

//注册回调函数
glfwSetFramebufferSizeCallback(window, framebuffer_size_callback);

//回调函数 窗口大小被调整时调用(可选)
void framebuffer_size_callback(GLFWwindow* window, int width, int height)
{
    glViewport(0, 0, width, height);
}
```

不设置则默认窗口大小为视口大小

### 主循环

```cpp
while(!glfwWindowShouldClose(window))
{
    //渲染

    glfwSwapBuffers(window);
    glfwPollEvents();    
}
```

程序在主动关闭它之前不断绘制图像并能够接受用户输入

- `glfwWindowShouldClose()`在每次循环的开始前检查一次GLFW是否被要求退出
  - 如果是的话，该函数返回true，渲染循环将停止运行，之后我们就可以关闭应用程序。

- `glfwPollEvents()`检查有没有触发什么事件（比如键盘输入、鼠标移动等）、更新窗口状态，并调用对应的回调函数（可以通过回调方法手动设置）。

- `glfwSwapBuffers()`会交换颜色缓冲（它是一个储存着GLFW窗口每一个像素颜色值的大缓冲），它在这一迭代中被用来绘制，并且将会作为输出显示在屏幕上。

### 结束阶段

```cpp
glfwTerminate();
return 0;
```

当渲染循环结束后需要正确释放/删除之前的分配的所有资源
