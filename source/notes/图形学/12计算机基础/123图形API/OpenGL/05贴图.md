# 贴图

## 配置贴图完整步骤

### 1. 准备纹理资源
首先需获取纹理图像文件（如PNG、JPG、TGA等），并通过图像加载库（如`stb_image`、`FreeImage`、`SOIL2`）读取图像数据，获取关键信息：
- 图像宽度（width）、高度（height）
- 颜色通道数（channels）：如RGB（3通道）、RGBA（4通道，含透明度）
- 像素数据缓冲区（unsigned char* 类型，存储每个像素的颜色值）

**示例（使用stb_image加载图像）**：
```c
#define STB_IMAGE_IMPLEMENTATION
#include "stb_image.h"

// 图像参数
int width, height, channels;
// 加载图像（最后一个参数0表示自动检测通道数，1/3/4强制指定通道数）
unsigned char* textureData = stbi_load(
    "texture.jpg",  // 图像路径
    &width,         // 输出宽度
    &height,        // 输出高度
    &channels,      // 输出通道数
    0               // 强制通道数（0=自动）
);

// 检查加载是否成功
if (!textureData) {
    printf("Failed to load texture: %s\n", stbi_failure_reason());
    // 处理错误（如返回、终止）
}
```


### 2. 创建纹理对象
使用`glGenTextures`创建纹理对象（类似着色器的“对象ID”），后续所有纹理操作均围绕该ID进行。

```c
GLuint textureID;
// 生成1个纹理对象，ID存储到textureID中
glGenTextures(1, &textureID);
```


### 3. 绑定纹理对象
通过`glBindTexture`将纹理对象绑定到指定的**纹理目标（Texture Target）**，后续操作会作用于该绑定的纹理。  
常用纹理目标：
- `GL_TEXTURE_2D`：2D纹理（最常用，如平面、模型表面贴图）
- `GL_TEXTURE_CUBE_MAP`：立方体贴图（如天空盒、环境映射）

```c
// 将textureID绑定到2D纹理目标
glBindTexture(GL_TEXTURE_2D, textureID);
```


### 4. 配置纹理参数（关键）
纹理参数决定GPU如何采样纹理（如放大/缩小过滤、边缘环绕方式），需在绑定纹理后调用`glTexParameteri`配置。若参数未正确设置，可能导致纹理拉伸、模糊或边缘异常。

#### 核心纹理参数列表
| 参数名（`GLenum`）      | 作用                           | 常用值（`GLenum`）                                           |
| ----------------------- | ------------------------------ | ------------------------------------------------------------ |
| `GL_TEXTURE_WRAP_S`     | 纹理S轴（水平方向）环绕方式    | `GL_REPEAT`（重复）、`GL_CLAMP_TO_EDGE`（边缘拉伸）、`GL_MIRRORED_REPEAT`（镜像重复） |
| `GL_TEXTURE_WRAP_T`     | 纹理T轴（垂直方向）环绕方式    | 同`GL_TEXTURE_WRAP_S`                                        |
| `GL_TEXTURE_MIN_FILTER` | 纹理缩小过滤（物体远离镜头时） | `GL_NEAREST`（邻近过滤，像素化）、`GL_LINEAR`（线性过滤，平滑）、`GL_LINEAR_MIPMAP_LINEAR`（MIP贴图+线性，最高质量） |
| `GL_TEXTURE_MAG_FILTER` | 纹理放大过滤（物体靠近镜头时） | `GL_NEAREST`（像素化）、`GL_LINEAR`（平滑，无MIP贴图）       |

**示例代码（基础配置）**：
```c
// 1. 配置环绕方式（S/T轴均设为“重复”）
glTexParameteri(GL_TEXTURE_2D, GL_TEXTURE_WRAP_S, GL_REPEAT);
glTexParameteri(GL_TEXTURE_2D, GL_TEXTURE_WRAP_T, GL_REPEAT);

// 2. 配置过滤方式（缩小用MIP线性过滤，放大用线性过滤）
// 缩小过滤：MIP贴图+线性采样（需后续生成MIP贴图）
glTexParameteri(GL_TEXTURE_2D, GL_TEXTURE_MIN_FILTER, GL_LINEAR_MIPMAP_LINEAR);
// 放大过滤：线性采样（无MIP贴图，因放大时纹理像素密度低于屏幕像素）
glTexParameteri(GL_TEXTURE_2D, GL_TEXTURE_MAG_FILTER, GL_LINEAR);
```


### 5. 加载纹理数据到GPU
使用`glTexImage2D`将CPU端的图像数据（`textureData`）上传到GPU的纹理对象中，同时指定纹理的格式（如RGB/RGBA）和存储方式。

**函数原型**：
```c
void glTexImage2D(
    GLenum target,        // 纹理目标（如GL_TEXTURE_2D）
    GLint level,          // MIP贴图层级（0=基础层级，后续层级由glGenerateMipmap生成）
    GLint internalFormat, // GPU内部存储格式（如GL_RGB、GL_RGBA）
    GLsizei width,        // 纹理宽度（需为2的幂？现代OpenGL支持非2幂，但兼容性需注意）
    GLsizei height,       // 纹理高度
    GLint border,         // 边框宽度（必须为0， legacy参数）
    GLenum format,        // 输入图像的格式（如GL_RGB、GL_RGBA，需与channels匹配）
    GLenum type,          // 输入像素数据的类型（如GL_UNSIGNED_BYTE，对应unsigned char）
    const void* data      // CPU端的像素数据缓冲区（textureData）
);
```

**示例代码**：
```c
// 确定输入图像格式（根据channels）
GLenum imageFormat = (channels == 4) ? GL_RGBA : GL_RGB;
// 确定GPU内部格式（与输入格式匹配，确保颜色通道对应）
GLenum internalFormat = (channels == 4) ? GL_RGBA : GL_RGB;

// 上传纹理数据到GPU
glTexImage2D(
    GL_TEXTURE_2D,        // 目标：2D纹理
    0,                    // MIP层级：基础层
    internalFormat,       // GPU内部格式：RGB/RGBA
    width,                // 纹理宽度
    height,               // 纹理高度
    0,                    // 边框：0（必须）
    imageFormat,          // 输入图像格式
    GL_UNSIGNED_BYTE,     // 像素数据类型：无符号字节
    textureData           // CPU端像素数据
);
```


### 6. 生成MIP贴图（可选但推荐）
MIP贴图（Mipmap）是一组分辨率递减的纹理副本（如原图→1/2尺寸→1/4尺寸…），GPU在物体远离镜头时自动使用低分辨率MIP层，减少采样计算量并避免“纹理闪烁”。  
仅需调用`glGenerateMipmap`即可自动生成所有MIP层级（需先上传基础层纹理数据）。

```c
// 为当前绑定的2D纹理生成MIP贴图
glGenerateMipmap(GL_TEXTURE_2D);
```


### 7. 释放CPU端图像数据
纹理数据已上传到GPU后，CPU端的`textureData`不再需要，需调用图像加载库的释放函数（如`stbi_image_free`），避免内存泄漏。

```c
// 释放stb_image加载的CPU端像素数据
stbi_image_free(textureData);
```


### 8. 在着色器中使用纹理
需在顶点着色器和片段着色器中添加纹理相关逻辑，建立“顶点纹理坐标→片段采样”的流程。

#### 步骤1：定义纹理坐标（Vertex Shader）
顶点着色器需接收**纹理坐标（TexCoord）**（由应用程序传递，如顶点数据的一部分），并将其传递给片段着色器（通过`out`变量）。

```glsl
// 顶点着色器（Vertex Shader）
#version 330 core

// 输入：顶点位置（来自CPU）
layout (location = 0) in vec3 aPos;
// 输入：纹理坐标（来自CPU，与顶点一一对应）
layout (location = 1) in vec2 aTexCoord;

// 输出：纹理坐标（传递给片段着色器）
out vec2 TexCoord;

void main() {
    gl_Position = vec4(aPos, 1.0); // 计算顶点最终位置
    TexCoord = aTexCoord;          // 传递纹理坐标到片段着色器
}
```

#### 步骤2：采样纹理颜色（Fragment Shader）
片段着色器需通过**采样器（Sampler）** 变量访问GPU中的纹理，使用`texture()`函数根据纹理坐标采样颜色，并将其作为片段颜色输出。

```glsl
// 片段着色器（Fragment Shader）
#version 330 core

// 输入：来自顶点着色器的纹理坐标（插值后的值）
in vec2 TexCoord;

// 输出：片段最终颜色（RGBA）
out vec4 FragColor;

// 采样器：绑定到特定纹理单元（默认0），类型需与纹理目标匹配（如sampler2D对应GL_TEXTURE_2D）
uniform sampler2D ourTexture;

void main() {
    // 采样纹理颜色：texture(采样器, 纹理坐标)
    FragColor = texture(ourTexture, TexCoord);
}
```


### 9. 绑定纹理单元并激活纹理
现代OpenGL支持多纹理采样（如同时使用“ diffuse贴图”和“ specular贴图”），通过**纹理单元（Texture Unit）** 区分不同纹理（编号从0开始，默认激活纹理单元0）。  
使用纹理前需：
1. 激活目标纹理单元（`glActiveTexture`）；
2. 将纹理对象绑定到该纹理单元（`glBindTexture`）；
3. （多纹理时）在着色器中设置采样器的`uniform`值，指定其绑定的纹理单元。

**示例代码（单纹理）**：
```c
// 1. 激活纹理单元0（默认激活，可省略，但显式调用更清晰）
glActiveTexture(GL_TEXTURE0);
// 2. 将textureID绑定到当前激活的纹理单元（GL_TEXTURE0）
glBindTexture(GL_TEXTURE_2D, textureID);

// 3. （可选）若着色器采样器未默认绑定0，需设置uniform（通常无需，因sampler默认取纹理单元0）
GLint texUniformLoc = glGetUniformLocation(shaderProgram, "ourTexture");
glUniform1i(texUniformLoc, 0); // 0表示绑定到纹理单元0
```

**示例代码（多纹理，如diffuse+specular）**：
```c
// 激活纹理单元0，绑定diffuse纹理
glActiveTexture(GL_TEXTURE0);
glBindTexture(GL_TEXTURE_2D, diffuseTextureID);
// 激活纹理单元1，绑定specular纹理
glActiveTexture(GL_TEXTURE1);
glBindTexture(GL_TEXTURE_2D, specularTextureID);

// 在着色器中设置采样器的纹理单元
glUniform1i(glGetUniformLocation(shaderProgram, "diffuseTex"), 0); // 绑定到0号单元
glUniform1i(glGetUniformLocation(shaderProgram, "specularTex"), 1); // 绑定到1号单元
```


### 10. 绘制几何体（触发纹理采样）
激活着色器程序和纹理后，调用绘制函数（如`glDrawArrays`、`glDrawElements`），GPU会自动根据顶点纹理坐标采样纹理，生成带纹理的片段颜色。

```c
// 激活着色器程序
glUseProgram(shaderProgram);
// 绑定顶点数组（含顶点位置和纹理坐标数据）
glBindVertexArray(VAO);
// 绘制三角形（3个顶点）
glDrawArrays(GL_TRIANGLES, 0, 3);
```


### 11. 解绑纹理（可选）
绘制完成后，可解绑纹理对象（避免后续操作意外修改该纹理），但非必需（后续绑定其他纹理会自动覆盖当前绑定）。

```c
// 解绑2D纹理目标（传递0表示解绑）
glBindTexture(GL_TEXTURE_2D, 0);
```


### 12. 释放纹理资源（程序退出/资源销毁时）
当纹理不再需要（如场景切换、程序退出），需调用`glDeleteTextures`删除纹理对象，释放GPU内存。

```c
// 删除纹理对象（1个纹理，ID为textureID）
glDeleteTextures(1, &textureID);
```


## 核心函数详解

### 1. `glGenTextures`
- **作用**：生成一个或多个纹理对象ID（用于标识GPU中的纹理资源）。
- **函数原型**：
  ```c
  void glGenTextures(GLsizei n, GLuint* textures);
  ```
- **参数**：
  - `n`：要生成的纹理对象数量（如1表示生成1个纹理）；
  - `textures`：指向GLuint数组的指针，用于存储生成的纹理ID（若n=1，可直接传单个变量地址）。
- **注意**：生成的ID仅为“空标识”，需通过`glBindTexture`绑定后才能配置参数和上传数据。


### 2. `glBindTexture`
- **作用**：将纹理对象绑定到指定的**纹理目标**，后续纹理操作（如配置参数、上传数据）均作用于该绑定的纹理。
- **函数原型**：
  ```c
  void glBindTexture(GLenum target, GLuint texture);
  ```
- **参数**：
  - `target`：纹理目标（如`GL_TEXTURE_2D`、`GL_TEXTURE_CUBE_MAP`），决定纹理的类型和用途；
  - `texture`：要绑定的纹理ID（生成的`textureID`），或0（表示解绑当前目标的纹理）。
- **关键逻辑**：OpenGL通过“绑定目标”管理状态，同一时间一个目标只能绑定一个纹理，但一个纹理可绑定到多个目标（需类型匹配）。


### 3. `glTexParameteri`
- **作用**：设置纹理对象的参数（如环绕方式、过滤方式），决定GPU如何处理纹理采样。
- **函数原型**：
  ```c
  void glTexParameteri(GLenum target, GLenum pname, GLint param);
  ```
- **参数**：
  - `target`：纹理目标（需与绑定的目标一致，如`GL_TEXTURE_2D`）；
  - `pname`：要设置的参数名（如`GL_TEXTURE_WRAP_S`、`GL_TEXTURE_MIN_FILTER`）；
  - `param`：参数值（需与`pname`匹配，如`GL_REPEAT`、`GL_LINEAR`）。
- **常见参数组合**：
  - 像素化风格纹理：`GL_TEXTURE_MIN_FILTER = GL_NEAREST` + `GL_TEXTURE_MAG_FILTER = GL_NEAREST`；
  - 平滑风格纹理：`GL_TEXTURE_MIN_FILTER = GL_LINEAR_MIPMAP_LINEAR` + `GL_TEXTURE_MAG_FILTER = GL_LINEAR`；
  - 无重复纹理（如UI贴图）：`GL_TEXTURE_WRAP_S = GL_CLAMP_TO_EDGE` + `GL_TEXTURE_WRAP_T = GL_CLAMP_TO_EDGE`。


### 4. `glTexImage2D`
- **作用**：将CPU端的2D图像数据上传到GPU的纹理对象中，是“CPU→GPU”纹理数据传输的核心函数。
- **参数细节（补充）**：
  - `level`：MIP贴图层级，0表示“基础分辨率层”，1表示“1/2分辨率层”，以此类推（手动生成MIP时需指定，自动生成时设为0）；
  - `internalFormat`：GPU内部存储格式，决定纹理的颜色精度和通道数（如`GL_RGB8`表示8位/通道的RGB，`GL_RGBA32F`表示32位浮点/通道的RGBA）；
  - `format`：输入图像的格式，必须与`textureData`的通道数匹配（如`channels=3`时设为`GL_RGB`，`channels=4`时设为`GL_RGBA`）；
  - `type`：输入像素数据的类型，常用`GL_UNSIGNED_BYTE`（对应`unsigned char`，0-255范围），若为浮点纹理设为`GL_FLOAT`。
- **注意**：图像宽度/高度若为“2的幂”（如256、512），兼容性更好；现代OpenGL支持非2幂，但需确保`GL_TEXTURE_WRAP`设为非重复模式（如`GL_CLAMP_TO_EDGE`）。


### 5. `glGenerateMipmap`
- **作用**：自动为当前绑定的纹理生成所有MIP贴图层级，避免手动创建低分辨率纹理副本。
- **函数原型**：
  ```c
  void glGenerateMipmap(GLenum target);
  ```
- **参数**：纹理目标（需与绑定的目标一致，如`GL_TEXTURE_2D`）；
- **使用场景**：当纹理需要在“远/近镜头”切换时保持清晰（如3D模型贴图），必须生成MIP贴图；若为UI贴图（始终全屏显示），可省略（因无需缩小）。


### 6. `glActiveTexture`
- **作用**：激活指定的纹理单元，用于多纹理采样（如同时使用多个贴图时区分不同纹理）。
- **函数原型**：
  ```c
  void glActiveTexture(GLenum texture);
  ```
- **参数**：纹理单元标识，格式为`GL_TEXTUREi`（i为纹理单元编号，如`GL_TEXTURE0`、`GL_TEXTURE1`）；
- **默认值**：OpenGL默认激活`GL_TEXTURE0`，因此单纹理场景可省略`glActiveTexture`调用；多纹理场景必须显式激活不同单元。


### 7. `texture()`（GLSL函数）
- **作用**：在片段着色器中根据纹理坐标采样纹理颜色，是“GPU纹理采样”的核心函数。
- **函数原型（GLSL）**：
  ```glsl
  vec4 texture(sampler2D sampler, vec2 texCoord);
  vec4 texture(samplerCube sampler, vec3 texCoord); // 立方体贴图采样
  ```
- **参数**：
  - `sampler`：采样器变量（如`sampler2D ourTexture`），绑定到特定纹理单元；
  - `texCoord`：纹理坐标，2D纹理用`vec2`（S/T轴，范围通常0.0-1.0），立方体贴图用`vec3`（方向向量）；
- **返回值**：采样得到的颜色（`vec4`，RGBA格式，每个分量0.0-1.0）。
- **示例**：
  ```glsl
  // 采样纹理，并混合白色（提亮效果）
  FragColor = texture(ourTexture, TexCoord) * vec4(1.2, 1.2, 1.2, 1.0);
  ```
