# 着色器

## 配置着色器完整步骤

### 1. 编写着色器代码
使用GLSL（OpenGL Shading Language）编写顶点着色器和片段着色器的源代码，分别处理顶点数据和像素颜色计算。

**示例代码**：
```glsl
// 顶点着色器代码
const char* vertexShaderSource = "#version 330 core\n"
    "layout (location = 0) in vec3 aPos;\n"
    "void main()\n"
    "{\n"
    "   gl_Position = vec4(aPos, 1.0);\n"
    "}\0";

// 片段着色器代码
const char* fragmentShaderSource = "#version 330 core\n"
    "out vec4 FragColor;\n"
    "void main()\n"
    "{\n"
    "   FragColor = vec4(1.0f, 0.5f, 0.2f, 1.0f);\n"
    "}\0";
```


### 2. 创建着色器对象
使用`glCreateShader`创建顶点着色器和片段着色器对象，用于后续附加源代码和编译操作。

```c
// 创建顶点着色器对象
GLuint vertexShader = glCreateShader(GL_VERTEX_SHADER);
// 创建片段着色器对象
GLuint fragmentShader = glCreateShader(GL_FRAGMENT_SHADER);
```


### 3. 附加着色器源代码
通过`glShaderSource`将编写的GLSL代码附加到对应的着色器对象，为编译做准备。

```c
// 附加顶点着色器源代码
glShaderSource(vertexShader, 1, &vertexShaderSource, NULL);
// 附加片段着色器源代码
glShaderSource(fragmentShader, 1, &fragmentShaderSource, NULL);
```


### 4. 编译着色器
调用`glCompileShader`对已附加源代码的着色器对象进行编译，生成中间代码。

```c
// 编译顶点着色器
glCompileShader(vertexShader);
// 编译片段着色器
glCompileShader(fragmentShader);
```


### 5. 检查编译状态
编译完成后，必须通过`glGetShaderiv`和`glGetShaderInfoLog`检查编译是否成功，并处理可能的错误信息。

```cpp
// 检查顶点着色器编译状态
int success;
char infoLog[512];
glGetShaderiv(vertexShader, GL_COMPILE_STATUS, &success);
if (!success) {
    glGetShaderInfoLog(vertexShader, 512, NULL, infoLog);
    printf("Vertex shader compilation error: %s\n", infoLog);
}

// 检查片段着色器编译状态
glGetShaderiv(fragmentShader, GL_COMPILE_STATUS, &success);
if (!success) {
    glGetShaderInfoLog(fragmentShader, 512, NULL, infoLog);
    printf("Fragment shader compilation error: %s\n", infoLog);
}
```


### 6. 创建着色器程序
使用`glCreateProgram`创建着色器程序对象，用于将多个编译后的着色器链接成可执行程序。

```c
GLuint shaderProgram = glCreateProgram();
```


### 7. 附加着色器到程序
通过`glAttachShader`将编译好的顶点着色器和片段着色器附加到着色器程序中。

```c
// 附加顶点着色器到程序
glAttachShader(shaderProgram, vertexShader);
// 附加片段着色器到程序
glAttachShader(shaderProgram, fragmentShader);
```


### 8. 链接着色器程序
调用`glLinkProgram`将附加的着色器链接成一个完整的可执行程序，供GPU执行。

```c
glLinkProgram(shaderProgram);
```


### 9. 检查链接状态
链接完成后，通过`glGetProgramiv`和`glGetProgramInfoLog`检查链接是否成功，处理可能的链接错误。

```cpp
// 检查程序链接状态
glGetProgramiv(shaderProgram, GL_LINK_STATUS, &success);
if (!success) {
    glGetProgramInfoLog(shaderProgram, 512, NULL, infoLog);
    printf("Shader program linking error: %s\n", infoLog);
}
```


### 10. 删除着色器对象
着色器成功链接到程序后，不再需要原始着色器对象，调用`glDeleteShader`释放资源。

```cpp
// 删除顶点着色器
glDeleteShader(vertexShader);
// 删除片段着色器
glDeleteShader(fragmentShader);
```


### 11. 激活着色器程序
在渲染前，使用`glUseProgram`激活着色器程序，使其成为后续渲染命令使用的当前程序。

```c
glUseProgram(shaderProgram);
```


### 12. 设置Uniform变量（可选）
若着色器中定义了uniform变量（可由CPU设置的全局变量），需在激活程序后通过`glUniform*`系列函数设置其值。

```cpp
// 获取uniform变量位置
GLint ourColorLoc = glGetUniformLocation(shaderProgram, "ourColor");
// 设置4个浮点分量的uniform值（RGBA）
glUniform4f(ourColorLoc, 1.0f, 0.0f, 0.0f, 1.0f);
```


### 13. 执行绘制命令
激活着色器程序后，调用绘制函数（如`glDrawArrays`）触发GPU执行着色器程序并渲染几何体。

```cpp
// 绘制三角形（3个顶点）
glDrawArrays(GL_TRIANGLES, 0, 3);
```


### 14. 禁用着色器程序（可选）
绘制完成后，可调用`glUseProgram(0)`禁用当前着色器程序，避免后续操作意外修改。

```cpp
glUseProgram(0);
```


### 15. 释放着色器程序资源（程序退出时）
当着色器程序不再需要（如程序退出），调用`glDeleteProgram`删除程序对象，释放GPU资源。

```cpp
glDeleteProgram(shaderProgram);
```


## 核心函数详解

### 1. `glCreateShader`
- **作用**：创建指定类型的着色器对象，用于后续附加源代码和编译。
- **函数原型**：
  ```c
  GLuint glCreateShader(GLenum shaderType);
  ```
- **参数**：
  - `shaderType`：着色器类型，常用`GL_VERTEX_SHADER`（顶点着色器）和`GL_FRAGMENT_SHADER`（片段着色器）；
- **返回值**：新创建的着色器对象ID（非零值），创建失败返回0。
- **注意**：创建的着色器对象初始为未编译状态，需通过`glShaderSource`和`glCompileShader`处理。


### 2. `glShaderSource`
- **作用**：为着色器对象附加源代码字符串，作为编译的输入。
- **函数原型**：
  ```c
  void glShaderSource(GLuint shader, GLsizei count, const GLchar* const* string, const GLint* length);
  ```
- **参数**：
  - `shader`：目标着色器对象ID；
  - `count`：源代码字符串的数量；
  - `string`：指向字符串数组的指针（存储源代码）；
  - `length`：每个字符串的长度数组（为`NULL`时表示字符串以null结尾）；
- **示例**：单字符串传递时，`count=1`，`string`为单个字符串地址。


### 3. `glCompileShader`
- **作用**：编译指定的着色器对象，将源代码转换为GPU可执行的中间代码。
- **函数原型**：
  ```c
  void glCompileShader(GLuint shader);
  ```
- **参数**：需编译的着色器对象ID；
- **注意**：编译可能因语法错误失败，必须通过`glGetShaderiv`检查`GL_COMPILE_STATUS`。


### 4. `glGetShaderiv`
- **作用**：查询着色器对象的属性信息，最常用以检查编译状态。
- **函数原型**：
  ```c
  void glGetShaderiv(GLuint shader, GLenum pname, GLint* params);
  ```
- **参数**：
  - `shader`：目标着色器对象ID；
  - `pname`：查询的属性类型，常用`GL_COMPILE_STATUS`（编译状态，1为成功，0为失败）；
  - `params`：存储查询结果的整数指针；
- **使用场景**：编译后必须调用以确认着色器是否可用。


### 5. `glGetShaderInfoLog`
- **作用**：获取着色器编译错误的详细日志信息，用于调试。
- **函数原型**：
  ```c
  void glGetShaderInfoLog(GLuint shader, GLsizei maxLength, GLsizei* length, GLchar* infoLog);
  ```
- **参数**：
  - `shader`：目标着色器对象ID；
  - `maxLength`：日志缓冲区的最大长度；
  - `length`：实际日志长度（可为`NULL`）；
  - `infoLog`：存储日志信息的字符数组；
- **示例**：编译失败时，通过该函数获取具体错误位置和原因。


### 6. `glCreateProgram`
- **作用**：创建着色器程序对象，用于管理多个着色器的链接和执行。
- **函数原型**：
  ```c
  GLuint glCreateProgram(void);
  ```
- **返回值**：新创建的程序对象ID（非零值），创建失败返回0；
- **注意**：程序对象需附加着色器并链接后才能使用。


### 7. `glAttachShader`
- **作用**：将编译好的着色器对象附加到着色器程序，为链接做准备。
- **函数原型**：
  ```c
  void glAttachShader(GLuint program, GLuint shader);
  ```
- **参数**：
  - `program`：目标着色器程序ID；
  - `shader`：要附加的着色器对象ID；
- **常见组合**：一个程序至少需附加顶点着色器（核心模式），通常还需片段着色器。


### 8. `glLinkProgram`
- **作用**：将附加到程序的着色器链接成一个可执行程序，验证着色器间的兼容性。
- **函数原型**：
  ```c
  void glLinkProgram(GLuint program);
  ```
- **参数**：需链接的着色器程序ID；
- **注意**：链接可能因着色器不兼容（如输入输出变量不匹配）失败，需通过`glGetProgramiv`检查。


### 9. `glGetProgramiv`
- **作用**：查询着色器程序的属性信息，最常用以检查链接状态。
- **函数原型**：
  ```c
  void glGetProgramiv(GLuint program, GLenum pname, GLint* params);
  ```
- **参数**：
  - `program`：目标着色器程序ID；
  - `pname`：查询的属性类型，常用`GL_LINK_STATUS`（链接状态，1为成功，0为失败）；
  - `params`：存储查询结果的整数指针；


### 10. `glGetProgramInfoLog`
- **作用**：获取程序链接错误的详细日志信息，用于调试。
- **函数原型**：
  ```c
  void glGetProgramInfoLog(GLuint program, GLsizei maxLength, GLsizei* length, GLchar* infoLog);
  ```
- **参数**：
  - `program`：目标着色器程序ID；
  - `maxLength`：日志缓冲区的最大长度；
  - `length`：实际日志长度（可为`NULL`）；
  - `infoLog`：存储日志信息的字符数组；
- **使用场景**：链接失败时，获取如“输入输出变量不匹配”等具体错误信息。


### 11. `glDeleteShader`
- **作用**：删除着色器对象，释放其占用的内存资源。
- **函数原型**：
  ```c
  void glDeleteShader(GLuint shader);
  ```
- **参数**：要删除的着色器对象ID；
- **最佳实践**：着色器成功链接到程序后立即删除，因程序已包含编译后的信息。


### 12. `glUseProgram`
- **作用**：激活指定的着色器程序，使其成为后续渲染命令使用的当前程序。
- **函数原型**：
  ```c
  void glUseProgram(GLuint program);
  ```
- **参数**：要激活的程序ID（0表示禁用当前程序）；
- **注意**：核心模式下，渲染前必须激活有效的程序对象，否则会产生错误。


### 13. `glGetUniformLocation`
- **作用**：获取着色器程序中uniform变量的位置索引，用于设置其值。
- **函数原型**：
  ```c
  GLint glGetUniformLocation(GLuint program, const GLchar* name);
  ```
- **参数**：
  - `program`：包含uniform变量的程序ID；
  - `name`：uniform变量的名称（字符串）；
- **返回值**：uniform变量的位置（非负整数），未找到时返回-1；
- **注意**：未被使用的uniform变量会被编译器优化移除，导致返回-1。


### 14. `glUniform4f`
- **作用**：为4个浮点分量的uniform变量设置值（如RGBA颜色）。
- **函数原型**：
  ```c
  void glUniform4f(GLint location, GLfloat v0, GLfloat v1, GLfloat v2, GLfloat v3);
  ```
- **参数**：
  - `location`：uniform变量的位置（由`glGetUniformLocation`获取）；
  - `v0-v3`：4个浮点分量的值；
- **系列函数**：根据变量类型不同，还有`glUniform1i`（整数）、`glUniform3fv`（向量）等。


### 15. `glDeleteProgram`
- **作用**：删除着色器程序对象，释放其占用的GPU资源。
- **函数原型**：
  ```c
  void glDeleteProgram(GLuint program);
  ```
- **参数**：要删除的程序对象ID；
- **注意**：删除正在使用的程序（已通过`glUseProgram`激活）会导致后续渲染错误，删除前应确保已解绑。
