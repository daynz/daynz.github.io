# 屏幕空间全局光照(SSGI)简介

SSGI（Screen Space Global Illumination，屏幕空间全局光照）是一种在实时渲染中快速模拟间接光照的后处理技术，核心是在屏幕空间内通过光线步进与随机采样计算间接光，仅利用当前帧的深度、法线、颜色等缓冲区数据，不依赖场景几何或离线烘焙，适合密闭场景，速度快但无法处理屏幕外物体。

## 核心思想与定位

- **本质**：复用屏幕空间已渲染的像素作为 “间接光源”，通过逆向光线追踪（从着色点发射采样光线）估算间接光照，避免复杂的全局光照计算。
- **局限**：仅能处理屏幕内可见物体，屏幕外或被遮挡的物体无法贡献间接光；易产生噪点与边缘泄漏，需降噪与修正。
- **适用场景**：密闭空间（如室内、走廊）效果最佳；开阔场景中屏幕外信息缺失会导致效果减弱。

## 关键技术基础

SSGI 依赖渲染管线中的多个缓冲区（`GBuffer`），核心输入数据包括：

| 缓冲区类型                  | 作用                                           |
| --------------------------- | ---------------------------------------------- |
| 深度缓冲区（Depth Buffer）  | 还原像素的世界 / 视空间位置，用于碰撞检测      |
| 法线缓冲区（Normal Buffer） | 提供像素表面法线，计算光线反射 / 散射方向      |
| 颜色缓冲区（Color Buffer）  | 存储直接光照后的像素颜色，作为间接光采样源     |
| 噪点纹理（Noise Texture）   | 提供随机采样偏移，避免采样图案重复导致的摩尔纹 |
| 层次化深度缓冲区（HZB）     | 加速光线步进中的碰撞检测，减少计算量           |

## 完整实现流程

SSGI 的实现通常分为 5 个核心步骤，以下以主流实时渲染管线为例说明：

1. 准备阶段：缓冲区预处理
   - **生成 `GBuffer`**：渲染场景时输出深度、法线、颜色等缓冲区，确保每个像素的空间与材质信息可用。
   - **构建 HZB**：生成深度缓冲区的多级分层结构（Mipmap），每层存储对应区域的最大深度值，用于快速判断光线步进中的遮挡关系，减少无效计算。
   - **噪点采样初始化**：加载 2D 噪点纹理，为每个像素生成随机采样方向，避免采样规律性导致的带状噪点。
2. 采样阶段：光线步进与碰撞检测
   - **着色点初始化**：对每个像素，从深度缓冲区还原其世界坐标（P）与法线（N），计算间接光采样的初始方向（如反射方向、半球随机方向）。
   - **光线步进（Ray Marching）**：从 P 出发，沿采样方向以固定步长推进光线，每步通过 HZB 快速查询当前位置的深度，判断是否与场景碰撞。
   - **碰撞验证**：当光线位置的深度值小于场景深度时，视为碰撞，记录碰撞点的颜色作为间接光贡献；若超出最大步长仍无碰撞，则视为采样失败，贡献为 0。
   - **多采样整合**：对每个像素发射多条采样光线（如 16-64 条），通过随机偏移避免重复，将所有有效采样颜色加权平均（如按距离衰减），得到该像素的间接光颜色。
3. 降噪阶段：消除采样噪点
   - **TAA 时间重投影**：利用上一帧的采样结果与当前帧进行时间累积，减少单帧噪点，提升稳定性。
   - **空间滤波**：对采样后的间接光纹理执行横向 + 纵向双边模糊，保留边缘细节的同时平滑噪点；或使用深度学习降噪（如 DLSS）进一步优化画质。
   - **边缘修正**：通过法线与深度缓冲区检测物体边缘，避免间接光跨边缘泄漏（如墙面颜色渗透到地面）。
4. 混合阶段：间接光与直接光融合
   - 将降噪后的间接光纹理与原始颜色缓冲区按比例混合（如间接光强度 ×0.3 + 直接光颜色），得到最终带全局光照的场景颜色。
   - 可通过参数调节间接光强度、采样范围等，适配不同场景需求。
5. 优化阶段：性能与质量平衡
   - **采样数控制**：降低采样数（如 8-16 条）提升速度，通过 TAA 与空间滤波补偿噪点；
   - **LOD 适配**：对远处像素使用低分辨率采样，近处像素提高采样精度；
   - **动态开关**：根据场景复杂度或硬件性能，动态启用 / 禁用 SSGI，优先保证帧率。

## 关键技术细节与优化

1. 光线步进优化

   - **自适应步长**：近处物体使用小步长保证精度，远处物体增大步长减少计算量。
   - **HZB 加速**：通过层次化深度缓冲区快速跳过空区域，避免逐像素深度比较，计算量可降低 50% 以上。

2. 采样方向策略

   - **反射主导**：高光表面（如金属）优先沿镜面反射方向采样，提升反射效果（类似 SSR）。
   - **半球采样**：漫反射表面（如墙面）在法线半球内随机采样，模拟光线的各向散射。
   - **重要性采样**：根据材质粗糙度调整采样方向分布，粗糙度越高，采样越分散。

3. 降噪算法对比

   | 降噪方法     | 原理                     | 优点               | 缺点                   |
   | ------------ | ------------------------ | ------------------ | ---------------------- |
   | TAA 时间累积 | 利用历史帧信息平均       | 低开销，效果稳定   | 运动物体易产生拖影     |
   | 双边模糊     | 结合颜色与空间距离的滤波 | 边缘保留好，速度快 | 强噪点场景效果有限     |
   | 深度学习降噪 | 通过神经网络学习噪点分布 | 降噪效果最佳       | 依赖硬件算力，延迟较高 |

## 常见问题与解决方案

1. **屏幕外物体缺失**：结合烘焙光照（如 Lightmap）补充屏幕外间接光，或使用体积光照技术（如 LPV）辅助。
2. **边缘泄漏**：通过深度与法线的梯度检测物体边缘，限制间接光采样范围，避免跨边缘混合。
3. **噪点严重**：增加采样数 + TAA + 双边模糊组合，或使用硬件加速的降噪技术（如 NVIDIA 的 RTX 降噪）。
4. **性能瓶颈**：降低采样数、使用 HZB 加速、动态分辨率渲染（DSR）等。
